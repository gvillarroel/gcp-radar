# ADRs

This directory stores Architecture Decision Records for `gcp-radar`.

## When to Add an ADR

Add an ADR for decisions that materially affect:

- repository structure
- data models
- workflow stages
- source policy
- validation strategy
- output format
- knowledge organization
- skill evaluation or evolution strategy

## Minimal ADR Structure

Use a simple structure:

1. Title
2. Status
3. Context
4. Decision
5. Consequences

## Naming Convention

Prefer sequential filenames such as:

- `0001-initial-repository-structure.md`
- `0002-canonical-card-schema.md`

## Language

All ADRs must be written in English.
