- Target (event destination) Events can be routed to one of the following event destinations: Cloud Run functions ( using the Cloud Run functions interface ) Cloud Run Google Kubernetes Engine (GKE), including the public endpoints of private and public services running in a GKE cluster Internal HTTP endpoints in a Virtual Private Cloud (VPC) network Workflows Event type You can route an event by configuring filters for an Eventarc trigger.
- Source (event provider) Depending on your source, select an appropriate trigger type: Google sources—Filters events sent from Google providers (directly or through Cloud Audit Logs entries) Third-party—Filters events sent from eligible third-party providers Using the Google Cloud CLI, you can list Eventarc providers and retrieve their details, including supported events.
- Third-party events—Triggered by the events of a non-Google provider that offers an Eventarc source Eventarc triggers To create an Eventarc trigger, click the instructions provided for the event you want to route.
