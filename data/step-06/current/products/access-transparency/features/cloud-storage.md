# Cloud Storage

Product: Access Transparency
Coverage: MEDIUM

## Step 02 Summary

Access Transparency now supports Cloud Storage in GA.

## Extended Definition

Access Transparency covers Cloud Storage by emitting log entries for Google personnel access to Cloud Storage resources, shown as entries with `product: "Cloud Storage"` and `resourceName` values under `//googleapis.com/storage/buckets/.../objects/...`. These entries can include permission-level context such as `permissionDetails` (for example `DATA READ`/`ADMIN READ`) and are associated with concrete Cloud Storage actions including creating/deleting buckets or objects and updating HMAC keys.

## Evidence Summary

The Access Transparency logs page provides concrete Cloud Storage examples in audit log entries, while the IAM Conditions page contributes resource-name formatting context for Cloud Storage resources, but neither excerpt explicitly states GA status or a formal launch-date statement.
