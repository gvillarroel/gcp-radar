# App Engine flexible environment branding

Product: App Engine flexible environment Ruby

## Step 02 Summary

App Engine Managed VMs was renamed to App Engine flexible environment.

## Extended Definition

The available evidence identifies this feature primarily by its current branding as **App Engine flexible environment**, but it does not explicitly document a rename from "Managed VMs." In current Google Cloud App Engine documentation, the feature is described as an App Engine deployment model using Compute Engine virtual machine instances, with configurable CPU and memory, support for custom runtimes/custom libraries/SSH/Docker, and automatic scale balancing.

## Evidence Summary

These official docs pages confirm the App Engine flexible environment naming and core VM-based runtime/scaling characteristics, but do not provide explicit evidence of a Managed VMs rename in the provided excerpts.
