# Serverless VPC Access

Product: App Engine Admin API
Coverage: HIGH

## Step 02 Summary

Serverless VPC Access is now generally available for App Engine; Serverless VPC Access reached beta status, allowing App Engine apps to connect to internal VPC resources.

## Extended Definition

Serverless VPC Access is an App Engine capability that enables an app to connect to internal resources in a VPC network, such as Compute Engine VM instances or Cloud Memorystore. The App Engine Admin API release notes record this feature as entering beta on April 9, 2019 and becoming generally available (GA) on December 11, 2019.
