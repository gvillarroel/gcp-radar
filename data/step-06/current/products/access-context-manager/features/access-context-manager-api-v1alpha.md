# Access Context Manager API v1alpha

Product: Access Context Manager
Coverage: MEDIUM

## Step 02 Summary

The Access Context Manager API v1alpha was deprecated; deprecated on Q3 2019.

## Extended Definition

Access Context Manager API v1alpha is the v1alpha version of the Access Context Manager REST API, hosted at `https://accesscontextmanager.googleapis.com`, and it exposes resources such as `accessPolicies`, `accessLevels`, and `servicePerimeters` with operations including create, get/list, update, delete, and replace/commit actions. It also supports long-running operation patterns for mutation methods and publishes corresponding v1alpha RPC method names for audit logging (for example, `CreateAccessPolicy`, `UpdateServicePerimeter`, `CommitServicePerimeters`) with ADMIN activity permission mappings. Deprecation status or date for this v1alpha API is not shown in the provided excerpts, so that fact is not directly evidenced here.

## Evidence Summary

The reference page documents the v1alpha REST surface (resources, endpoints, and methods), while the audit-logging page links those v1alpha methods to admin/audit permissions, and the manage-access-levels page shows example v1alpha endpoint usage.
