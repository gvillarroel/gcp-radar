# In-place major version upgrade for AlloyDB clusters

Product: AlloyDB
Coverage: HIGH

## Step 02 Summary

AlloyDB now supports generally available in-place major version upgrades of clusters to higher supported PostgreSQL versions.

## Extended Definition

In-place major version upgrade for AlloyDB is a feature that lets an existing AlloyDB cluster be upgraded to a newer PostgreSQL major version directly, including upgrades from PostgreSQL 14 or 15 to PostgreSQL 16. The feature was first announced in preview and is documented as generally available as of March 19, 2025.
