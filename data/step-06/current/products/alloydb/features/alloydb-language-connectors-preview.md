# AlloyDB Language Connectors preview

Product: AlloyDB
Coverage: HIGH

## Step 02 Summary

AlloyDB Language Connectors are now available in preview with automated mTLS, IAM-based authorization, and automated IAM authentication.

## Extended Definition

AlloyDB Language Connectors are connector libraries used to connect to an AlloyDB instance, and as of the February 27, 2024 release note they are available in Preview with automated mutual TLS (mTLS), IAM-based authorization, and Automated IAM Authentication. The same release note describes these capabilities as part of the language connector feature itself, and a later 2026 note states support for AlloyDB Language Connectors with Auto IAM Authentication and managed connection pooling.

## Evidence Summary
