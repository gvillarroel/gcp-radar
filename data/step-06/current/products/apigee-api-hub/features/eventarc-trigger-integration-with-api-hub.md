# Eventarc trigger integration with API hub

Product: Apigee API hub
Coverage: MEDIUM

## Step 02 Summary

API hub is now integrated with Google Cloud Eventarc so users can create Eventarc triggers for API hub events and launch custom workflows.

## Extended Definition

API Hub’s Eventarc trigger integration lets users create and configure Eventarc triggers for API Hub events, including events when an API is updated. In the documented quickstart, these triggers are executed by a Cloud Run service, and trigger configuration is performed from the Eventarc Triggers page in the Google Cloud console using Cloud Run service details.

## Evidence Summary

This official quickstart shows how to create an Eventarc trigger for API Hub and confirms trigger execution for API update events via a Cloud Run service through the Cloud Console.
