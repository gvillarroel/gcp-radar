- Private Service Connect provides an authorization model that gives consumers and producers granular control, ensuring that only the intended service endpoints and no other resources can connect to a service.
- Service consumers access those Private Service Connect services directly through one of these Private Service Connect types: Private Service Connect endpoints .
- Endpoints Private Service Connect endpoints are internal IP addresses in a consumer VPC network that can be directly accessed by clients in that network.
