# CMK encryption for component volumes

Product: Anthos clusters on AWS (previous generation)
Coverage: HIGH

## Step 02 Summary

Anthos clusters on AWS supports encrypting component volumes with customer-managed keys (CMK).

## Extended Definition

Anthos clusters on AWS (GKE on AWS) allow operators to enable customer-managed key encryption for key component data stores and volumes by supplying AWS KMS key ARNs in cluster and node-pool creation parameters (for example, `--database-encryption-kms-key-arn` and `--config-encryption-kms-key-arn`). The documentation also specifies separate KMS key ARNs for control plane configuration, etcd/secret data, and control-plane main volume encryption, with required IAM permissions (`kms:Encrypt`, `kms:Decrypt`, and related grant actions), confirming CMK-backed encryption of cluster component volumes and sensitive control-plane artifacts.

## Evidence Summary

The cited GKE on AWS quickstart, cluster-creation, and IAM-role pages collectively document CMK/KMS ARN usage for cluster and node-pool encryption and the exact KMS IAM permissions required for controlling access to encrypted component data and volumes.
