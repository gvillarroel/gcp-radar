## Step 02 Summary

The Ruby runtime became available for the App Engine flexible environment.

## Extended Definition

The App Engine flexible environment Ruby runtime is the Ruby language runtime option for applications deployed to App Engine in the flexible environment, configured via `app.yaml` with `runtime: ruby` and `env: flex`. Google’s release notes state that on May 02, 2016, "The Ruby runtime is now available for the App Engine flexible environment," indicating the feature’s introduction date.
