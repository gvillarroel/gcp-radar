# Google Cloud Managed Service for Prometheus on Anthos on Azure

Product: Anthos clusters on Azure
Coverage: MEDIUM

## Step 02 Summary

Enabled Google Cloud Managed Service for Prometheus as an invite-only private preview starting with Kubernetes 1.24+ on Anthos clusters on Azure.

## Extended Definition

In Anthos clusters on Azure, Google Cloud Managed Service for Prometheus (GMP) is available as an invite-only private preview for Kubernetes version 1.24 and later. In this mode, GMP supports managed collection and upload of workload metrics to Cloud Monarch, enabling workload monitoring and alerting with Prometheus without manual, large-scale Prometheus operations.

## Evidence Summary

The release notes confirm GMP’s invite-only private preview availability on Azure starting with Kubernetes 1.24+, and describe its managed workload-metrics collection flow into Cloud Monarch with Prometheus-based monitoring and alerting.
