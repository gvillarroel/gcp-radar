# Custom logging parameters for Kubernetes 1.22 clusters

Product: Anthos clusters on Azure
Coverage: HIGH

## Step 02 Summary

New clusters created with Kubernetes 1.22 can now be configured with custom logging parameters.

## Extended Definition

In Anthos on Azure, this feature enables customers to configure custom logging parameters during the creation of new clusters that use Kubernetes version 1.22. It is a cluster-creation-time configuration option added in the Kubernetes 1.22 context and is described as a new behavior for that version.

## Evidence Summary

The referenced official GKE on Azure release notes explicitly say that new Kubernetes 1.22 clusters can be configured with custom logging parameters.
