Product: Google Distributed Cloud (software only) for VMware
Coverage: HIGH

## Step 02 Summary

The Ubuntu node image is qualified against the CIS L1 and L2 Server Benchmark.

## Extended Definition

Google Distributed Cloud (software only) for VMware documents a CIS Ubuntu benchmark assessment for its Ubuntu nodes, including the specific CIS benchmark versions/levels applied (for example, CIS Ubuntu Benchmark level 1.31 and CIS level 2 Server 1.0.0 on Ubuntu 22.04 LTS). The feature exposes benchmark recommendation results as status tables and explicitly identifies recommendations that are not applicable, failed, or otherwise deviating from the benchmark, which is used as evidence of Ubuntu node image compliance posture.
