# SNI support in Controlplane V2 user clusters

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

Server Name Indication (SNI) is supported in Controlplane V2 user clusters.

## Extended Definition

In Google Distributed Cloud (software only) for VMware, Controlplane V2 user clusters are enabled with the `enableControlplaneV2` (config file) or `--enable-control-plane-v2` (gcloud) setting, and the feature is required for user clusters at version 1.30 and higher. These Controlplane V2 clusters are configured with separate control-plane and ingress VIP settings (and optional HTTPS ingress node ports), indicating HTTPS ingress setup for user traffic. The provided excerpts, however, do not explicitly confirm Server Name Indication (SNI) behavior, so direct support for SNI is not evidenced in these snippets.

## Evidence Summary

The official docs confirm how to enable and configure Controlplane V2 user clusters and their VIP/ingress networking options, but they do not provide an explicit statement that SNI is supported.
