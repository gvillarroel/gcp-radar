# Anthos clusters on VMware

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

Anthos clusters on VMware 1.7.4-gke.2 is available for VMware-based Kubernetes clusters; Anthos clusters on VMware 1.8.3-gke.0 is available for VMware-based Kubernetes clusters.

## Extended Definition

Anthos clusters on VMware are user clusters managed through Google Distributed Cloud (software only) for VMware, created with `gcloud container vmware clusters create` and optionally managed via the `google_gkeonprem_vmware_cluster` Terraform resource. The creation workflow ties each cluster to an admin-cluster membership, supports version selection (with version discovery via `query-version-config`), and includes optional networking/load-balancer configuration such as MetalLB, DNS, and VIP/static IP settings. These clusters do not support the Kubernetes EventRateLimit admission controller because it is treated as a Kubernetes alpha feature.

## Evidence Summary

The CIS benchmark page documents an admission-control limitation for Anthos clusters on VMware, and the user-cluster guide documents creation/management mechanics including admin-cluster association, version handling, and configurable cluster networking options.
