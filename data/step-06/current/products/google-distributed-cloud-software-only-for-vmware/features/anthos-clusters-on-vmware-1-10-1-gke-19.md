# Anthos clusters on VMware 1.10.1-gke.19

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

A maintenance release of Anthos clusters on VMware that runs on Kubernetes v1.21.5-gke.1200.

## Extended Definition

Anthos clusters on VMware 1.10.1-gke.19 is a maintenance-release context for Anthos on VMware, where cluster updates are expected to be managed through Anthos patch releases. The cited Google Distributed Cloud docs indicate that, in this environment, Anthos does not support the Kubernetes EventRateLimit admission controller because it is an alpha feature, and cluster patching can involve monthly Anthos patch releases or urgent Windows node-template updates.

## Evidence Summary

The CIS benchmark page provides feature-scope compliance behavior for Anthos clusters on VMware (including unsupported alpha features), while the Windows node pool guide describes patch and upgrade mechanics tied to Anthos patch releases.
