# gkectl prepare image pull and push

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

The gkectl prepare command can pull and push GKE On-Prem container images.

## Extended Definition

In Google Distributed Cloud (software only) for VMware, `gkectl prepare` is a pre-deployment command used before cluster creation or upgrade to perform image-related preparation. The command is documented to push Google Distributed Cloud system images to a configured private registry, and for Windows node pools it can be used with `--upload-windows-images` to handle image upload without manual registry operations; when doing this manually, the docs show pulling Windows base images from `gcr.io/gke-on-prem-release`, retagging them, and pushing them to a private registry. The evidence shows the image acquisition and registry interaction workflows but does not explicitly document every substep of pull/push behavior as part of the same single `gkectl` subcommand in all scenarios.

## Evidence Summary

These pages define `gkectl prepare` as a setup step tied to image handling, including private-registry image pushes and a Windows-specific automatic upload option, with documented manual pull/tag/push alternatives for Windows base images.
