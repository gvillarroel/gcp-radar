# CSI volume snapshots

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

CSI snapshot controllers are automatically deployed in user clusters to support volume snapshots and restores.

## Extended Definition

In Google Distributed Cloud (software only) for VMware, CSI volume snapshots are a supported user-cluster capability that requires vSphere 7.0 Update 3+ or 8.0+ (with a vSphere Enterprise Plus license) when snapshot creation is needed. The documentation also states that CSI proxy is deployed automatically onto Windows nodes in user clusters, indicating that CSI-related components are pre-deployed for storage operations, though the excerpts do not explicitly describe the full snapshot-controller deployment workflow or restoration details.

## Evidence Summary

The cited pages establish required vSphere version/license conditions to create CSI volume snapshots and confirm automatic CSI proxy deployment on Windows nodes, but provide limited direct evidence for complete snapshot-controller behavior.
