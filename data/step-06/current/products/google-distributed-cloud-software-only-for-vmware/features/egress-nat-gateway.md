# Egress NAT gateway

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

Egress NAT Gateway is generally available for configuring predictable source IP addresses for egress traffic from user clusters; Egress NAT gateway provides deterministic source IP addresses for selected cluster egress traffic and is built on Dataplane V2.

## Extended Definition

In Google Distributed Cloud (software only) for VMware, an egress NAT gateway is a user-cluster networking option that can be enabled during cluster creation. The official setup docs indicate that when you plan to create an egress NAT gateway, you should set `advancedNetworking` to true. The provided excerpts do not define its exact packet-flow behavior, just its enablement path in cluster configuration.

## Evidence Summary

Both cited pages show that egress NAT gateway is a documented cluster option and that its configuration requires enabling advanced networking, but they do not provide full functional details (for example, IP determinism or Dataplane V2 linkage).
