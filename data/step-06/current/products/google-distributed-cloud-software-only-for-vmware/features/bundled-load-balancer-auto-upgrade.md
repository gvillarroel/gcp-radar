# Bundled load balancer auto-upgrade

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

The bundled load balancer is upgraded automatically during cluster upgrades.

## Extended Definition

In Google Distributed Cloud (software only) for VMware, the bundled load balancer feature refers to using the bundled MetalLB option in cluster configuration (`loadBalancer.kind: MetalLB`) for admin and user clusters. The documentation states that MetalLB is bundled and simpler to configure than manual load balancing, and that upgrade-related admin commands can update cluster checkpoint state automatically, but it does not explicitly confirm that the bundled load balancer itself is auto-upgraded as part of that process.

## Evidence Summary

These pages show how MetalLB is configured as the bundled load balancer and indicate automatic checkpoint updates during `gkectl upgrade/update`, but they do not explicitly document automatic upgrade behavior of the bundled load balancer itself.
