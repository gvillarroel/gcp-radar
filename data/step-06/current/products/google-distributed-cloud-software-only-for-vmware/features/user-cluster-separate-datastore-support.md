# User cluster separate datastore support

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

User clusters can place nodes and persistent volumes on a datastore separate from the admin cluster datastore.

## Extended Definition

Google Distributed Cloud for VMware’s admin-cluster configuration exposes `vCenter.datastore` and an alternative `vCenter.storagePolicyName` for cluster nodes; the `vCenter.datastore` field is generally immutable, except that it can be cleared when migrating a datastore to Storage Policy Based Management (SPBM). These admin-cluster settings are part of the lifecycle-management configuration path for user clusters, so storage placement is controlled through these datastore/policy controls during cluster configuration. The available excerpts do not explicitly confirm a direct per-user-cluster override to a datastore separate from the admin cluster datastore.

## Evidence Summary

The linked configuration docs define `vCenter.datastore` behavior and the `vCenter.storagePolicyName` fallback (including immutability rules), and note that these admin-cluster settings are used for user-cluster lifecycle management.
