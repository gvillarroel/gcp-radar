# vSphere CSI controller deployment on user cluster control plane nodes

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

The vSphere CSI controller can be deployed on user cluster control plane nodes in advanced clusters.

## Extended Definition

In Google Distributed Cloud for VMware, vSphere CSI component deployment is controlled in user-cluster configuration via the `storage.vSphereCSIDisabled` setting: setting this field to `true` disables deployment of vSphere CSI components. Advanced-cluster behavior requires `enableAdvancedCluster: true`, and while control-plane-related configuration for user clusters is documented, the provided excerpts do not explicitly confirm that the vSphere CSI controller is deployed on user-cluster control plane nodes.

## Evidence Summary

The cited page provides the authoritative configuration fields for advanced user clusters, including the vSphere CSI deployment toggle and related advanced cluster requirements.
