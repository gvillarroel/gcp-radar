Anthos clusters on VMware are Google Distributed Cloud (software only) user clusters managed through `gcloud container vmware` commands, where a cluster is created with a selectable version via `--version` and supported versions are obtained from `query-version-config` for a specific admin cluster membership. The provided Google Cloud documentation does not explicitly list version `1.9.7-gke.8` or state that it runs Kubernetes `1.21.5-gke.1200`, so that specific pairing is not directly evidenced in these excerpts.
