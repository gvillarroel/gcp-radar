# User cluster node pools

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

User cluster node pools are generally available; User cluster node pools let users create multiple node pools in a cluster and update them as needed.

## Extended Definition

For Google Distributed Cloud (software only) for VMware, a user cluster node pool is a configurable group of worker nodes defined under the user cluster’s `nodePools` configuration. Each node pool entry includes settings such as `cpus`, `memoryMB`, and `replicas`, and the `nodePools.replicas` value determines how many worker nodes that pool has. Node pools can be updated (for example, by changing node image fields like `osImage`/`osImageType` and re-running cluster update commands).

## Evidence Summary

These pages show how `nodePools` is declared in user cluster config/Terraform, explain that a node pool is a set of same-config worker nodes, and show that replica count and OS image fields govern worker-node sizing and that pool settings can be updated.
