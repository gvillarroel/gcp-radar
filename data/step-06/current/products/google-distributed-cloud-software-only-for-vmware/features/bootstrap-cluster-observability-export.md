# Bootstrap cluster observability export

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

Metrics and logs from the bootstrap cluster are uploaded to Google Cloud Operations for improved admin cluster observability.

## Extended Definition

Bootstrap cluster observability export refers to configuring a Google Distributed Cloud (software only) for VMware bootstrap/admin cluster so its operational telemetry can be handled through Google Cloud Operations. In the documented bootstrap flow, the admin cluster configuration includes Stackdriver fields (such as project ID) and location settings that control where cluster metadata, Cloud Logging/Monitoring data, and admin audit logs are stored, indicating observability data is directed to Google Cloud rather than only the local environment. The cluster-creation process also logs local progress while waiting for metrics to become ready in Google Cloud.

## Evidence Summary

The official create-admin-cluster page links observability scope to the bootstrap/admin cluster settings (`stackdriver` project ID and location) and explicitly states that system logs/monitoring and audit data are stored in Google Cloud services.
