# Cloud Monitoring alerts

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

Cloud Monitoring can provide out-of-the-box alerts for critical cluster metrics and events.

## Extended Definition

In Google Distributed Cloud (software only) for VMware, Cloud Monitoring is supported as part of the cluster telemetry path by enabling Stackdriver/Monitoring in cluster setup so that monitoring data is collected for system components. The documentation also notes that cluster service settings store Cloud Monitoring data in the selected region for on-prem user/admin clusters, which indicates operational metrics/events can be surfaced for visibility, while specific alert policy details are not shown in the provided excerpts.

## Evidence Summary

The cited pages provide evidence that Stackdriver/Cloud Monitoring is enabled and that monitoring data for cluster components is collected and regionally stored, but they do not provide explicit steps for defining Cloud Monitoring alert policies.
