# vSAN datastore support

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

VSAN datastore support is available for admin and user clusters.

## Extended Definition

In Google Distributed Cloud (software only) for VMware, vSAN datastore support refers to the ability to specify vCenter-backed datastores in cluster configuration. The admin-cluster documentation examples show `datastore` and `clusterBackup.datastore` fields in the vCenter configuration, which indicates datastore-based storage configuration is part of admin-cluster setup. The provided user-cluster excerpts do not contain explicit datastore configuration parameters, so evidence for user-cluster datastore support is not directly shown in these snippets.

## Evidence Summary

The cited pages provide admin-cluster examples that include datastore-related configuration fields, but user-cluster documentation excerpts supplied here focus on cluster creation commands and load-balancer/network settings without explicit datastore-vSAN configuration evidence.
