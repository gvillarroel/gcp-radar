# multiple control planes per user cluster

Product: Google Distributed Cloud (software only) for VMware
Coverage: MEDIUM

## Step 02 Summary

User clusters can run up to three control planes.

## Extended Definition

In Google Distributed Cloud (software only) for VMware, a user cluster configured with Control Plane V2 can include multiple control-plane nodes instead of a single control-plane instance. The provided examples show three control-plane nodes (`cp-1`, `cp-2`, `cp-3`) marked as `isControlPlane: true` and replica settings (`--replicas=3` / `masterNode.replicas: 3`) for control-plane configuration. The excerpts show three-node examples but do not explicitly document an exact upper limit.

## Evidence Summary

The cited pages provide command and YAML examples for Control Plane V2 user-cluster creation that demonstrate multi-control-plane node definitions and replica settings (including three control-plane nodes in examples).
