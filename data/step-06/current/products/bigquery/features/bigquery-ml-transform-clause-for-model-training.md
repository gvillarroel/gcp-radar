# BigQuery ML TRANSFORM clause for model training

Product: BigQuery
Coverage: MEDIUM

## Step 02 Summary

BigQuery ML now supports the TRANSFORM clause for training models that can be exported in TensorFlow SavedModel format.

## Extended Definition

In BigQuery ML, the TRANSFORM clause in the CREATE MODEL statement defines which transformed columns are used as training input, and only the columns produced by that clause are used during training. The clause can select columns from a query and omit raw columns not needed for training, with supported input column types including SIMPLE types and ARRAY of SIMPLE types. BigQuery documentation also describes Transform-only models as feature-transformation artifacts rather than typical predictive ML models, while it does not provide evidence in these excerpts that the TRANSFORM clause itself enables TensorFlow SavedModel export.

## Evidence Summary

The CREATE MODEL syntax page explains how TRANSFORM shapes training input and accepted types, and the end-to-end journey page places TRANSFORM within model workflows and defines Transform-only models as feature-engineering artifacts.
