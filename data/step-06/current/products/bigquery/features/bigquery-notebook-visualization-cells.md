# BigQuery notebook visualization cells

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery notebooks gained visualization cells that can automatically render charts for DataFrames with configurable columns, chart types, aggregations, colors, labels, and titles.

## Extended Definition

BigQuery Notebooks now support visualization cells that can automatically generate a visualization of a DataFrame in the notebook. The feature is described as a built-in notebook capability rather than a standalone external tool.
