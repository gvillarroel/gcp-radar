# Data Science Agent for BigQuery in Colab Enterprise

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

The BigQuery Data Science Agent is now available in Colab Enterprise for exploratory analysis and ML within notebooks.

## Extended Definition

The BigQuery Data Science Agent (DSA) is a built-in agent available in BigQuery Colab Enterprise notebooks that automates exploratory data analysis, data processing, machine-learning tasks, and visualization-insight generation directly within notebook workflows. In September 2025, the feature’s capabilities were expanded to help users find BigQuery tables with **@**, find files to upload with **+**, and select one or more tables for analysis within the Data Science Agent.

## Evidence Summary

The release notes establish launch and feature enhancements for the BigQuery Data Science Agent in Colab Enterprise, while the AI introduction page describes its role in notebook-based exploratory analysis and ML work.
