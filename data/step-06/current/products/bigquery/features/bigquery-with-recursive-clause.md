# BigQuery WITH RECURSIVE clause

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

The WITH RECURSIVE clause is now generally available in BigQuery for recursive common table expressions.

## Extended Definition

BigQuery Standard SQL supports recursive common table expressions using the `WITH RECURSIVE` clause, which can precede a query and contain one or more CTE definitions. A recursive CTE is expressed as an anchor query combined with a recursive query (typically via `UNION ALL`), allowing the CTE to reference itself to generate iterative rows, while recursive references are constrained to specific allowed contexts.

## Evidence Summary

The referenced query syntax page defines the `WITH [RECURSIVE]` grammar, includes recursive CTE examples, and documents usage rules and restrictions for recursive references.
