Product: BigQuery

## Step 02 Summary

BigQuery Data Insights can use Gemini to generate table and column descriptions from table metadata.

## Extended Definition

BigQuery Data Insights supports generating table and column descriptions using Gemini from table metadata. The generated metadata descriptions can be produced in all supported Gemini languages, and the resulting insights can be published to Dataplex Universal Catalog.
