# BigQuery Studio Data canvas

Product: BigQuery
Coverage: MEDIUM

## Step 02 Summary

BigQuery Studio added support for creating a data canvas with a graphical, natural-language interface for analysis workflows.

## Extended Definition

BigQuery Studio’s Data canvas is a data-analysis artifact that can be created and modified through a "data canvas assistant," an agent-like tool that can construct or modify the canvas based on user prompting to answer analytics questions. BigQuery release notes also indicate a Gemini-powered assistant can be used in a BigQuery data canvas, and that data canvases can be organized in folders and annotated with comments as first-class single-file code assets.

## Evidence Summary

The cited release-notes page confirms that Data canvas supports prompt-driven assistant workflows (including a Gemini-powered variant), and can be managed via folders/comments like other code assets.
