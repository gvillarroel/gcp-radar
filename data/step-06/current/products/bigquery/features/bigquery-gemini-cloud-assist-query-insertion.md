# BigQuery Gemini Cloud Assist query insertion

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

Allows applying SQL generated by Gemini Cloud Assist directly into the query currently open in the BigQuery editor.

## Extended Definition

BigQuery Gemini Cloud Assist query insertion is a BigQuery editor feature that enables users to apply SQL generated in the Gemini Cloud Assist chat directly into the query that is currently open in the editor. It is an announced release-note capability dated October 1, 2025.

## Evidence Summary

The release notes state that SQL generated in Gemini Cloud Assist can be applied to the open editor query, and the Gemini overview page confirms Gemini Cloud Assist is used for SQL generation in BigQuery.
