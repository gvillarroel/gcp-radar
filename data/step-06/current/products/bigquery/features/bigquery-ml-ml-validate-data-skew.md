# BigQuery ML ML.VALIDATE_DATA_SKEW

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery ML now includes ML.VALIDATE_DATA_SKEW to compare serving data statistics against training data statistics for skew detection.

## Extended Definition

ML.VALIDATE_DATA_SKEW is a BigQuery ML model monitoring function that computes statistics for serving data and compares them with statistics from training data to detect anomalous differences (data skew). The BigQuery documentation also lists this function as part of the supported monitoring workflow for multiple model types, including supervised and other model families. Overall, it is intended for skew checks between training and production/serving datasets.

## Evidence Summary

The journey reference identifies ML.VALIDATE DATA SKEW as a model-monitoring function across model types, while the release notes explicitly define it as comparing serving versus training statistics to find anomalous differences.
