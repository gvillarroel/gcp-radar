# BigQuery console Reference panel

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery now provides a Reference panel in the query and notebook editors for schema preview and query snippet or field-name insertion.

## Extended Definition

The BigQuery Reference panel is a console feature in BigQuery query and notebook editors that lets users preview schema details for tables, snapshots, views, and materialized views, and open selected resources in a new tab. The feature was introduced in the BigQuery release notes with this capability, indicating console-side schema reference functionality in both editor types.

## Evidence Summary

The BigQuery release notes page documents the August 18, 2025 feature announcement that adds the Reference panel to query and notebook editors for schema previewing and opening resources in a new tab.
