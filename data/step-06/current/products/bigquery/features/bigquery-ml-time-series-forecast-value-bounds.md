# BigQuery ML time series forecast value bounds

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery ML now supports forecast value constraints for time series models via FORECAST_LIMIT_LOWER_BOUND and FORECAST_LIMIT_UPPER_BOUND options.

## Extended Definition

In BigQuery ML, time series models of type ARIMA PLUS or ARIMA PLUS XREG can include the CREATE MODEL OPTIONS `forecast limit lower bound` and `forecast limit upper bound` as `float64` values. These options define lower and upper bounds for forecasted values, allowing constraints to be applied to generated predictions (for example, forcing forecast values to stay above 0).

## Evidence Summary

The tutorial shows practical use of forecast limit options in an ARIMA_PLUS CREATE MODEL query, while the syntax reference formally documents both options and their meaning for ARIMA PLUS family models.
