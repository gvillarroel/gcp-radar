# Multilingual data-insight descriptions in BigQuery

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery can now generate table and column descriptions in all supported Gemini languages during data insight generation.

## Extended Definition

BigQuery data insights can now generate table and column descriptions in all supported Gemini languages when data insights are generated, including descriptions produced from table metadata. This multilingual data-insight generation is part of Gemini-powered auto-description functionality, and the generated insights (including recommendations and descriptions) can also be published to Dataplex Universal Catalog.

## Evidence Summary
