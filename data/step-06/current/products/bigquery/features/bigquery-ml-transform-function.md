# BigQuery ML TRANSFORM function

Product: BigQuery
Coverage: MEDIUM

## Step 02 Summary

The BigQuery ML TRANSFORM function is now generally available for preprocessing feature data using transformations defined in the model TRANSFORM clause.

## Extended Definition

BigQuery ML supports preprocessing via a `CREATE MODEL ... TRANSFORM` clause, where you define transformed feature columns to be used for model training, and only the outputs of that clause are used as input features. The SQL syntax reference states that input columns in `TRANSFORM` can be any SIMPLE type or ARRAY of SIMPLE type, and columns not referenced in `TRANSFORM` can be omitted. BigQuery ML also documents `ML.TRANSFORM` as part of supported inference capabilities for working with transformed model features.

## Evidence Summary

These pages define how BigQuery ML defines and uses the `TRANSFORM` clause in model creation, and list `ML.TRANSFORM` among BigQuery ML model inference functions.
