# BigQuery ML contribution analysis models

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery ML supports creating contribution analysis models with CREATE MODEL and generating metric insights using ML.GET_INSIGHTS; BigQuery ML now supports creating contribution analysis models with CREATE MODEL and analyzing results with ML.GET_INSIGHTS.

## Extended Definition

BigQuery ML supports a dedicated model type, CONTRIBUTION ANALYSIS, in the CREATE MODEL statement for building models that identify key drivers of changes. The release notes state that these contribution analysis models can be used with ML.GET_INSIGHTS to generate insights about changes to key metrics in multi-dimensional data. As of April 1, 2025, the feature is documented as newly available in BigQuery ML.

## Evidence Summary

The CREATE MODEL reference page defines CONTRIBUTION ANALYSIS as a supported BigQuery ML model type, and the release notes confirm its usage with ML.GET_INSIGHTS for metric-change explanation, with an April 1, 2025 availability note.
