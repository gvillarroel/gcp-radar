# BigQuery Gemini-enhanced translation rules for interactive SQL translator

Product: BigQuery
Coverage: MEDIUM

## Step 02 Summary

BigQuery now supports Gemini-enhanced translation rules to customize interactive SQL translator output for migration needs.

## Extended Definition

BigQuery offers **Gemini-enhanced translation rules** (currently in Preview) that let users customize SQL translation output when using the interactive SQL translator. This feature applies to interactive, query-by-query migration translation in BigQuery’s SQL migration tooling.

## Evidence Summary

The Gemini overview page documents the preview capability to create Gemini-enhanced translation rules for interactive SQL translation, while the migration introduction page defines interactive SQL translator usage for translating individual queries in SQL migration.
