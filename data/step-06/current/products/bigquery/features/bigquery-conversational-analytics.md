# BigQuery conversational analytics

Product: BigQuery
Coverage: MEDIUM

## Step 02 Summary

Conversational analytics enables natural-language interactions with data through predefined and custom BigQuery agents and chat-based query workflows.

## Extended Definition

BigQuery Conversational Analytics is an early-access BigQuery feature that enables working with BigQuery through a conversational analytics agent in a chat-style workflow. The official release notes describe support for custom glossary terms for the agent (including Dataplex Universal Catalog terms), clickable suggested follow-up questions in the Cloud console, and ObjectRef-based integration with Google Cloud Storage for that workflow.
