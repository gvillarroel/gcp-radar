## Extended Definition

The BigQuery ML TRANSFORM clause in CREATE MODEL defines custom feature preprocessing expressions for model training using SQL functions. It generates the transformed columns that form the model’s training input, so only those output columns are used during training, and unreferenced source columns can be omitted.
