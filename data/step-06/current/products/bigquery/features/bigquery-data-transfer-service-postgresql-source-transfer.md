# BigQuery Data Transfer Service PostgreSQL source transfer

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery Data Transfer Service now supports transferring data from PostgreSQL sources.

## Extended Definition

BigQuery Data Transfer Service supports loading data from PostgreSQL as one of its supported source types, enabling data transfer jobs from PostgreSQL into BigQuery. Google’s release notes state that MySQL and PostgreSQL transfers are supported in Preview, and the DTS introduction page includes PostgreSQL in its supported data sources list. In practical usage, DTS is used for scheduled recurring data transfers from supported sources.

## Evidence Summary

The cited DTS documentation pages confirm PostgreSQL is a supported BigQuery Data Transfer Service source and explicitly note that PostgreSQL transfer support is listed in release notes as being in Preview.
