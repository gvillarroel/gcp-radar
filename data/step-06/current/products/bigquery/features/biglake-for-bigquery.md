# BigLake for BigQuery

Product: BigQuery
Coverage: MEDIUM

## Step 02 Summary

BigLake is now generally available in BigQuery, including using Cloud Storage data for BigQuery ML and publishing BigLake tables to Analytics Hub listings.

## Extended Definition

BigLake for BigQuery is BigQuery’s support for BigLake external tables that reference external object storage. The BigQuery CLI docs show that BigLake tables are defined with the `--external table definition` option, including Cloud Storage syntax using `FORMAT = BUCKET_PATH @ REGION` and file-based definitions for BigLake tables on AWS and Azure. Evidence from access-control documentation is about Analytics Hub data exchange/listing permissions and does not explicitly state that those permissions are the dedicated control plane for publishing BigLake tables.

## Evidence Summary

The BigQuery CLI page directly documents BigLake external table definition syntax for Cloud Storage and other object sources, while the IAM page contributes related Analytics Hub listing/exchange permission details but only indirectly to BigLake publishing.
