# ObjectRef integration in BigQuery conversational analytics

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery conversational analytics now integrates ObjectRef functions to reference and analyze unstructured Cloud Storage objects like images and PDFs.

## Extended Definition

BigQuery conversational analytics gained support for ObjectRef integration, allowing analysts to reference and work with unstructured Google Cloud Storage objects (including images and PDFs) through ObjectRef functions and ObjectRef/ObjectRefRuntime values. This enables those referenced objects to be included in conversational analysis workflows, with ObjectRef execution supporting both direct and delegated access paths. BigQuery also defines dedicated IAM roles for this capability, including ObjectRef admin and reader roles that grant read/write access to referenced objects.
