# Apache Iceberg REST catalog in BigLake metastore

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

The Apache Iceberg REST catalog in BigLake metastore is now generally available.

## Extended Definition

The Apache Iceberg REST catalog in BigLake metastore is a generally available feature (announced October 30, 2025) that provides a REST-based Iceberg metadata catalog in BigLake metastore. It supports capabilities including BigQuery catalog federation, credential vending, and catalog management in the Google Cloud console, and it is used to allow open source query engines to interoperate with and access Iceberg data in Cloud Storage.
