# BigQuery migration assessment support for Amazon Redshift Serverless

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery migration assessment now includes source assessment support for Amazon Redshift Serverless.

## Extended Definition

BigQuery migration assessment supports Amazon Redshift Serverless as a source for source assessment, enabling customers to evaluate and plan data warehouse migration from that platform to BigQuery. In general, the BigQuery Migration Service’s migration assessment feature is used to assess and plan data warehouse migrations by running a BigQuery migration assessment.

## Evidence Summary

The release notes explicitly announce the April 3, 2025 addition of Redshift Serverless support in BigQuery migration assessment, while the migration introduction page defines migration assessment as the BigQuery tool for assessing and planning migration.
