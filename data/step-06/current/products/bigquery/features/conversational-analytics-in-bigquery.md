# Conversational analytics in BigQuery

Product: BigQuery
Coverage: MEDIUM

## Step 02 Summary

BigQuery introduced Early Access conversational analytics that lets users chat with data, get quick natural-language insights, and create custom agents that can also be accessed outside BigQuery.

## Extended Definition

BigQuery Conversational Analytics is an early-access feature in BigQuery for which users must enroll through a request form. The feature is implemented as a conversational analytics capability using agents, with release-note updates indicating support for custom glossary term workflows (including Dataplex Universal Catalog business glossary terms) and later ObjectRef integration with Google Cloud Storage for those agents.

## Evidence Summary

The BigQuery release notes provide official confirmation that conversational analytics is an early-access feature and list specific recent feature updates, including agent glossary support and ObjectRef-based Google Cloud Storage integration.
