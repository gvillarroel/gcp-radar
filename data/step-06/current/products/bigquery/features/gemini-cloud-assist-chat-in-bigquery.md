# Gemini Cloud Assist chat in BigQuery

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery now supports Gemini Cloud Assist chat for generating SQL queries and Python code.

## Extended Definition

Gemini Cloud Assist chat in BigQuery is an AI assistant feature that can generate SQL queries and Python code for users, with the option to apply chat-generated SQL directly to the currently open query in the editor. The release notes also indicate it can provide job-history insights (for example, why a query was slow or which queries used the most resources) and can discover resources across projects.
