# Parameterized queries in BigQuery Query Editor

Product: BigQuery
Coverage: LOW

## Step 02 Summary

The BigQuery Query Editor in Google Cloud console now supports running parameterized queries.

## Extended Definition

BigQuery parameterized queries use placeholders in SQL (`@name` for named parameters and `?` for positional parameters) that are replaced with supplied values when the query runs. The GoogleSQL reference defines these placeholders and describes query parameters as valid substitutable expressions, with additional constraints on where they can be used in certain statements. The provided excerpts do not explicitly confirm that the Cloud Console BigQuery Query Editor itself provides a dedicated parameter-run workflow, so that UI-specific claim is not directly evidenced.

## Evidence Summary
