# Authorized stored procedures in BigQuery

Product: BigQuery
Coverage: MEDIUM

## Step 02 Summary

BigQuery now supports authorized stored procedures so users can share stored procedures without direct access to underlying tables.

## Extended Definition

BigQuery supports stored procedures via the `CREATE PROCEDURE` statement, including procedure bodies that run in the context of the project owning the procedure. It also defines dedicated **Authorized Routine** IAM roles (such as `roles/bigquery.routineAdmin`, `roles/bigquery.routineDataEditor`, `roles/bigquery.routineDataViewer`, and `roles/bigquery.routineMetadataViewer`) that grant routine-related permissions on routines plus associated tables/datasets/models, which indicates a permissions model for controlled routine access separate from broader BigQuery access.

## Evidence Summary

The BigQuery DDL reference documents stored procedure creation syntax, while the access-control documentation lists specific Authorized Routine roles and their granted routine and data permissions.
