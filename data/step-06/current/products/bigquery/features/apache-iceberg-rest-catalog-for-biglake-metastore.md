# Apache Iceberg REST catalog for BigLake metastore

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery adds Apache Iceberg REST catalog support in BigLake metastore to enable interoperability for open source query engines with Iceberg data in Cloud Storage.

## Extended Definition

The Apache Iceberg REST catalog for BigLake metastore is a BigQuery feature that lets BigLake metastore expose Apache Iceberg data in Cloud Storage to multiple query engines through a shared REST catalog, enabling interoperability for open source engines. The release notes indicate it was introduced on June 23, 2025 and marked generally available on October 30, 2025, where it added capabilities such as BigQuery catalog federation, credential vending, and catalog management in the Google Cloud console.
