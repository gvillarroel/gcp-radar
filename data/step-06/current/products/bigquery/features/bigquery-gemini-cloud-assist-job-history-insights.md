# BigQuery Gemini Cloud Assist job-history insights

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery now supports using Gemini Cloud Assist to retrieve job-history insights, including slow-query analysis and recent resource-intensive queries.

## Extended Definition

BigQuery’s Gemini Cloud Assist feature provides job-history insights that can explain why specific queries were slow and identify the most resource-intensive queries over the past day. It also labels jobs initiated by the conversational analytics agent in BigQuery Job History within the Google Cloud Console.
