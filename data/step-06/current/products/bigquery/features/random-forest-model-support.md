# Random Forest model support

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery ML Random Forest models are now generally available.

## Extended Definition

BigQuery ML supports Random forest models as a built-in supervised learning model type through the `CREATE MODEL` statement using `MODEL TYPE = 'RANDOM FOREST CLASSIFIER'` or `MODEL TYPE = 'RANDOM FOREST REGRESSOR'`. In BigQuery ML workflows, random forest appears in the supported model-creation journey (including automatic/manual preprocessing and hyperparameter tuning), and the model category supports standard evaluation and inference functions such as `ML.EVALUATE`, `ML.PREDICT`, `ML.EXPLAIN PREDICT`, `ML.GLOBAL EXPLAIN`, `ML.FEATURE IMPORTANCE`, and drift/skew validation.

## Evidence Summary

These pages show that BigQuery ML explicitly lists Random Forest classifier/regressor in `MODEL TYPE`, and document it as a supported supervised learning model path with dedicated creation and model lifecycle/serving statements/functions.
