# BigQuery migration assessment for Informatica

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery adds a migration assessment for Informatica to evaluate the complexity of moving data from Informatica platforms to BigQuery.

## Extended Definition

The BigQuery migration assessment for Informatica is a feature of BigQuery Migration Service that helps evaluate and plan migration work by assessing the complexity of moving data from an Informatica platform to BigQuery. It is documented as a standalone assessment capability used during data warehouse migration planning.

## Evidence Summary

Google’s BigQuery release notes and migration introduction page both confirm that a BigQuery migration assessment for Informatica exists and is used to assess migration complexity from Informatica to BigQuery as part of migration planning.
