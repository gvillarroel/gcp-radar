# BigQuery ML ML.TRANSFORM function

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

The ML.TRANSFORM function enables preprocessing by applying transformations defined in a model’s TRANSFORM clause.

## Extended Definition

In BigQuery ML, the `TRANSFORM` clause in `CREATE MODEL` defines the transformed feature columns used to build the training input, and only the outputs of that clause are used as training inputs when it is present. It allows selecting or transforming columns from the source query (including dropping unused columns) and the transform inputs can be SIMPLE types or ARRAY of SIMPLE types. The `ML.TRANSFORM` function is also documented as an available model inference-stage function in BigQuery ML workflows across supported model categories, including transform-only models.

## Evidence Summary

The CREATE MODEL syntax page explains how the TRANSFORM clause controls training inputs and allowed data types, and the end-to-end journey reference lists ML.TRANSFORM as an official BigQuery ML inference capability.
