# BigQuery custom constraints for sharing resources

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery added support for Organization Policy custom constraints to apply more granular field-level controls for selected sharing resources such as data exchanges and listings.

## Extended Definition

BigQuery supports using Organization Policy custom constraints to enforce more granular, field-level control over specific fields for selected sharing resources, specifically including data exchanges and listings. The same feature update also indicates this approach is available for BigQuery dataset resources.

## Evidence Summary

The release notes explicitly announce custom constraints for field-level sharing-resource governance (and datasets), while the IAM page documents the sharing resource types and permissions relevant to those resources.
