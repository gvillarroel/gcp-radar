# BigQuery ML ML.HOLIDAY_INFO function

Product: BigQuery
Coverage: MEDIUM

## Step 02 Summary

BigQuery ML introduces ML.HOLIDAY_INFO to return the list of holidays modeled by ARIMA_PLUS and ARIMA_PLUS_XREG forecasting models.

## Extended Definition

ML.HOLIDAY_INFO is a BigQuery ML function used to inspect which holidays were used during modeling for time-series forecasting, returning a list of holiday entries associated with a model. In the provided BigQuery tutorial example, it is called on an ARIMA PLUS model to verify both custom holidays and built-in holidays before analyzing forecast effects. The documentation also indicates ARIMA PLUS and ARIMA PLUS XREG are BigQuery ML model types, but only ARIMA PLUS is directly shown with ML.HOLIDAY_INFO in the provided examples.

## Evidence Summary

The tutorial demonstrates ML.HOLIDAY_INFO for listing holidays used in an ARIMA PLUS forecast model, while the CREATE MODEL reference confirms ARIMA PLUS and ARIMA PLUS XREG are supported model types and documents holiday-related modeling options.
