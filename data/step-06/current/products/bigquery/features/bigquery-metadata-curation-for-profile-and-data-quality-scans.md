# BigQuery metadata curation for profile and data-quality scans

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery metadata curation in Google Cloud console now lets users manage data profile scans and data quality scans across projects.

## Extended Definition

BigQuery metadata curation in the Google Cloud console supports management of data profile scans and data quality scans (introduced as a feature on July 31, 2025). The release notes also state that data quality scan results can be published as Dataplex Universal Catalog metadata, and enabling that publishing for an existing scan requires editing the scan and re-enabling the publishing option.

## Evidence Summary

The cited BigQuery release notes page documents the July 31, 2025 launch of scan management in Metadata curation and the June 18, 2025 capability to publish data quality scan results to Dataplex Universal Catalog metadata.
