# BigQuery ML remote open model creation

Product: BigQuery
Coverage: HIGH

## Step 02 Summary

BigQuery ML now supports creating remote models from open models in Vertex Model Garden or Hugging Face and deploying them to Vertex AI.

## Extended Definition

BigQuery ML remote open model creation is the ability to create a `CREATE MODEL` remote model backed by an external open model by using `REMOTE WITH CONNECTION` plus `OPTIONS` such as `HUGGING FACE MODEL ID` or `MODEL GARDEN MODEL NAME` in the model options list. The BigQuery documentation and tutorials show this used to create remote models in BigQuery from open models (for example Hugging Face and Gemma) and then invoke them through `AI.GENERATE_EMBEDDING`/`AI.GENERATE_TEXT`. These open models are treated as hosted in Vertex AI for serving, and open-model remote models can be managed after creation (for example by disabling deployment with `ALTER MODEL ... SET OPTIONS (deploy model = false)`).

## Evidence Summary

The cited BigQuery documentation defines the CREATE MODEL syntax and options needed for remote open models and the tutorials demonstrate creating and using hosted open models from Hugging Face and Model Garden in BigQuery ML.
