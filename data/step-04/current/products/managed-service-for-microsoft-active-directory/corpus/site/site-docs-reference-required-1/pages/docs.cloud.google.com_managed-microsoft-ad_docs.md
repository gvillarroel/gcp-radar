Managed Service for Microsoft Active Directory is a highly available, hardened Google Cloud service running
Microsoft AD that enables you to manage your cloud-based AD-dependent
workloads, automate AD server maintenance and security configuration, and connect
your on-premises AD domain to the cloud.
