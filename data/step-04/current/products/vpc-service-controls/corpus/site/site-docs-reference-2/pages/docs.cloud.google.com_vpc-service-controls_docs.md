VPC Service Controls documentation
Read product documentation
VPC Service Controls lets you mitigate data exfiltration risks by isolating
resources of multi-tenant Google Cloud services. With VPC Service Controls, you
can enforce adaptive access control based on IP range or device trust for
accessing Google Cloud resources from outside privileged networks.
Go to the VPC Service Controls product page for more.
