This document shows how administrators can sync device information manually from
Endpoint Verification to view the latest device information.
Endpoint Verification automatically checks and reports device information after every four
hours. Endpoint Verification also checks for any updates in the device posture at
every hour and reports the updated device information, in case there is an
update.
To sync the device information manually, do the following:
From the Chrome browser toolbar, click
the Endpoint Verification extension.
Click Sync now .
