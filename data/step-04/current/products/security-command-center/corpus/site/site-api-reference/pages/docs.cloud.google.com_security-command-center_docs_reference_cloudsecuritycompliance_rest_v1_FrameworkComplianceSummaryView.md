FrameworkComplianceSummaryView
Stay organized with collections
Save and categorize content based on your preferences.
Specifies the view of the framework compliance summary to be returned. New values may be added in the future.
Enums
FRAMEWORK_COMPLIANCE_SUMMARY_VIEW_UNSPECIFIED
The default / unset value. The API will default to the BASIC view.
FRAMEWORK_COMPLIANCE_SUMMARY_VIEW_BASIC
Includes basic compliance metadata, but omits trend data.
FRAMEWORK_COMPLIANCE_SUMMARY_VIEW_FULL
Includes all information, including findingCount and controlsPassingTrend . Trend data is provided for the last 30 days.
