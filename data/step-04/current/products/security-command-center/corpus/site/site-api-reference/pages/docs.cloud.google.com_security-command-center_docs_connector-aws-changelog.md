This page describes changes to the Security Command Center connector for AWS .
Changes the week of 2025-03-03
AWS connector requires the collection of organization and organizational unit data
The AWS connector has changed to enable additional use cases that require AWS
organization and organizational unit (OU) data. To support these use cases, and
to collect organization and OU data, the delegate account must be configured to
meet requirements. For example, it must be attached to an organization.
If you created a delegated account before this change, check that the account
meets all configuration requirements described in
Create AWS accounts .
