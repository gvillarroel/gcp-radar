Enterprise service tier
Advanced configuration for threat management helps you obtain as much information
about threats as possible, by integrating Security Command Center with other
optional products and services using its security orchestration, automation, and response (SOAR) features.
To identify, enrich, and triage threats, certain integrations provided in the
Enterprise tier of Security Command Center require you to manually configure them.
To configure optional integrations for advanced threat management, refer to the
following pages in the Google SecOps documentation:
AWS Elastic Compute Cloud (EC2)
AWS Identity and Access Management (IAM)
Email V2
Mandiant Threat Intelligence
VirusTotalV3
