Security Command Center is Google Cloud's centralized vulnerability and threat reporting
service. Security Command Center helps you strengthen your security posture by
evaluating your security and data attack surface; providing asset inventory and
discovery; identifying misconfigurations, vulnerabilities and threats; and helping you mitigate and
remediate risks.
Go to the Security Command Center product page for more.
