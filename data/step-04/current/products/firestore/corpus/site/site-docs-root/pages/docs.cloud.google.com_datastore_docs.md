Firestore in Datastore mode documentation
Read product documentation
Firestore in Datastore mode is a NoSQL document database built for automatic scaling,
high performance, and ease of application development.
While the Datastore mode interface has many of the same features as
traditional databases, as a NoSQL database it differs from them in the way it
describes relationships between data objects.
