# Generative knowledge assist | Agent Assist | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/agent-assist/docs/generative-knowledge-assist

Generative knowledge assist provides answers to your agent&#x27;s questions based on information in documents you provide. You can specify your domain name or upload documents for a flow-based data store agent or a playbook-based data store agent.
