The first step in this tutorial is to create an agent.
Rather than building an agent from scratch,
you will import a banking
prebuilt agent .
Using a prebuilt agent will accelerate your progress for this tutorial.
To import the prebuilt agent:
Go to the Dialogflow ES console .
Click Prebuilt agents in the left sidebar menu.
Hover your mouse over the Banking prebuilt agent.
Click Import .
A dialog box appears.
Provide a name for your agent.
Either create a new GCP project or choose an existing one.
Click Create Agent From Template .
In the next step,
you will create a webhook service for this agent.
