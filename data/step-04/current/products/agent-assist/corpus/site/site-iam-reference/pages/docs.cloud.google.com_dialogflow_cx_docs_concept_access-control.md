# Access control | Dialogflow CX | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/dialogflow/cx/docs/concept/access-control

The Google Cloud console is used to grant IAM roles to principals, while the Conversational Agents console is used to grant Dialogflow CX agent roles to principals. Dialogflow CX agent roles are convenient predefined roles defined by Dialogflow CX that restrict access to one agent or the child resources of a specific agent.
