# Access control | Dialogflow ES | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/dialogflow/es/docs/access-control

You can control access using either Identity and Access Management (IAM) or the Dialogflow Console. The Dialogflow Console provides the Agent Admin role to the user that created the agent.
