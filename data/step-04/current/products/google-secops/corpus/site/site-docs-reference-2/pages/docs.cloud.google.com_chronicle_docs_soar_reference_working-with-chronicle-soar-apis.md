Google SecOps SOAR APIs
Supported in:
SOAR
Caution: Legacy APIs can have a performance impact.
Legacy Google SecOps SOAR APIs are deprecated and will be fully
non-functional in September 2026 .
Continued use of these APIs can lead to performance issues or unexpected
behavior within the platform.
You must migrate all legacy API calls to the new, more efficient
Chronicle APIs immediately to ensure platform stability and performance.
For more information, see the
API migration guide . Note: If you've migrated SOAR to a customer managed project and have the Chronicle API enabled, the SOAR APIs are part of
Chronicle API.
For more information, see Migrate to Google Cloud .
The Google Security Operations SOAR APIs are documented in Swagger (pre-migration). Google SecOps supports only the APIs that are documented in the Swagger page, which you can access using the following URL:
https://{instance_url}/swagger/index.html
Note: The Google Cloud Armor settings allow 900 API queries over a one
minute timespan per IP address.
