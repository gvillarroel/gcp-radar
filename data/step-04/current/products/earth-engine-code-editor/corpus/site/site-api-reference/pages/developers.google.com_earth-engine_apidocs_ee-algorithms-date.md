ee.Algorithms.Date
Stay organized with collections
Save and categorize content based on your preferences.
Creates a Date.
Usage Returns ee.Algorithms.Date(value, timeZone ) Date Argument Type Details value Object A number (interpreted as milliseconds since 1970-01-01T00:00:00Z), or string such as '1996-01-01' or '1996-001' or '1996-01-01T08:00'. timeZone String, default: null The time zone (e.g., 'America/Los_Angeles'); defaults to UTC.
