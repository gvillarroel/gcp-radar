This package is not the recommended entry point to using this client library!
For this library, we recommend using com.google.devtools.cloudtrace.v2 for new applications.
Stub Package Implications
This package is a a base stub class. It is for advanced usage and reflects the underlying API directly.
We generally recommend using the non-stub, latest GA package, such as com.google.devtools.cloudtrace.v2 . Use with caution.
