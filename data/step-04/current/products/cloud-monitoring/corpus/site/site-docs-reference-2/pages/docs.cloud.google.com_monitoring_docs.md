Cloud Monitoring documentation
Read product documentation
Cloud Monitoring collects metric data and provides tools that let you monitor
and visualize how your applications and services are performing.
To collect metrics data from your Compute Engine instances,
create a VM Extension Manager policy that automatically installs and maintains
the Google Cloud Observability Ops Agent across your fleet of VMs.
To collect metrics from on-premises and hybrid-cloud systems and applications,
we recommend using Bindplane .
Go to the Cloud Monitoring product page for more.
