Google Cloud NetApp Volumes provides support based on your Cloud Customer Care
tier. While all Google Cloud customers, including NetApp Volumes
customers, receive access to documentation, community support, and support for
billing issues, additional technical support for NetApp Volumes
isn't offered within the basic support services tier.
To learn more about Google Cloud's customer support tiers and service offerings,
refer to the Cloud Customer Care overview page .
You can also check which support tier your subscription currently offers by
visiting your Google Cloud console dashboard .
