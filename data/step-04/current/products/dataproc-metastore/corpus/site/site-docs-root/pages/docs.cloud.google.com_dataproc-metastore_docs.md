Dataproc Metastore is a fully managed Apache Hive metastore
(HMS) that runs on Google Cloud. An HMS is the established standard in the open source big data
ecosystem for managing technical metadata.
Dataproc Metastore is highly available, autohealing, and serverless.
It helps you manage your data lake
metadata and provides interoperability between the various data processing engines
and tools you're using.
