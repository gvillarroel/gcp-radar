The forecasting components let you compose
tabular data forecasting pipelines with AutoML.
Forecasting models predict a sequence of values.
For more information, see Forecasting with AutoML .
The Google Cloud SDK includes the following operators related to tabular data forecasting pipelines:
ForecastingPrepareDataForTrainOp
ForecastingPreprocessingOp
