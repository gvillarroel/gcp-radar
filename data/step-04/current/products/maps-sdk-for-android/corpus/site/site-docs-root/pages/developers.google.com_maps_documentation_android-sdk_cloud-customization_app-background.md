To use cloud-based maps styling on Android, you must use the
latest renderer for Maps SDK for Android.
Follow these instructions .
Availability: This feature is visible on
Android, iOS, Maps JavaScript API, and Maps Static.
You can change the background color of the Map container. This color shows
before the tiles load.
Set the app background color
In the Map features panel, select the settings
gear icon to open the Map Settings menu.
Set the app background color by using the color picker or entering a Hex
string. When you set the color, the tiles reload to show the chosen
background color.
