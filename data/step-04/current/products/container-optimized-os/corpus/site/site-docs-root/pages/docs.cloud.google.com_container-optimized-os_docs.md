Container-Optimized OS from Google documentation
Read product documentation
Container-Optimized OS is an operating system image for your Compute Engine
VMs that is optimized for running Docker containers. With Container-Optimized OS, you can
bring up your Docker containers on Google Cloud Platform quickly, efficiently, and securely.
Container-Optimized OS is maintained by Google and is based on the open source
Chromium OS project.
