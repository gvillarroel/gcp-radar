Page Summary
outlined_flag
The Google Navigation SDK provides widespread coverage for traffic, driving directions, and walking directions globally.
Coverage for two-wheeled vehicle directions, biking directions, speed limits, and traffic signals is more limited and varies by region.
Users should refer to the Google Maps Platform Coverage Details for the most up-to-date information as data is subject to change.
Google One VPN is broadly available, with most countries supporting all three VPN protocols without requiring Google One Premium.
A small subset of countries have limited VPN protocol support or require Google One Premium for advanced features.
The Google Maps Platform team is constantly working to improve country and region
coverage for our API services. The following table shows the latest feature coverage
for the Navigation SDK.
Note: Coverage for some of the features of the Navigation SDK
differs from that of other Google Maps Plaform products. For more information, see
Google Maps Platform Coverage Details .

Note: Some real-time disruption features, such as police
presence and mobile speed cameras, are not available in all countries where real-time disruptions
are available.
