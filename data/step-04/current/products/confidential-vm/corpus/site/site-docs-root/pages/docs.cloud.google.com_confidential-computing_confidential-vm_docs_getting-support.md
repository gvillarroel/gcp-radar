The following support channels are available for Confidential VM.
Get a Google support package
Google Cloud offers different support packages to meet different needs, such as
24/7 coverage, phone support, and access to a technical support manager. For
more information, see Cloud Customer Care .
Ask a question on Stack Overflow
Ask a question about Confidential VM on
Stack Overflow ,
using the tag confidential-vm . This tag not only receives responses from
the Stack Overflow community, but also from Google engineers, who monitor the
tag and offer unofficial support.
Discuss Confidential VM on Slack
You can also visit the Google Cloud Slack community
to discuss Confidential VM and other Google Cloud products. If you haven't
already joined, use this form to sign up .
For Confidential VM, join the #confidential-compute
channel.
Send feedback
To file a bug or a feature request,
create a new Confidential VM issue .
If you have questions or feedback about Confidential VM, contact
confidential-compute@google.com .
