EXPONENT
Calculates the value of an existing number raised to the specified power.
EXPONENT(value)
Power value.
Value of the number raised to the specified power.
Supported data type
The EXPONENT function supports the following data types:
Double
Integer
Example: Find the value of an integer raised to the power of 3
Sample data : $var1$ = 5
Usage : $var1$.EXPONENT(3)
Raise var1 to the power of 3.
Output : 125
