Accessibility features of Cloud Workstations
Stay organized with collections
Save and categorize content based on your preferences.
This page outlines Code OSS for Cloud Workstations accessibility features
that you can use from Cloud Workstations. Code OSS for Cloud Workstations is based
on the open source Code-OSS
For more information about Google Cloud accessibility resources, see
Google Cloud accessibility .
For additional information about enabling screen reader features in the
Google Cloud CLI, see Enabling accessibility features .
Keyboard navigation
To navigate and customize accessibility features, use the following keyboard
shortcuts:
If you use JAWS, press Insert+z to toggle the virtual cursor
on and off.
To navigate to the next focusable element on the page, press Tab .
Terminal accessibility features
To navigate and customize the terminal, use the following features when using
the terminal:
To go to the previous page, press Shift+PageUp .
To go to the next page, press Shift+PageDown .
Customize color themes and font sizes
To change the color theme, navigate to File >
Preferences > Color theme and then select the color
theme you prefer.
To change the terminal font size, navigate to File >
Preferences > Settings , select
Features > Terminal , and then change the font size.
