The Cloud Natural Language API supports a variety of languages.
These languages are specified within a request using the optional language
parameter. Language code parameters conform to
ISO-639-1 or
BCP-47 identifiers.
If you do not specify a language parameter, then the language for
the request is auto-detected by the Natural Language API.
The list of supported languages differs depending on the feature.
