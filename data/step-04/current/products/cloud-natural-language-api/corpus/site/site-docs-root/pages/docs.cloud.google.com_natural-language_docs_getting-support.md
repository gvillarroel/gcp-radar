Getting support
Stay organized with collections
Save and categorize content based on your preferences.
If you have additional need for technical support, you have a number of options
listed below.
Get a Google support package
Google Cloud offers different support packages to meet different needs, such as 24/7
coverage, phone support, and access to a technical support manager. For more information,
see Cloud Customer Care .
Get support from the community
Ask a question on Stack Overflow
Ask a question about the Cloud Natural Language API on
Stack Overflow .
Please use the tag google-cloud-nl for questions about the Cloud Natural Language API.
This tag not only receives responses from the Stack Overflow
community, but also from Google engineers, who monitor the tag and offer
unofficial support.
Ask a question
See a list of all questions
Discuss Cloud Natural Language API and get updates
Join the
cloud-nl-discuss
Google group to discuss the Cloud Natural Language API and receive Cloud Natural Language API
announcements and updates.
You can also visit the Google Cloud
Slack community to discuss
Cloud Natural Language API and other Cloud Natural Language API products. If you haven't
already joined,
use this form to sign up .
For Cloud Natural Language API, join the
#ai-nlp
channel.
File bugs or feature requests
From the Cloud Natural Language API documentation, click "Send feedback" near the
top right of the page. This will open a feedback form. Your comments will be
reviewed by the Cloud Natural Language API team.
