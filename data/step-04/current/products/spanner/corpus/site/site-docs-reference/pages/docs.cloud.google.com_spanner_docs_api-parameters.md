System Parameters .
Performance tips
We strongly recommend using the client libraries
for workloads that involve relatively high queries per second, relatively small
requests or responses, and where you are concerned about latency or throughput.
The libraries have substantially lower overhead than REST or JSON because they
are built on top of the gRPC
interfaces. There are cases where using the REST API makes sense, and you want
to optimize for fewer bytes transferred or smaller JSON responses.
