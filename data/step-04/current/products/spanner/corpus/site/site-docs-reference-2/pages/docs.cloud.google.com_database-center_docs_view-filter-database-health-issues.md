In Database Center, you can filter database issues and view an
aggregation of recent health issues. Use these tools to manage information that
helps you troubleshoot your database fleet health.
Before you begin
Ensure Database Center is set up for your
organization .
Filter database health issues
To specify which database health issues you care about and the thresholds you
consider relevant, follow these steps:
Go to the Database Center page in the Google Cloud console.
Database Center
Click All Resources .
Click Filter .
In the Properties drop-down, enter a property name, like
Country:United States . To refine your query, enter a value like Or
and another property name like Country:Canada .
Database Center displays only those health issues related to
the property name.
Click Show Resource Details to show database resource details. Click Hide Resource Details to hide database resource details.
Click a health issue to learn health issue details, including recommended
resolutions.
Click Go to Resource to display detailed information about the database resource experiencing the database health issue.
You can also filter database health issues by clicking one of the database
health categories, like Availability Configuration , Data Protection ,
Security , Industry Compliance , Performance and Capacity , and
Cost . These fields only appear if there are database issues with database
resources in those categories.

To view recent health issues that occurred in a category in the last seven days, follow these steps:
Go to the Database Center page in the Google Cloud console.
Database Center
Click Overview .
Filter the database health issues so the
database issues you want to see are visible in the
Database Center dashboard.
In Fleet issues , you can see how many new issues were found in the last
seven days for each category.
Click View to see the health issues that were found. If no new issues
were found for a category, then the section for that category that shows the
number of new issues and the View button isn't displayed.
For each health issue in the list of recently found health issues, click the
button in the Issue column to learn more.
