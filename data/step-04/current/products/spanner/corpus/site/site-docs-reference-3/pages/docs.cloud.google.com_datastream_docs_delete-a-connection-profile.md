If you no longer need a connection profile, then delete it.
Note: If a connection profile is assigned to any streams, then you can't delete the profile. To delete the connection profile, you must first delete each stream that's associated with the profile. To see which streams are using the connection profile, you can view detailed information about the profile .
Delete a connection profile
Go to the Connection profiles page in the Google Cloud Console.
Go to the Connection profiles page
Click the connection profile that you want to delete.
In the Connection profile details page, verify that the connection profile isn't being used by any streams. If it is, then delete the streams .
Click DELETE .
In the dialog, click DELETE .
