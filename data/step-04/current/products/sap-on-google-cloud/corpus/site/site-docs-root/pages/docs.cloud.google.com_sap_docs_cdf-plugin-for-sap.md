Cloud Data Fusion integrations for SAP
Stay organized with collections
Save and categorize content based on your preferences.
You can integrate your SAP data with your data repositories on
Google Cloud by creating a data pipeline with Cloud Data Fusion
and one of the following plugins :
SAP Ariba Batch Source
This plugin enables bulk data transfers from SAP Ariba with
Cloud Data Fusion. It extracts data from the reporting facts provided in
the SAP Ariba Source. For more information, see the
SAP Ariba Batch Source reference .
SAP BW Open Hub Batch Source
This plugin lets you use SAP as a source for batch-based and delta-based data
extraction in Cloud Data Fusion through the BW Open Hub Service. For more information, see the
SAP BW Open Hub Batch Source plugin overview .
SAP OData
This plugin enables batch-based data extraction in Cloud Data Fusion
using the
Open Data Protocol (OData) . You
can configure and execute data transfers from SAP OData Catalog Services without
any coding. For more information, see the
SAP OData plugin overview .
SAP ODP
This plugin enables bulk data integration from SAP applications with
Cloud Data Fusion. You can configure and execute bulk and delta data transfers from SAP DataSources without any coding. For more information, see
the
SAP ODP plugin overview .
SAP SLT Replication
This plugin lets you replicate your data continuously and in real time from
SAP sources into BigQuery. You can configure and execute bulk
data transfers from SAP Systems without any coding. For more information, see
the SAP SLT Replication plugin overview .
SAP SuccessFactors Batch Source
This plugin lets you extract data from any entity within the SAP SuccessFactors Employee Central module. For more information, see the
SAP SuccessFactors Batch Source reference .
SAP Table Batch Source
This plugin enables bulk data integration from SAP applications with
Cloud Data Fusion. You can configure and execute bulk data transfers from SAP tables and views without any coding. For more information, see the
SAP Table Batch Source plugin overview .
Sample pipelines
To help you get started on your end-to-end business processes and analytics,
sample pipelines, called accelerators, are available for the following business
processes:
Order to cash
Procure to pay
For more information, see Cloud Data Fusion .
