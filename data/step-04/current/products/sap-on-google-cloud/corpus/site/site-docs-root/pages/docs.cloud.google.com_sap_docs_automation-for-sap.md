Overview of automating SAP deployments on Google Cloud
Stay organized with collections
Save and categorize content based on your preferences.
This guide shows you how you can automate the deployment of select SAP solutions
and supporting databases on Google Cloud, including the infrastructure
that they need in order to run on Google Cloud, such as
Compute Engine virtual machine (VM), the operating system, persistent
storage, and more.
Automation options
You can automate SAP deployments on Google Cloud using the following options:
Terraform (Recommended): provides declarative
configuration files to provision resources. For more information, see
Automating SAP deployments on Google Cloud with Terraform .
Workload Manager - Guided Deployment Automation : lets
you configure and deploy SAP systems on Google Cloud. Post
deployment, this tool lets you generate Terraform and Ansible files that
you can export for further customization or use in an existing deployment
pipeline. For more information, see
About Guided Deployment Automation .
