Planning for SAP NetWeaver on Google Cloud
SAP NetWeaver planning guide
Discusses considerations for planning an SAP NetWeaver deployment on
Google Cloud. The guide discusses services used in Google Cloud for
NetWeaver, their strengths and limitations, various architectures,
networking, and security considerations, among others.
