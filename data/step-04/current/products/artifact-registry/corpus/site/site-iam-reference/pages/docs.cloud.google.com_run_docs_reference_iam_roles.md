# Cloud Run IAM roles | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/run/docs/reference/iam/roles

To get the permissions that you need to deploy services or revisions, you or your administrator must grant IAM roles to the deployer account on the following resources: Cloud Run Developer (roles/run.developer) on the Cloud Run service · Artifact Registry Reader (roles/artifactregistry.reader) on the Artifact Registry repository of the container images of the service
