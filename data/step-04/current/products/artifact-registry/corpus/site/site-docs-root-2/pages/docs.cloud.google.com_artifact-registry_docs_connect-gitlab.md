The GitLab on Google Cloud integration simplifies authentication and
authorization to Google Cloud for GitLab pipelines, and uses GitLab and Google
CI/CD components.
If you use the Free, Premium, or Ultimate tier of GitLab.com for continuous
integration, you can connect your Docker format Artifact Registry
repository to GitLab and streamline your deployment to Google Cloud runtimes.
Artifacts in your GitLab container registry can be pushed to your
Artifact Registry repository, and viewed in both GitLab and Artifact Registry.
Metadata for each artifact can be accessed in the Google Cloud console.
To connect your Artifact Registry repository to GitLab, follow the steps in
Google Artifact Management on GitLab.
To learn more about the GitLab on Google Cloud integration:
Try the end to end tutorial on GitLab .
