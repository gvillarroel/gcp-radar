coverage, phone support, and access to a technical support manager. For more information,
see Cloud Customer Care .

Bugs and defects
Example bug or defect: I am unable to push a container image
Check existing resources to address your issue. Search for existing Artifact Registry issues in the
issue tracker .
If you cannot find a resolution for your issue, open a new issue and include
the following information:
What steps will reproduce the problem?
What is the expected output? What do you see instead?
What version of Docker are you using? On what operating system?
Any additional information that can help with diagnosing the issue.
File a feature request
Example: Artifact Registry should add feature X
Search for existing requests for the same Artifact Registry feature in the
issue tracker .
You can add a comment to an existing feature request or add yourself to the
CC list to track the progress of the request.
If you create a new feature request, include the following information:
What is the desired behavior of the feature? (Be specific!)
If relevant, why are current approaches or workarounds insufficient?
If relevant, what new use cases will this feature enable?
Documentation feedback
Example: Documentation for X is out of date
If you run into issues while using the documentation, have general feedback,
or want to make a suggestion, use the documentation feedback mechanism. From
any page in the Artifact Registry documentation, click the Send feedback
link next to the page title. This will open a feedback form. Provide
the following information (if applicable):
What URL are you reporting?
What was inaccurate?
General comments or suggestions
Your comments will be reviewed by the Artifact Registry team.
Production issues
Example: I cannot deploy images to a repository
If you have a paid support contract, contact Google directly .
You can file a
production issue report for
your application. Google reads these reports but cannot reply individually.
Operational support for individual applications is not provided via the issue
tracker.
