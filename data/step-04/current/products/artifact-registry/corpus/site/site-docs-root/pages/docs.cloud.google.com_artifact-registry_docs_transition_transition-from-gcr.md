# Transition from Container Registry | Artifact Registry | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/artifact-registry/docs/transition/transition-from-gcr

Artifact Registry extends the capabilities of Container Registry with the following features: Repository-level access control. Hosting artifacts in regions to reduce latency and data transfer costs, and to comply with data residency requirements. Streaming images to Google Kubernetes Engine and Google Cloud Serverless for Apache Spark to reduce workload startup times.
