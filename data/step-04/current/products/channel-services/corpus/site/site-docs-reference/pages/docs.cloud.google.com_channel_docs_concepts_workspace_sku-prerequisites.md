Terminology
SKU : Each SKU represents an entity that will be provisioned when an
offer is purchased. An offer maps to a single SKU. Offers reference the
SKU that a reseller is allowed to sell. You use offer IDs when creating an
entitlement.
Prerequisite SKU : SKUs sometimes have prerequisite SKUs that need to
be met for entitlement create execution. In other words, the customer must
already have purchased the prerequisite SKU. If there are multiple prerequisites
then any of them can be purchased.
