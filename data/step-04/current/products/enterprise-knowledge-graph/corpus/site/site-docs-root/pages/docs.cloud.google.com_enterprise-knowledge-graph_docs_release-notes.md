This page documents production updates to Enterprise Knowledge Graph. Check this page for
announcements about new or updated features, bug fixes, known issues, and

October 10, 2022
Announcement
Enterprise Knowledge Graph is available in Preview .
Feature
Enterprise Knowledge Graph API has been updated with the following features:
Support to cancel and delete an entity reconciliation job
Support for three entity types : Organization , LocalBusiness , and Person .
Entity linking to Google Knowledge Graph is available for Organization and LocalBusiness entity types.
May 24, 2022
Feature
Enterprise Knowledge Graph API has been updated with the following features:
Added a model that is fine tuned for the Organization type.
For entity reconciliation jobs, you can select different models by name and version tag .
Increased geocoding efficiency, reducing time to process results.
May 02, 2022
Feature
Enterprise Knowledge Graph has been updated with the following features:
You can list all entity reconciliation jobs.
Added additional jobs states to help you understand which stage the job is currently in.
March 10, 2022
Feature
Enterprise Knowledge Graph has been updated with the following advanced options :
The entity reconciliation API supports outputting stable cluster IDs across different runs.
You can select the clustering algorithm for reconciliation.
You can enable geo enrichment and separation for better location-related clustering.
