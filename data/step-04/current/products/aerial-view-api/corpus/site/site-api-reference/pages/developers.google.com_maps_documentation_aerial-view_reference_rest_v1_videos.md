Page Summary
outlined_flag
This resource has no persistent data associated with it.
It provides methods to fetch video and video metadata given an address or videoId.
It allows adding an address to a rendering queue for video generation.
Resource
Methods
Resource
There is no persistent data associated with this resource.
Methods
lookupVideo
Fetches a video given its address or videoId.
lookupVideoMetadata
Fetches metadata for a video given its address or videoId.
renderVideo
Adds an address to the renderer's queue if a video hasn't already been rendered.
