Some configuration tasks can only be performed on the AppNeta instance created
when you enable Cloud Network Insights. You don't need separate login credential; access
is handled through Google Single Sign On (SSO).
If you want to configure access to the AppNeta API, see Access the AppNeta API .
Before you begin
You can only access your AppNeta instance after you have deployed a Monitoring
Point .
Authenticate using Google SSO
To perform tasks located in AppNeta, you must authenticate through the Google Cloud console.
In the Google Cloud console, navigate to Network Intelligence >
Cloud Network Insights >
Monitoring Points .
Go to Cloud Network Insights
Open the more_vert
Actions menu on any active Monitoring Point.
Select Open in AppNeta .
Sign in to AppNeta using Google SSO. You might be prompted to authorize
AppNeta to read Google Cloud data.
