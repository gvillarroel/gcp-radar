This page describes Google Cloud CLI commands and APIs that can be used with
Cloud Network Insights and links to Broadcom AppNeta APIs that can be used in conjunction
with Google Cloud CLI APIs.
Cloud Network Insights is possible with a close partnership with Broadcom AppNeta.
As such, both Google Cloud APIs and Broadcom AppNeta APIs can be used to
perform actions with Cloud Network Insights.
Google Cloud API references
Cloud Network Insights uses APIs from the Network Management APIs through the
network-insights resource.
You can perform actions such as the following using the Network Management APIs:
Get Monitoring Point information
Create and delete monitor providers
Download installation scripts
Network Management v1alpha1 reference
Download installation scripts, generate access tokens, and get information
about Monitoring Points, network paths, and web paths with the
v1alpha1 version of the Network Management API.
AppNeta API references
Broadcom's AppNeta API makes data collected and generated by AppNeta available
for analysis, reporting, and presentation in third-party systems. As well as
collecting system data, the API also provides the ability to configure and
control AppNeta.
For more information, see the AppNeta API documentation.
