# Supported modules | Cluster Toolkit | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/cluster-toolkit/docs/support-matrix

Cluster Toolkit uses a cluster blueprint to define a deployment. For each blueprint, you can use the deployment_groups setting to define a set of modules that customize your deployment.
