# Cluster Toolkit release notes | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/cluster-toolkit/docs/release-notes

Cluster Toolkit version v1.75.0 is available. This release graduates the cloud-storage-bucket module to the core collection of modules and adds integration tests for TPU v6e and TPU 7x. This version also enables Spot VM testing for A3 Ultra instances and provides ML dependencies and dual NIC guidance for G4 machines.
