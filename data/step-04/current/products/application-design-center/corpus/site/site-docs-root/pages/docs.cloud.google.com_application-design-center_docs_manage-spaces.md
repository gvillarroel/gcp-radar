# Manage and assign spaces | Application Design Center | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/application-design-center/docs/manage-spaces

In the app-enabled folder where you created your initial space, create a descendant app-enabled folder. For more information, see Managing applications in a folder. In the Google Cloud console, select the descendant app-enabled folder. Go to the App Design Center Overview page.
