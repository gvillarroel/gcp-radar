This document shows the various ways that you can get support for Cloud Asset Inventory.
Get a Google support package
Google Cloud offers different support packages to meet different needs, such as
24/7 coverage, phone support, and access to a technical support manager. For
more information, see Cloud Customer Care .
Feedback on Cloud Asset Inventory
For feedback, bug and error reports, and feature requests, send an email to
gcp-asset-inventory-and-search-feedback@googlegroups.com .
If you're reporting a bug or error, include the following information:
What happened? What did you expect to happen?
How can we reproduce the problem?
Announcements and updates
Join the Cloud Asset Inventory Customers
Google Group to receive Cloud Asset Inventory announcements and updates.
