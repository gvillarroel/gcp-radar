Get a Google support package
Google Cloud offers different support packages to meet different needs, such as 24/7
coverage, phone support, and access to a technical support manager. For more information,
see Cloud Customer Care .
Get support from the community
Ask a question on Stack Overflow
Ask a question about Cloud Tasks on
Stack Overflow .
Use the tag google-cloud-tasks for questions about
Cloud Tasks. This tag not only receives responses from the
Stack Overflow community, but also from Google engineers, who monitor the tag
and offer unofficial support.
Discuss Cloud Tasks
Request to join the
Cloud Tasks Insiders Program
where you can discuss Cloud Tasks, gain access to pre-release
features, and provide input on the product roadmap.
You can also visit the Google Cloud
Slack community to discuss
Cloud Tasks and other Google Cloud products. If you haven't
already joined,
use this form to sign up .
File bugs or feature requests
Keep track of Cloud Tasks issues on the
issue tracker .
You can also submit product or documentation issues by clicking the
"Send feedback" link near the top right of this page. This opens a feedback form.
The comments you submit will be reviewed by the Cloud Tasks team.
