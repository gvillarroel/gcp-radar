outlined_flag
Different enums are used to extract the value of a conversion activity.
COUNTING_METHOD_UNSPECIFIED indicates the action is not specified.
CONVERSIONS_COUNT provides the count of conversions for the activity.
SALES_VALUE shows the sales revenue related to the conversion activity.
The method for extracting the value of a conversion activity.
Enums
COUNTING_METHOD_UNSPECIFIED
The action is not specified.
CONVERSIONS_COUNT
The count of conversions associated with the conversion activity.
SALES_QUANTITY
The number of sales items associated with the conversion activity.
SALES_VALUE
The sales revenue associated with the conversion activity.
UNIQUE_COUNT
The count of unique conversions associated with the conversion activity. Only one conversion can be counted per impression.
