Page Summary
outlined_flag
Age range targeting options include broad age brackets like 18-24, 25-34, up to 65+.
There are also more granular age range options available, such as 18-20 or 21-24, which are only supported for specific ad types like YouTube Programmatic Reservation line items.
Default and unknown age range options exist but do not represent real age ranges for targeting.
Possible age range targeting options.
