Google Cloud VMware Engine is a fully managed service that lets you run the VMware platform in
Google Cloud. This service helps you to retain operational continuity with your existing VMware
environments, and enables seamless integration with Google Cloud services. It also lets you
benefit from a cloud consumption model and lower total cost of ownership.
Go to the Google Cloud VMware Engine product page for more.
