Data protection recommendations
Customers are responsible for creating and implementing a data protection plan
for their workloads. We recommend using a backup and Disaster Recovery (DR)
solution for your workloads running in VMware Engine. For more
information on customer responsibilities, see VMware Engine shared responsibility model .
If your workload requires a zero Recovery Point Objective (RPO) and zero
Recovery Time Objective (RTO), consider using a VMware Engine
stretched cluster .
Stretched clusters are available in a limited number of regions. Confirm
availability in your selected region by reviewing the release notes or
contacting [Cloud Customer Care][gcp support].
VMware Engine has validated Google Cloud Backup and Disaster Recovery
(GCBDR) and several other popular third-party data protection solutions. Choose
a certified solution from this list based on your workload needs. For more
information, see Workload VM backup solutions .
