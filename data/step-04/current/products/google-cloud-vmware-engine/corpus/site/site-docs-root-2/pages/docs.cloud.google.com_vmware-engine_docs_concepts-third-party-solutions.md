Support for Oracle workloads in Google Cloud VMware Engine
Google Cloud VMware Engine provides a fully managed VMware platform with VMware
vSphere, vCenter, vSAN, and NSX, running on Google-provided enterprise-grade
hardware infrastructure. Oracle supports Oracle products on VMware virtualized environments .
My Oracle support portal note 249212.1
states that Oracle customers with an active support contract and running
supported versions of Oracle products will receive assistance from Oracle when
running those products on VMware virtualized environments.
The compatibility matrix on the Oracle support portal shows
Oracle products certified by Oracle by using operating system support. Oracle
also certifies its own operating systems
for the VMware ESXi hypervisor used in Google Cloud VMware Engine.
The VMware vSphere platform is fully compatible with Oracle Linux, SUSE Linux,
Red Hat Linux, Windows Server, and other operating systems certified for
Oracle products. For more information, see the
VMware Compatibility Guide for Guest OS .
VMware provides support for Oracle database technical issues on VMware vSphere
platforms. For information about the support and subscription contract, see the
VMware Oracle Support Policy .
Google Cloud support extends the support described above to
VMware Engine customers. Google is committed to working with VMware
and Oracle to support Oracle workloads running in VMware Engine.
You are fully responsible for ensuring that you comply with Oracle licensing and
technical support on Google Cloud VMware Engine.
