Advanced API Security helps you monitor and manage the security posture of your APIs. This page
provides an overview of the Advanced API Security functionality, which differs depending on
where the Advanced API Security addon is enabled.
Note: Use of Advanced API Security does not affect your runtime traffic or
negatively impact the runtime performance of your APIs.
Use Advanced API Security for assessment, monitoring, and actions on your Apigee
and Apigee hybrid instances
When used with your Apigee or Apigee hybrid instance, Advanced API Security provides
comprehensive protection by continuously monitoring for security threats like malicious client
attacks and API abuse. It analyzes API traffic to detect suspicious requests and offers tools for
blocking or flagging them. The service also assesses your API configurations against security
standards, providing recommendations for improvement to enhance your security posture.
In order to use this functionality, enable the Advanced API Security addon from your Apigee
project . For enablement and usage instructions, see
Overview of Advanced API Security from your Apigee instance .
Use Advanced API Security to perform risk assessments on multiple Apigee
organizations and gateways
You can use Advanced API Security to perform risk assessments across multiple Apigee
organizations and gateways, including Apigee, Apigee hybrid, and Apigee Edge.
In order to use this functionality, enable the Advanced API Security addon from your
API hub . For enablement and usage instructions, see
Advanced API Security for multi-gateway projects .
Choose the right Advanced API Security features for your needs
If you want the multi-gateway risk assessment functionality that you can apply to multiple Apigee
gateways, including on Apigee Edge, enable the Advanced API Security add-on
from your API hub instance. For details, see
Use Advanced API Security to perform risk assessments on multiple Apigee organizations and
gateways .
Otherwise, use the full Advanced API Security feature suite on your Apigee or Apigee hybrid instances
by enabling the Advanced API Security add-on from your Apigee instance. For details, see the
Use Advanced API Security for assessment, monitoring, and actions on
your Apigee and Apigee hybrid instances .
