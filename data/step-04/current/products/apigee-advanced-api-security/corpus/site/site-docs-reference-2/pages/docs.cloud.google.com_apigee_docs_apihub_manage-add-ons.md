This page
applies to Apigee and Apigee hybrid .
Add-ons are optional, standalone features and services that you can use to enrich the way you manage and secure your API data in API hub. The Add-on management page lets you enable, disable, and manage the configurations of your add-ons.
The following table lists the available add-ons and their pricing:
Add-on
Pricing
Description
Specification linter
Free
Specification linter helps you to validate your OpenAPI specifications to ensure that your APIs meet your team style guidelines. For more information, see Validate API specs using the specification linter .
Specification boost
Free
Specification boost is an AI-powered add-on that lets you automatically enhance the readability and discoverability of your API specifications in API hub. For more information, see Specification boost add-on .
Semantic search
Free
Semantic search helps you to find the details of an API resource quickly using natural language. For more information, see Search APIs using semantic search .
