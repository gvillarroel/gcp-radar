Personalized Service Health documentation
Read product documentation
Personalized Service Health is a one-stop view of Google Cloud service health
events , where you can manage active events and review past events. It identifies how
Google Cloud service health events are relevant to your project and filters out events that
are not relevant. Personalized Service Health provides the following options to access service health events:
View active and past Google Cloud incidents that are relevant to
your project in the Service Health dashboard in the Google Cloud console.
Request service health events using an API on a per-project or per-organization
basis.
Configure alerts or export logs through Cloud Logging across
channels such as
Cloud Monitoring channels
including email, Pub/Sub, webhooks, Slack, and PagerDuty.
Go to the Personalized Service Health product page for more.
