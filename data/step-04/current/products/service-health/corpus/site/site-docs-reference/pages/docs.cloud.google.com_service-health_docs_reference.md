You can request service health events that are relevant to your Google Cloud
project using the Service Health API. This section explains how to list and view
events in Personalized Service Health using the REST API.
Example use cases for the Service Health API include:
List service health events that might be impacting or have impacted Google Cloud services in
your Google Cloud project.
List assets under an organization that may be affected by an event.
Filter events based on event state (active versus closed).
Get service health event details such as event description, start/end time,
and updates.
You must enable the Service Health API for the project before using the API.
