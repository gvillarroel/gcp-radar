Setting up on Apps Script
Stay organized with collections

Error Reporting exception grouping is automatically enabled for
Google Apps Script logs. No additional setup is required beyond enabling
exception logging in Apps Script. For details on this integration, read the
Apps Script documentation .
If you want to view error and exception data for your application in the
Google Cloud console, see
Viewing errors .
Note : If you see the message "Set up Error Reporting" on the Error Reporting page,
then your Google Cloud project has no error groups to display.
