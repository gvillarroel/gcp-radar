Enable or disable Cloud Data Fusion

This page explains how to enable or disable the Cloud Data Fusion API
for your Google Cloud project.
For information about Service Usage on Google Cloud,
see Enabling and disabling services .
Before you begin
Before using Cloud Data Fusion, you must
create a Google Cloud project
and enable billing .
To enable and disable the Cloud Data Fusion API, you must have
the administrator permission. For more information about roles and permissions,
see Access control .
Enable Cloud Data Fusion
You can use an existing project with Cloud Data Fusion or create a new
one. If you're using an existing project, you need to enable the
Cloud Data Fusion API.
To create a project and enable the Cloud Data Fusion API:
In the Google Cloud console,
select or create a project .
Make sure that
billing is enabled
for your project.
Go to the
Cloud Data Fusion API overview
page.
Click Enable .
Disable Cloud Data Fusion
To avoid additional charges, complete the following steps for each instance
before you disable the Cloud Data Fusion API.
When you disable the Cloud Data Fusion API,
instances become unusable within an hour of service deactivation—unless
you re-enable the API.
If you re-enable the API, you're billed for the Service Usage that
occurs while the Cloud Data Fusion service is deactivating.
Delete your instance .
Wait until the following occurs:
All operations such as creating, updating, or deleting an instance have completed.
All pipelines are no longer running.
To disable the Cloud Data Fusion API:
In the Google Cloud console, select the project to disable the
Cloud Data Fusion API in.
Go to the Cloud Data FusionAPI overview
page.
Click Manage .
Click Disable API .
