Cloud Monitoring supports the metric types defined by
Google Cloud services. The following pages display the
metric types for a subset of Google Cloud services. Each page lists
services in alphabetical order. The name of a metric type identifies the
associated service. For example, metric types whose name starts with
compute.googleapis.com/ are assigned to the compute service:
Metric types: A through B
Metric types: C
For Cloud Run functions that rely on the
run.googleapis.com API, the metric types are generated by
Cloud Run. For a list of metric types, see
run .
Cloud Endpoints : APIs managed by Cloud Endpoints write
serviceruntime metrics against the
api
monitored-resource type.
The prefix container.googleapis.com is for older Google Kubernetes Engine
metric types. For newer GKE metric types, see the
kubernetes.io metrics .
Metric types: D through H
Metric types: I through O
The VM Manager generates metrics with the osconfig.googleapis.com
prefix.
