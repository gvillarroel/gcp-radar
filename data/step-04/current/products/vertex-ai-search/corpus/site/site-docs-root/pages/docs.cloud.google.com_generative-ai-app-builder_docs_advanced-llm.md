For structured, unstructured, and advanced website search, generative responses
include the following advanced LLM features:
Search summaries using the search method
Search answers using the answer method
Search with follow-ups using the answer or the
converse method
This page describes how to turn generative responses
on or off for an app.
Before you begin
If you're turning on generative responses, be aware of
additional costs that this can incur. See Pricing .
When you're turning off generative responses for an app, make sure the app
doesn't require these features. For example, if you have deployed a search widget that
uses search with follow-ups, Google recommends that you change the search type
to "single-turn without summarization" before turning off generative responses.
After turning generative responses off, all features that require advanced LLM
features stop working in your app within a few minutes.
Key Terms: answer versus summary : Answers and
summaries are indistinguishable. However, answers
are generated by the answer
method and summaries are generated by the search method.
Turn generative responses on or off
To turn generative responses on or off, follow these steps:
In the Google Cloud console, go to the AI Applications page.
AI Applications
Click the app from the Name field.
In the navigation menu, click Configurations .
Click the Response Settings tab.
In the Generative Responses pane, click the toggle on or off.
Click Save . Your changes take place within a few minutes.
