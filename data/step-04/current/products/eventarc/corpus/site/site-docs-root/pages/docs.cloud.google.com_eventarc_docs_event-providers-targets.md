Depending on the variant of Eventarc that you are using, specific event
providers and destinations are supported.
Eventarc Advanced
Events are delivered from an event provider or source to an
Eventarc Advanced bus and through an
Eventarc Advanced pipeline to a specified event destination. For
more information, see
Event providers and destinations .
Eventarc Standard
Supported events are routed from an event provider (the source) to an event
destination (the target), also known as the event consumer or receiver. For more
information, see
Event providers and destinations .
