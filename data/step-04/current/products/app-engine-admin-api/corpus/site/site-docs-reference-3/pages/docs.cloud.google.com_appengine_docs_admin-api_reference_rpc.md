Provisions and manages developers' App Engine applications.
Service: appengine.googleapis.com
The Service name appengine.googleapis.com is needed to create RPC client stubs.
google.appengine.v1.Applications
Methods
CreateApplication
Creates an App Engine application for a Google Cloud Platform project.
GetApplication
Gets information about an application.
RepairApplication
Recreates the required App Engine features for the specified App Engine application, for example a Cloud Storage bucket or App Engine service account.
UpdateApplication
Updates the specified Application resource.
