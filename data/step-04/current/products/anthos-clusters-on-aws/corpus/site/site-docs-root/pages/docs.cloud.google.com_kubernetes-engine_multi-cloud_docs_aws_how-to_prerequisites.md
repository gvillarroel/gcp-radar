Before creating clusters or node pools in AWS, you need to prepare your AWS
VPC.
Prepare your VPC directly
You can prepare your VPC yourself by following the steps below.
Configure the Google Cloud CLI
Configure the AWS CLI
Create an AWS VPC
Create an AWS KMS key
Create AWS IAM roles
Create an SSH key pair
Prepare your VPC with Terraform
If you're familiar with Terraform, you can
use Terraform to prepare your VPC .
The Terraform scripts also create a cluster and node pool.
