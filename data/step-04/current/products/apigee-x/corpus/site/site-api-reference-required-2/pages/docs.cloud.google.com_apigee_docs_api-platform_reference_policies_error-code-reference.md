Apigee Edge documentation.
Every policy document includes an error reference section that
describes the fault codes and error messages that are returned and fault
variables that are set by Apigee when the policy triggers an error. The
error reference section includes:
Runtime errors
Deployment errors
Fault variables
Examples
This information is important to know if you are developing fault rules to
handle faults. To learn more, see
What you need to know about policy errors and
Handling faults .
For a current list of all policies, see
Policy reference .
Refer to the individual policy documents for error codes specific to that
policy. For example, see
AssignMessage policy, Error codes .
