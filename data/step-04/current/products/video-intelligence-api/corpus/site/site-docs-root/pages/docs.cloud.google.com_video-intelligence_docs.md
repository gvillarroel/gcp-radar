Video Intelligence API documentation
Read product documentation
The Video Intelligence API allows developers to use Google video
analysis technology as part of their applications. The REST API enables users
to annotate videos stored locally or in Cloud Storage , or
live-streamed, with contextual information at the level of the entire video,
per segment, per shot, and per frame.
Go to the Video Intelligence API product page for more.
