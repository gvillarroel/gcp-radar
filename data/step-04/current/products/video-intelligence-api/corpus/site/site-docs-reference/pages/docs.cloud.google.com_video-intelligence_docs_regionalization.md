Regionalization
Stay organized with collections
Save and categorize content based on your preferences.
You can use the location_id parameter in your
AnnotateVideoRequest ,
to specify the
Google Cloud Platform region where
annotation is performed. The following regions are currently supported:
us-east1
us-west1
europe-west1
asia-east1
If no region is specified, the region is determined based on the video
file location.
