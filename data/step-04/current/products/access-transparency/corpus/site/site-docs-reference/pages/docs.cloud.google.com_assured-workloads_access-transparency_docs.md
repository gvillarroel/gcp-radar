Read product documentation
Access Transparency is a part of Google's long-term commitment to transparency and user trust.
Access Transparency records the actions that Google personnel take when accessing Customer Data stored
on Google Cloud. Go to the Access Transparency product page for
more.
Google Cloud provides several administrative access controls that are designed to ensure that
Google personnel can't access Customer Data without your explicit consent.
Access Approval lets you approve or deny Google employees from accessing your content.
For more information, see
Access Approval documentation .
Key Access Justifications aims to give you visibility into a request for an externally-managed encryption key
by including a justification for that request. For more information, see
Overview of Key Access Justifications .
Assured Workloads lets you secure your workloads and accelerate your path to running
compliant workloads on Google Cloud.
