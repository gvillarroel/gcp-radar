# Principal access boundary policies | Identity and Access Management (IAM) | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/iam/docs/principal-access-boundary-policies?hl=en

If a principal access boundary policy doesn&#x27;t block a permission, then principal access boundary policies have no effect on whether principals can use the permission. For example, imagine that a principal, Lee (lee@example.com), is granted the Dataflow Developer role (roles/dataflow.developer).
