Users and roles
Manage users, roles, and permissions using the Apigee APIs described in the following table:
API method
Description
Organizations list API
List all Apigee organizations, and the related projects for which a user has
permissions.
Environments Get IAM Policy API
Gets the IAM policy on an environment.
Environments Set IAM Policy API
Sets the IAM policy on an environment. If the policy already exists, it will be
replaced.
Environments Test IAM Permissions API
Tests the permissions of a user on an environment. Returns a subset of permissions that
the user has on the environment.
