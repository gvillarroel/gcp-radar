Infrastructure Manager (Infra Manager) is a managed service that automates the deployment and management of
Google Cloud infrastructure resources. Infrastructure is defined using Terraform and
deployed onto Google Cloud by Infra Manager, enabling you to manage resources
using Infrastructure as Code (IaC).
