Database Center lets you view an inventory of the resources in your
database fleet. The Inventory page shows you resource inventory information,
such as the following:
The number of resources used by each product, such as Spanner,
AlloyDB for PostgreSQL, and Bigtable.
The number of resources used by each product version in your fleet, such as
Cloud SQL for MySQL 8.0, Cloud SQL for PostgreSQL 16, and
Firestore with MongoDB compatibility.
Your database inventory filtered by labels and tags.
The inventory of resources by location, such as the europe-north1 and the
us-west1 regions.
Before you begin
Ensure that Database Center is set up for your
organization .
View information about your database inventory
The Inventory page includes cards that display unique information about
your database inventory. To view all your database inventory information, do the
following:
Go to the Inventory page in Database Center.
Go to Database Center
After the Inventory page opens, use the following topics to view your
fleet inventory by product, product and version, location, labels, or tags.
View resource inventory by product
To view resources in your database fleet by product, follow these steps:
In the Types of resources card, view the number of resources used by
each product. The managed database products are listed together, and the
self-managed database products are listed together.
Optional: Click View all next to a database product to view details
about its resources in the Resources page of
Database Center.
View resource inventory by product and version
To view resources in your database fleet by product and version, follow these
steps:
In the Product version card, view the number of resources sorted by
product and version. This card shows you the total number of database
groups, resources, and new resources in your database fleet by product and
version.
Optional: Click filter_list Filter
to filter resources in the Product version card by database version.
Optional: To change the duration for added new resources, click
1 day , 7 days (default), or 30 days .
Optional: To view details about new resources, click View inventory
changes for the last X number of days , where X is 1, 7, or 30, based
on your previous selection. A pane in the Google Cloud console opens with your
resource details.
Optional: To view details about the resources for a version of a product,
click View resource details in the Product version card. The
Resources page in Database Center opens and shows
information about resources used by that version of the product.
View resource inventory by location
To view resources in your database fleet by location, follow these steps:
In the Location card, view the number of resources sorted by region.
Optional: Click filter_list Filter
to filter resources in the Location card by database region.
Optional: To view resources by an area on the map, pan and zoom to the
area you want to view.
Optional: To view details about the resources in a location, click
View resource details in the Location card. The Resources page
in Database Center opens and shows information about
resources used in that location.
For more information, see Geography and regions .
View resource inventory by labels and tags
To view resources in your database fleet by labels, tags, or both, follow these
steps:
In the Labels card, view the number of resources by labels.
In the Tags card, view the number of resources by tags.
Optional: Click filter_list Filter
in the Labels or Tags card to filter the resources by labels
or tags.
Optional: To view details about the resources that use a label or a tag,
click View resource details in the Label card or Tag card. The
Resources page in Database Center opens and shows
information about resources with that label or tag.
