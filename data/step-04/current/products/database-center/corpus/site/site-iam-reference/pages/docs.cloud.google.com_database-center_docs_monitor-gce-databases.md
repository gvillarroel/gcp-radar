Database Center provides a centralized view across your fleet of Google Cloud
databases. Database Center also displays health issues and recommendations for
self-managed databases that you run on Compute Engine virtual machines (VMs).
Database Center supports the following databases on Compute Engine
VMs:
MySQL
PostgreSQL
Microsoft SQL Server
