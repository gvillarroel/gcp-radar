Troubleshoot database health issues
In the Google Cloud console, go to the Database Center page.
Database Center
To define the scope of your database fleet, use the drop-down in
the Google Cloud console menu bar, select a Google Cloud project, folder, or
organization.
Select the products and versions, regions, and label and tag filters you want
to apply to your dashboard.
Click All Resources . The dashboard shows database resource metadata and
issues affecting each database resource.
To view a detailed description of the issue, click a database health
issue. The issue dialog describes the issue, recommends next steps, and
lists compliance violations where applicable.
To view the database resource affected by the issue, click Go to
Resource .
Optional: To edit the relevant configuration to resolve the issue you clicked,
click Edit Configuration .
Optional: To share detailed issue information, click Copy Link and
share the link.
