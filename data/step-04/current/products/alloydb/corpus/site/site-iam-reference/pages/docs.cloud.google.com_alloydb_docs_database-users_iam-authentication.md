# AlloyDB for PostgreSQL IAM database authentication | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/alloydb/docs/database-users/iam-authentication

When using IAM authentication, permission to access an AlloyDB instance isn&#x27;t granted directly to the end user. Instead, permissions are grouped into roles, and roles are granted to principals. For more information, see the IAM overview. Administrators who have users sign in through IAM database authentication can use IAM to centrally manage access control to their instances using IAM policies.
