# AlloyDB overview | AlloyDB for PostgreSQL | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/alloydb/docs/overview

AlloyDB uses a disaggregated architecture, where compute and storage layers are separate and scale independently. Compute: virtual machines, or nodes, that process your queries. Storage: a cloud-native, distributed storage engine that persists your data across multiple availability zones and scales automatically as your data grows.
