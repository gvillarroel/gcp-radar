API v1 shutdown
The Cloud Bigtable v1 API was deprecated on January 31, 2020 and shut
down on January 31, 2021. It was replaced by the Cloud Bigtable
v2 Data and Admin APIs .
Migrating to v2
The Cloud Bigtable API (v2 Data API) has been generally
available since June 2016, and the Cloud Bigtable Admin API (v2 Admin API) has
been GA since July 2017.
If you connect to Bigtable using an early version of one of the
Cloud Bigtable client libraries, including versions 0.3 and older of the
HBase client library, see the client library upgrade
instructions .
Where to get help
If you have any questions or require assistance, contact
Cloud Customer Care .
Shutdown timetable
With any deprecation, there is a follow-up decommission when the API or service
is formally removed. The Cloud Bigtable v1 API was shut down on
January 31, 2021 .
