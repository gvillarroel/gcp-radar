Encryption Info
Class for encryption info for tables and backups.
class google.cloud.bigtable.encryption_info.EncryptionInfo(encryption_type, encryption_status, kms_key_version)
Bases: object
Encryption information for a given resource.
If this resource is protected with customer managed encryption, the in-use Google
Cloud Key Management Service (KMS) key versions will be specified along with their
status.
Parameters
encryption_type ( int ) – See enums.EncryptionInfo.EncryptionType
encryption_status ( google.cloud.bigtable.encryption.Status ) – The encryption status.
kms_key_version ( str ) – The key version used for encryption.
