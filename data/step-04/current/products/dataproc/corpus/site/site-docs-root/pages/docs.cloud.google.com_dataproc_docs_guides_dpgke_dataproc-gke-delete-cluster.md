To delete Managed Service for Apache Spark on GKE virtual cluster, follow the steps to
delete a Managed Service for Apache Spark cluster .
Delete node pools: Deleting a Managed Service for Apache Spark on GKE virtual cluster deletes
Managed Service for Apache Spark component software from the GKE cluster, but it
does not delete Managed Service for Apache Spark on GKE node pools created on the GKE
cluster. After deleting the Managed Service for Apache Spark on GKE cluster, you can
delete node pools
that are no longer in use by a Managed Service for Apache Spark on GKE cluster.
