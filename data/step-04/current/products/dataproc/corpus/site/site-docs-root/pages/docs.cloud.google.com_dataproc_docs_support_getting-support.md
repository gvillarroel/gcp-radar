"Managed Service for Apache Spark" is the new name for the product formerly known as "Dataproc on Compute Engine" (cluster deployment) and "Google Cloud Serverless for Apache Spark" (serverless deployment).

Get a Google support package
Google Cloud offers different support packages to meet different needs, such as 24/7
coverage, phone support, and access to a technical support manager. For more information,
see Cloud Customer Care .
To try a Managed Service for Apache Spark Private Preview feature:
You can contact your Google Cloud Sales representative to have your project(s)
added to an allowlist for a specific feature.
