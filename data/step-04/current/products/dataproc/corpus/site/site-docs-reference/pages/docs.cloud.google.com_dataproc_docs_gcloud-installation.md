In addition to using the Managed Service for Apache Spark APIs or the
Managed Service for Apache Spark UI ,
you can access Managed Service for Apache Spark using gcloud CLI's gcloud dataproc
commands.

To use the Google Cloud CLI, install the gcloud CLI by following the
instructions at installation and quick start .
