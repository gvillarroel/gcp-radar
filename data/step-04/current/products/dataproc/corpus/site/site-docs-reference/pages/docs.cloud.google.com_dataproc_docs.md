Managed Service for Apache Spark cluster deployment mode lets you take advantage of open source data tools for
batch processing, querying, streaming, and machine learning. Managed Service for Apache Spark automation
helps you create clusters quickly, manage them easily, and save money by turning clusters off when
you don't need them. With less time and money spent on administration, you can focus on your jobs
and your data.
