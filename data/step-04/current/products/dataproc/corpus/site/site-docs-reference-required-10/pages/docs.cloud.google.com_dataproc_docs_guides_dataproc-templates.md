To set up and run Managed Service for Apache Spark workloads and jobs, use
Managed Service for Apache Spark templates on GitHub
Templates are provided in the following language and execution environments:
Airflow orchestration templates :
Run Spark jobs from DAGs in Airflow.
Java templates :
Run Spark batch workloads or jobs on Managed Service for Apache Spark or an
existing Managed Service for Apache Spark cluster.
Python templates :
Run PySpark batch workloads on Managed Service for Apache Spark.
Notebook templates :
Run Spark jobs using Vertex AI notebooks.
