BuildVersion
Stay organized with collections
Save and categorize content based on your preferences.
JSON representation
Describe user-specific version tag and server-generated unique build ID for a specific build.
JSON representation
{
"contentVersionTag" : string ,
"buildId" : string ,
"buildTime" : string ,
"isFailed" : boolean ,
"buildLogUri" : string
}
Fields
contentVersionTag
string
User-specified version tag of content build.
buildId
string
Unique build ID generated by server.
buildTime
string ( Timestamp format)
Build time stamp
A timestamp in RFC3339 UTC "Zulu" format, with nanosecond resolution and up to nine fractional digits. Examples: "2014-10-02T15:01:23Z" and "2014-10-02T15:01:23.045123456Z" .
isFailed
boolean
Boolean value whether build failed.
buildLogUri
string
Build log uri.
