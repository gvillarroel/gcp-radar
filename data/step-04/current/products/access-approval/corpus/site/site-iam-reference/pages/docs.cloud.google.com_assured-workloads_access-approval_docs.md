Google Cloud offers several administrative access controls that are designed
to ensure that Google personnel can't access Customer Data stored on
Google Cloud without your explicit consent. Access Approval lets you
control access to your organization's data
by Google personnel. Go to the Access Approval product page for
more.
Access Transparency records the actions that Google personnel take when accessing
Customer Data stored on Google Cloud. For more information, see Access Transparency
documentation .
Key Access Justifications aims to give you visibility into a request for an
externally-managed encryption key by including a justification for that
request. For more information, see Overview of
Key Access Justifications .
Assured Workloads lets you secure your workloads and accelerate your
path to running compliant workloads on Google Cloud. For more information, see
Assured Workloads
documentation .
