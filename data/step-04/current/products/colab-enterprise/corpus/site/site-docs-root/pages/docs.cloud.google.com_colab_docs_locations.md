Colab Enterprise locations
This page describes the available regions for Colab Enterprise.
For more information about regions,
see Geography and regions .
The Data Science Agent (Preview) isn't available in all regions. For more
information about the Data Science Agent, see Use the
Data Science Agent .
Note: When you use Gemini features, there is no guarantee that
Gemini requests are processed in the same region as
your notebook and runtime. Data stored at rest in your notebook
remains at rest in that notebook's location.
For more information about data residency, see
Data residency .
