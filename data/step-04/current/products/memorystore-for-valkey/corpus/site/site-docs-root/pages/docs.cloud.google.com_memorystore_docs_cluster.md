Memorystore for Redis Cluster documentation
Read product documentation
Memorystore for Redis Cluster is a fully managed Redis service for Google Cloud. Applications running
on Google Cloud can achieve extreme performance by leveraging the highly scalable, available,
secure Redis service without the burden of managing complex Redis deployments.
Memorystore for Redis Cluster distributes (or "shards") your data across primary nodes and
replicates your data across optional replica nodes to ensure high availability. The horizontally
scalable cluster architecture provides better performance over vertically scalable architecture
because Redis performance is better on many smaller nodes instead of fewer larger nodes.
Memorystore for Redis Cluster is based on and is compatible with open-source Redis
versions 7.2 and earlier and supports a subset of the total Redis command library.
Go to the Memorystore product page for more.
