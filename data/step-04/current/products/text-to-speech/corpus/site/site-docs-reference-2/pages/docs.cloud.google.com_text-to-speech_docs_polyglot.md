Overview
Polyglot voices can speak multiple languages.
Each polyglot voice has a language and a speaker number. For example,
"fr-FR-Polyglot-1" is speaker 1 in French, "en-US-Polyglot-1" is speaker 1
in American English, and "en-AU-Polyglot-2" is speaker 2 in Australian English.

of voices available in your language. Cloud TTS
