Google works continuously to improve its products, including the use
of customer data from Google consumer data to refine those products in many
cases. Cloud Text-to-Speech is both stateless and resourceless. This means
Data Access and
System Event data don't apply. As a
result, Cloud TTS is out of the scope of Client Access Licenses
(CAL). Google does not log any customer Cloud TTS text or audio
data.
See the Cloud Logging documentation for more details.
