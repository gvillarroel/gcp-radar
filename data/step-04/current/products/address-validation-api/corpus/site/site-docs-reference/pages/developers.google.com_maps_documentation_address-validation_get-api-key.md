Google Maps Platform secures its products by requiring API keys for authentication and billing purposes.
You can create and manage API keys through the Google Cloud Console or the Cloud SDK.
It's crucial to restrict your API keys for enhanced security by limiting their usage to specific APIs and IP addresses.
Include your API key in every Address Validation API request using HTTPS.
European Economic Area (EEA) developers
If your billing address is in the European Economic Area, effective on 8 July 2025, the
Google Maps Platform EEA Terms of Service
will apply to your use of the Services. Functionality varies by region.
