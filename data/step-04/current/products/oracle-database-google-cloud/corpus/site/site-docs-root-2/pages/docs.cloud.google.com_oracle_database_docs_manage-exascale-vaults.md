This page describes how to manage an Exascale Storage Vault.
You can only create an Exascale Storage Vault as part of the Exascale VM Cluster
provisioning workflow. After you've provisioned an Exascale Storage Vault,
Oracle Database@Google Cloud lets you modify its settings through the Oracle Cloud Infrastructure (OCI) console.
Before you begin
Make sure that you have the required Identity and Access Management (IAM) roles and
permissions to view an Exascale Storage Vault:
roles/oracledatabase.exascaleDbStorageVaultViewer
For information on how to assign roles, see
Apply IAM roles .
Make sure that you have the required OCI permissions
to manage an Exascale Storage Vault and its associated Exascale VM Clusters.
For more information, see the Oracle documentation.
Manage Exascale Storage Vaults
Go to the Exadata Database Service > Exascale Infrastructure page.
Go to Exascale Infrastructure
Select the Exascale VM Clusters tab.
Click the name of the vault.
On the Exascale Storage Vault details page, click Manage in OCI .
You're redirected to the OCI page to modify your Exascale Storage Vault.
For information about how to manage an Exascale Storage Vault, refer to the Oracle
documentation.
