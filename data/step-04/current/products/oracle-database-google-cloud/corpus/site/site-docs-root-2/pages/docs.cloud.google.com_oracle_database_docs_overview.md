This page provides an overview of the Oracle Database@Google Cloud service.
Google Cloud's partnership with Oracle lets you combine
Oracle Cloud Infrastructure (OCI) and Google Cloud technologies. With built-in integration,
you can deploy your Oracle AI Database services in a Google Cloud data center
running on OCI Exadata hardware with minimal latency. Workloads
reside in Google Cloud and Exadata systems are deployed in
Google Cloud data centers. Google Cloud provides the core infrastructure,
the network, the physical and network security, and hardware monitoring
capabilities for your OCI resources.
Oracle Database@Google Cloud supports the following Oracle Cloud Infrastructure (OCI) products on
Google Cloud:
Exadata Database Service
Autonomous AI Database Service
Base Database Service
Exadata Database Service on Exascale Infrastructure
What Oracle Database@Google Cloud provides
Oracle Database@Google Cloud offers many services to allow you to seamlessly integrate
and manage your OCI resources in Google Cloud:
ODB Network connectivity
Manage access using Identity and Access Management (IAM)
Create and manage Exadata Database Service resources
Create and manage Exascale Infrastructure resources
Create and manage Autonomous AI Database Service resources
Create and manage Base Database Service resources
Observe and Troubleshoot resources
ODB Network connectivity
Oracle Database@Google Cloud uses ODB Networks to manage connectivity
to your resources. For more information about how ODB Networks
work, see Set up Oracle Database@Google Cloud environment .
Manage access using Identity and Access Management
Oracle Database@Google Cloud uses Identity and Access Management integration to manage user and group
access for your Exadata Infrastructure and Autonomous AI Database resources. For more
information on how IAM works, see
IAM overview .
Create and manage Oracle Exadata Database Service resources
Oracle Database@Google Cloud lets you create and manage
Exadata Infrastructure instances
and Exadata VM Clusters using
Google Cloud console, Google Cloud CLI, or the Oracle Database@Google Cloud API.
Exadata Databases can only be created in Oracle Cloud Infrastructure (OCI).
Create and manage Exascale Infrastructure resources
Oracle Database@Google Cloud lets you create and manage
Exascale VM Clusters and Exascale Storage Vaults
on Exascale Infrastructure.
Create and manage Autonomous AI Database Service resources
Oracle Database@Google Cloud lets you create and manage
Autonomous AI Database
resources using Google Cloud console, Google Cloud CLI,
or the Oracle Database@Google Cloud API.
Create and manage Base Database Service resources
Oracle Database@Google Cloud lets you create and manage
DB system
resources using Google Cloud console, Google Cloud CLI,
or the Oracle Database@Google Cloud API.
Observe and troubleshoot resources
You can monitor and troubleshoot your Oracle Database@Google Cloud resources using
available metrics and
logs .
Networking prerequisites
Before you can create Exadata Infrastructure or Autonomous AI Database resources, you
must set up networking for your project.
Available regions and zones
To see which regions and zones are available for Oracle Database@Google Cloud, see
Regions and zones .
Get started with Oracle Database@Google Cloud
To get started with Oracle Database@Google Cloud and place an order, see
Purchase and billing .
