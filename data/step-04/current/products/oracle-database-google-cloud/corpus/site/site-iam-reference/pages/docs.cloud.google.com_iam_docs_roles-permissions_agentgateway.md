This page lists the IAM roles and permissions for Agent Gateway. To
search through all roles and permissions, see the role and
permission index .
Agent Gateway roles
Agent Gateway offers the following service agent roles.
Service agent roles should only be granted to service agents .
Role
Permissions
Agent Gateway Service Agent
( roles/ agentgateway.serviceAgent )
Grants Agent Gateway Service Agent permissions required to do DNS peering.
Warning: Do not grant service agent roles to any principals except
service agents .
dns. networks. targetWithPeeringZone
Agent Gateway permissions
There are no IAM permissions for this service.
