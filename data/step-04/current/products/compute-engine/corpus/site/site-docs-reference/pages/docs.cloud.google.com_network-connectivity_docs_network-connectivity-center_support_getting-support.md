Get a Google support package
Google Cloud offers different support packages to meet different needs, such as
24/7 coverage, phone support, and access to a technical support manager. For
more information, see Cloud Customer Care .
Get support from the community
Ask a question on Stack Overflow
On Stack Overflow ,
use the tag google-cloud-networking
for questions about NCC. This tag not only receives responses
from the Stack Overflow community, but also from Google engineers, who monitor
the tag and offer unofficial support.
Discuss NCC
Join the
Google group to discuss NCC and receive
NCC announcements and updates.
You can also visit the Google Cloud
Slack community to discuss
NCC and other Google Cloud products. If you haven't
already joined,
use this form to sign up .
For NCC, join the
#networking
channel.
File bugs or feature requests
From the NCC documentation, click Send feedback near the
top right of the page or at the bottom of the page. This opens a feedback form.
Your comments are reviewed by the NCC team.
Support considerations for Router appliance
Because Router appliance uses software from third-party vendors,
you must contact the vendor of this software for the first level of support.
