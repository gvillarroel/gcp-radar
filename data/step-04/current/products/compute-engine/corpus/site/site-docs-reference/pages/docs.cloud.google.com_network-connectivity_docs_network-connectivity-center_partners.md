The following table lists partners whose solutions are integrated with
NCC.
NCC is Google's hub-and-spoke
model for managing heterogeneous cloud and on-premises environments. When using
NCC, you can create spokes that connect each of your on-premises
locations with your Google Cloud network resources. Spokes can be powered by
resources such as Cloud VPN, Dedicated Interconnect,
Partner Interconnect, and Router appliance.
A Router appliance spoke lets you integrate the vendor solution of your
choice directly with your Virtual Private Cloud (VPC) network. This integration
enables multiple connectivity use cases. To create a Router appliance spoke,
you install the virtual appliance on a Compute Engine virtual machine (VM)
instance, following the instructions provided by the solution's vendor. For
more information, see
Working with spokes .
