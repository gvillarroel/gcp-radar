This document provides a high-level overview of setting up reCAPTCHA
with Google Cloud Armor.
Setting up reCAPTCHA with Google Cloud Armor involves the
following steps:
Choose the features for your integration .
Create a reCAPTCHA key for each selected feature.
Configure the reCAPTCHA frontend integration.
Integrate with Google Cloud Armor for websites .
Integrate with Google Cloud Armor for mobile applications .
Create security policies to enable protections on selected web pages and paths.
Use reCAPTCHA token attributes in Google Cloud Armor security policies .
