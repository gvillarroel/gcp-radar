Aerial View API
Stay organized with collections
Save and categorize content based on your preferences.
Lets you create and display aerial view videos rendered using Google's 3D geospatial imagery. Aerial view videos are photorealistic 3D aerial views of a point of interest that simulates video taken by a drone circling overhead.
