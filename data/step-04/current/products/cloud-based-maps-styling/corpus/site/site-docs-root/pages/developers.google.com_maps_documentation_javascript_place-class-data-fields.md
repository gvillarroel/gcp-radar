Page Summary
outlined_flag
This documentation outlines the data fields available when requesting Place Details from the Places API, categorized as ID only, basic, advanced, and preferred.
These fields provide various types of information about a place, such as address, business status, contact details, ratings, and operational attributes like dining options and accessibility.
Each data field is linked to specific Place Details, Text Search, and Nearby Search SKUs, influencing usage and billing.
An attribution is always returned with each Place result and must be displayed in the user interface.
Developers can select the appropriate data fields to retrieve relevant information for their applications, aligning with their specific needs and cost considerations.

Place data fields define the types of Place data to return when requesting place details. This
page lists all of the place data fields supported by the Place class.
Fields correspond to Place Details results ,
and are divided into these categories: ID only, basic, advanced, and preferred. See
Places API Usage and Billing
for more information. Every call always returns an Attribution
for each result, which must be shown in your UI.
