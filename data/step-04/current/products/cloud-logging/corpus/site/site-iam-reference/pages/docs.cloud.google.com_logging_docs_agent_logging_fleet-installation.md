Install the Logging agent by using automation tools
Stay organized with collections
Save and categorize content based on your preferences.
In addition to using the Google Cloud CLI or Terraform to create
agent policies ,
you can use other automation tools to manage the Logging agent across
your fleet of Compute Engine VMs:
Ansible by using the Ansible role, you can install and configure
the agent across your fleet of Linux
and Windows VMs. For more information,
see the
Ansible Role for Cloud Ops
documentation.
Chef : by using the Chef cookbook, you can install and configure
the agent across your fleet of Linux
VMs.
For more information, see the
Chef Integration
documentation.
Puppet : by using the Puppet module, you can install and configure
the agent across your fleet of Linux
VMs.
For more information, see the
Puppet Integration
documentation.
