The Imaging Data Commons (IDC)
hosts collections of de-identified medical images, primarily in DICOM format.
You can access this data from Google Cloud in the following ways:
In a NCI Imaging Data Commons BigQuery dataset from the
Google Cloud Marketplace:
Go to the IDC datasets in the Google Cloud Marketplace
In a DICOM store in the Cloud Healthcare API. The DICOM store is named idc-store ,
and is in a Cloud Healthcare API dataset named idc in the nci-idc-data
Google Cloud project. To request access to the IDC datasets, complete the
NCI Imaging Data Commons Access Form .
Go to the IDC datasets in the Cloud Healthcare API DICOM Studio
For information about the structure of the data, see the
DICOM overview
and Using the DICOMweb standard .
