The
Google Cloud Platform Terms of Service (section "Discontinuation of Services")
defines the deprecation policy that applies to the Cloud Healthcare API.
The deprecation policy only applies to the services,
features, or products listed therein.
After a service, feature, or product is officially
deprecated, it continues to be available for at least the period of time defined in the
Terms of Service. After this period of time, the service is scheduled for shutdown.

Google Cloud Healthcare Annotations API
May 16, 2023
May 30, 2025
The Google Cloud Healthcare Annotations API is deprecated. As an alternative, you can save annotation data for de-identified images using FHIR resources. For more information, see Write de-identify operation metadata to a FHIR store .
Healthcare Natural Language API
May 27, 2025
The Healthcare Natural Language API is deprecated. As an alternative, you can use a Generally Available (GA) Gemini model on Vertex AI. For more information, see Generally available Gemini models .
