Dialogflow CX integrates with the
AudioCodes
telecommunications provider.
Setup
To create a telephony integration with this system:
Open the Dialogflow CX console .
Choose your project.
Select your agent.
Select the Manage tab.
Click Telephony Integrations in the Integrations section
of the Manage tab.
Click the Connect button for the
AudioCodes integration.
You are redirected to AudioCodes.
Provide the configuration information requested by
AudioCodes.
You are redirected back to the Dialogflow CX console,
and the integration is now enabled for your agent.
For more information on this integration, see the
AudioCodes documentation .
