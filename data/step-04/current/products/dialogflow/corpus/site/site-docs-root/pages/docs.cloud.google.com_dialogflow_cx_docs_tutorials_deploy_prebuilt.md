The first step in this tutorial is to create an agent.
Rather than building an agent from scratch,
you will import a telecommunications
prebuilt agent .
Using a prebuilt agent will accelerate your progress for this tutorial.
To import a prebuilt agent to your project:
Go to the Dialogflow CX console .
Select the project where you would like to import the prebuilt agent
or click Create Project to create a new project.
Click Use pre-built agents .
Click the Telecommunications prebuilt agent.
Click Import as agent .
A dialog box opens.
Choose your desired
location .
Click Create .
In the next step,
you will create a webhook service required for this agent.
