Discover applications on your hosts
Stay organized with collections
Save and categorize content based on your preferences.
To manage your application, the appliance management console must discover the applications,
VMs, and Cloud instances managed through its appliances.
Use the Application Back up wizard to discover applications
within a host or in a VM. Once you discover one or more applications, VMs,
or cloud instances, you can protect them all at once by applying a backup
template and profile or you can add them to the appliance management console as
unmanaged or ignored.
You can access the wizard from:
Back up & recover menu.
Add applications in App Manager menu.
Back up & recover menu
The Back up & Recover menu provides two wizards to help you
back up and recover your databases and applications.
Click the Back up option to open the application back up
wizard. From here you can discover and manage applications and VMs.
Click the Recover option to open the
Data Recovery wizard. From here, you can mount, restore, and perform
other data access operations.
Application back up wizard
The Application Back up wizard helps you discover and manage applications and
VMs.
Use the following instructions to open the Application Back up wizard:
Click Back up & Recover and select Back up from the drop-down menu.
The Application Back up wizard opens.
From this wizard, you can you discover and protect applications and VMs.
Data recovery wizard
The Data Recovery wizard helps you access backed up data.
Application data can be backed up in a physical or a virtual machine.
Use the following instructions to open the recovery wizard:
Click Back up & Recover and select Recovery from the drop-down menu.
Select the applications or databases that you want to recover and click
Next .
The Application Recovery page opens with the timeline ramp view. From
the timeline ramp view , you can perform various access actions like
performing a mount, clone, and restore as detailed in
Access captured and backed up data .
Add applications
The Add Application wizard helps you discover and manage applications and
VMs.
Use these instructions to open the Add Application wizard:
From the Backup and DR Service appliance management console, click
App Manager and select Applications from the drop-down menu.
The Application Management page opens.
Click +Add Application in top right corner to launch the
Add Application wizard.
From this wizard, you can you discover and protect applications and VMs, including:
Discover and Protect Consistency Groups
Discover and Protect Generic Applications
Discover and Protect VMware VMs
Discover and Protect Compute Engine instances
