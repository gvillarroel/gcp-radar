v0.1 and v1beta1 metadata server endpoints deprecation
Stay organized with collections
Save and categorize content based on your preferences.
On Compute Engine each VM stores its metadata on a metadata server.
Multiple versions of the metadata version were available on Compute Engine.
However, the v0.1 and v1beta1 metadata server endpoints were deprecated and
shutdown on September 30, 2020.
Shutdown schedule
The following table lists the shutdown schedule for v0.1 and v1beta1 metadata
server endpoints.
Date
Event
September 30, 2019
v0.1 and v1beta1 metadata server endpoints were deprecated.
September 30, 2020
v0.1 and v1beta1 metadata server endpoints were shutdown.
