ProxyV2 and TargetV2 metrics deprecation
Stay organized with collections
Save and categorize content based on your preferences.
The ProxyV2 and TargetV2 metrics suite is deprecated for Apigee hybrid
installations as of April 17, 2024. The Apigee hybrid v1.12 release supports new proxy
and target metrics with improved performance and reliability.
Apigee hybrid users should be aware of the following:
The Apigee hybrid v1.12 release supports the
new proxy and target metrics by default.
Support for the ProxyV2 and TargetV2 metrics suite in Apigee hybrid v1.10 and v1.11
will end in April of 2025.
If you are upgrading to v1.12, you should begin using the new metrics
and reconfigure any existing alerts .
If you need additional time to transition to new metrics,
you can change the default behavior in 1.12 to continue using the original metrics.
If you use v1.10 or v1.11, we recommend that you upgrade to v1.12
and adjust your alerts and notifications to use the new metrics at your earliest convenience.
Shutdown schedule
The following table lists the shutdown schedule for the ProxyV2 and TargetV2 metrics suite:
Date
Event
April 17, 2024
ProxyV2 and TargetV2 metrics suite deprecated for Apigee hybrid v1.12.
April 17, 2024
Support for the ProxyV2 and TargetV2 metrics suite in Apigee hybrid in v1.10 and v1.11 extended for one year.
April 17, 2025
Support for the ProxyV2 and TargetV2 metrics suite shut down for all Apigee hybrid versions.
