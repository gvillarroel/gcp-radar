Apigee Classic UI shutdown
Stay organized with collections
Save and categorize content based on your preferences.
The Apigee Classic UI will be shutdown as of August 29, 2025.
This is the final phase of moving Apigee to the Google Cloud console.
Apigee in the Google Cloud console gives you the ability to manage
all of your Apigee functionality in one place.
To prepare for the deprecation of the Apigee Classic UI,
familiarize yourself with the new Apigee UI in Google Cloud console by
reviewing
UI overview .
Shutdown schedule
The following table lists the shutdown schedule for the
Apigee Classic UI:
Date
Event
May 29, 2025
Deprecation announcement sent to customers via
Mandatory Service Announcement (MSA).
June 16 - July 31, 2025
Begin redirecting navigation menu items in the
Apigee Classic UI to the Google Cloud console.
We will gradually expand the automatic redirects to transition all
Apigee Classic UI pages to the Google Cloud console.
Aug 15, 2025
Deadline for customers to submit
exception request form if you require more time to transition to the
Google Cloud console.
Aug 29, 2025
General shutdown of the Apigee Classic UI. Customers with
approved exceptions will be allowlisted to continue using the
Apigee Classic UI beyond this date. New orgs created by
existing customers will use the Google Cloud console unless an exception
was approved.
September 29, 2025
Final shutdown of the Apigee Classic UI for all allowlisted
(exception) customers.
