Introduction to Access Transparency
As a part of Google's long-term commitment to security and transparency,
Access Transparency lets you review logs of actions that Google personnel take when
accessing certain Customer Data to fulfill their contractual obligations.
Access Transparency logs include information about Google personnel activity, including
the following:
Actions taken by the Cloud Customer Care team to resolve a support ticket that
you filed.
Investigation of an outage.
For more information, see Overview of Access Transparency .
To learn about the core principles upon which Google Cloud's administrative
access controls are based, see
Overview of administrative access controls .
For the list of services that Access Transparency supports, see Supported services .
For information about Google Cloud's approach to privileged access management,
see Privileged access at Google Cloud .
