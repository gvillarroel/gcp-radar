As an administrator for your Google Cloud organization, you can
control access to
Gemini Code Assist for individuals ,
the free version of Gemini Code Assist service which includes
IDE support ,
Gemini CLI , and
Antigravity ,
by using the Google Admin console within Google Workspace.
Before you begin
To change access settings for Gemini Code Assist for individuals,
you must be a Google Workspace administrator with the
Service Settings privilege .
This privilege is available in
administrator roles such as the
Super Admin role and the Services Admin role.
Allow or block access to Gemini Code Assist for individuals
To toggle access to Gemini Code Assist for individuals, do the
following:
Go to the Google Workspace Admin console.
Go to the Admin console
If you're not already signed in, follow the steps to sign in to the
Admin console.
In the navigation menu, click Apps .
In the pane that opens, click Additional Google Services .
In the pane that opens, click Google Cloud Platform .
In the Code Assist settings pane, use the checkbox for
Allow access to Code Assist for individuals to allow or block access.
Click Save .
