Traffic on IP addresses
The fixed IP addresses for regions are shared by all Dataform
users on Google Cloud. As such, traffic originating from these addresses may
come from your Google Cloud projects as well as from other
Google Cloud customer projects.
Caution: While unlikely, we may need to change the regions' IP addresses at
short notice. This could impact the connectivity of Dataform to
privately hosted repositories until you update your firewall rules.
Connecting to a Git repository
To connect to a Git repository that is on a privately hosted instance—for
example, GitHub Enterprise or GitLab running on your own Virtual Private Cloud—do the
following:
Verify that your repositories in Dataform are configured to be
in one of these regions. To check your repository regions, go to the
Dataform page.
Go to Dataform
Configure firewall rules to allow connections from the IP addresses that
correspond to the regions being used, or configure firewall rules to allow all
of the IP addresses.
