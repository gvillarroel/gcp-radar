Overview of Sovereign Controls by Partners
Stay organized with collections
Save and categorize content based on your preferences.
Sovereign Controls by Partners provides sovereignty controls for
Google Cloud workloads, operated by partners.
Sovereign Controls by Partners helps enforce data residency and provides
security configurations that encompass critical aspects of cloud infrastructure,
such as encryption and key management.
Sovereign Controls by Partners data boundaries are generally available
from the following partners:
France Data Boundary by S3NS
Germany Data Boundary by T-Systems
Italy Data Boundary by Polo Strategico Nazionale (PSN)
Kingdom of Saudi Arabia Data Boundary Advanced by CNTXT
Kingdom of Saudi Arabia Data Boundary Foundation by CNTXT
