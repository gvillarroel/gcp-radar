Media CDN relies on the same global network and edge points of
presence that Google
uses to serve
Google's web properties to billions of users. This approach connects individual
points of presence (PoPs) to as many networks as possible, which reduces
latency and improves the capacity for large traffic spikes
(for example, for
streaming media or holiday sales). We have an open peering policy
with internet service providers (ISPs).
Learn more about our open approach to peering with ISPs .
Points of presence
Media CDN operates caches at several locations across the
following metropolitan areas. Google Cloud also has
colocation facility locations
to connect your corporate network to Google Cloud and network edge
locations to connect to Google Cloud services.
Google connects its network with other network operators at numerous edge
PoPs around the world, including many of the
Media CDN sites in the following list.
The set of PoPs in active use can change without notice. Equipment maintenance,
equipment failure, the introduction of new PoPs, the removal of old PoPs, and
other events mean that the following list might not reflect the PoPs that are
in use.
Many of the following cities have multiple PoPs to support service demand or to
peer with different network partners. Each PoP or edge server has its own
independent cache of content. For example, when a user in a specific geographic
region requests a video file, Media CDN serves it from the cache
at the nearest PoP.
