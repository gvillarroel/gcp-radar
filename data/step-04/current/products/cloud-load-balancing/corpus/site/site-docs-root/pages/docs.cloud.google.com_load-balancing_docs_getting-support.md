To get support for Cloud Load Balancing, see the following resources.
Get a Google support package
Google Cloud offers different support packages to meet different needs, such as 24/7
coverage, phone support, and access to a technical support manager. For more information,
see Google Cloud Customer Care support .
Get support from the community
Ask a question about Cloud Load Balancing on
Stack Overflow .
Use the tag google-cloud-load-balancer for questions about
Cloud Load Balancing. This tag not only receives responses from the
Stack Overflow community, but also from Google engineers, who monitor the tag
and offer unofficial support.
Visit the Google Cloud
Slack community to discuss
Cloud Load Balancing and other Google Cloud products. If you haven't
already joined,
use this form to sign up .
For Cloud Load Balancing, join the
#networking
channel.
File bugs or feature requests
From the Cloud Load Balancing documentation, click Send feedback near the
top right of the page or at the bottom of the page. This opens a feedback form.
Your comments are reviewed by the Cloud Load Balancing team.
