This guide describes how to use Gemini Enterprise to help you
effectively find and work with company data from a variety of sources. It also
includes information about using the API to develop apps or services that take
advantage of Gemini Enterprise.
Use assistants
With Gemini Enterprise Plus, your administrator can create AI-powered
assistants to help you navigate enterprise data.
To learn how to have a conversation with an assistant, see
Chat with the assistant .
To learn about assistant analysis features, see
Analyze data using the assistant .
Use agents
Gemini Enterprise is a single hub for workplace agents that can automate your workflows and boost productivity. Agents can perform a variety of tasks, from basic, single-step actions to complex workflows that involve multiple steps and data sources.
The Agent Gallery is your central portal to discover, use, and manage agents. Here you can find prebuilt agents created by Google, agents shared by your organization, and custom agents you have created.
To build your own custom agents, you can use Agent Designer. To learn more, see Agent Designer .
Develop with the Discovery Engine API
As a developer, you can use the Discovery Engine API to work with
Gemini Enterprise apps and get search answers and follow-up responses.
To preview search results in the Google Cloud console or get search results using
the API, see Get search results .
To get answers to complex queries and use multi-turn search, see
Get answers and follow-ups .
To filter your search results using metadata fields, see
Filter custom search for structured or unstructured data .
