Migrate to Virtual Machines lets you migrate your virtual machines (VMs) running
on an on-premises vSphere data center or on Google Cloud VMware Engine to VM
instances running on Google Cloud.
To migrate a VM from an on-premises vSphere data center, see Migrate to Virtual Machines from a VMware source .
To migrate a VM from Google Cloud VMware Engine, see Migrate to Virtual Machines from a Google Cloud VMware Engine source .
