# Enable the Assured Open Source Software free tier | Google Cloud Documentation

Source URL: https://docs.cloud.google.com/assured-open-source-software/docs/enable

To use the free tier of Assured Open Source Software (Assured OSS), you must submit the customer enablement form. Complete the steps in this section before you fill out the form. You require at least one service account or Amazon Web Services (AWS) account to access the following: Google-managed Artifact Registry for the Assured OSS curated packages. Google-managed Artifact Analysis APIs for the enriched package metadata. Secured Cloud Storage bucket with corresponding SPDX, VEX, package health and license files.
