Assured Workloads locations
Assured Workloads is available in the following regions and
multi-regions. For more information about regions in Google Cloud, see
Geography and regions .
Note: The control package you
choose when creating an Assured Workloads folder can restrict which of
these locations are allowed. Depending on the control package's specific
controls, you might be limited to a subset of these regions when creating
workloads or accessing Google Cloud resources. For example, many control
packages enforce the gcp.resourceLocations organization policy constraint,
which restricts creating or accessing resources in a non-compliant location. See
Restricting Resource Locations
for more information.
