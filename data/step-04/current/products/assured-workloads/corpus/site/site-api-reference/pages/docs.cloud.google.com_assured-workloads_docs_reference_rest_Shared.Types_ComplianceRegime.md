Assured Workloads control packages that provide compliant data boundaries in Google Cloud. The names of some of these control packages and their enums have changed. While old enums are backwards compatible with the new enums, we recommend using the new enums. See the Control package renaming notice for more information.
Enums
COMPLIANCE_REGIME_UNSPECIFIED
The default value. This value is used if the control package is omitted or unknown.
ASSURED_WORKLOADS_FOR_PARTNERS
Specifies a Sovereign Controls by Partners control package. To use this control package, you must also specify the partner field from the list of Sovereign Controls by Partners.
