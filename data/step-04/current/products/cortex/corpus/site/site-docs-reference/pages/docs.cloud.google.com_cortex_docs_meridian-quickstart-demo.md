Quickstart demo
This page describes how to get started with data preparation and setup cloud
automation for running Google Meridian
using Cortex for marketing predefined
data models for model inputs in its demo
instance in Cloud Shell. This demo includes automatic generation of
BigQuery datasets, automatic permission granting,
and sample test data. For information about deployment in production environments, see
Meridian deployment for Cortex Framework .
Caution: The default configuration parameters and sample data for Meridian are
intended for demo purposes only and shouldn't be deployed for production use.
Meridian configuration parameters should be chosen with great care as they
influence the behaviour of the model and results. See
Meridian modeling
for guidance on how to setup the model configuration for your unique business
needs and goals. Note: For assistance with fine-tuning the Meridian model, consult
your Google Ads representative. Note: For any questions or issues related
to the Google Cloud Cortex Framework itself, see the
Cortex Framework Support section.
This demo deployer automatically executes the notebook as part of the
deployment process. To begin the demo:
Click the following button to open Cloud Shell:
Cloud Shell
Follow the rest of the steps in Cloud Shell.
