Mainframe Assessment Tool values the open source community as an essential
resource and partner in innovation.
For this reason, you can download a list of licenses for the open source
projects used in Mainframe Assessment Tool.
The license information is available in a single zip file. To download this
file, run the following command:
gcloud
gcloud storage cp "gs://mainframe-ai-release/mat/v2/licenses.zip" FILE_NAME
curl
curl -H "Authorization: Bearer $(gcloud auth print-access-token)" -L https://storage.googleapis.com/mainframe-ai-release/mat/v2/licenses.zip -o FILE_NAME
Replace FILE_NAME with your chosen filename.
