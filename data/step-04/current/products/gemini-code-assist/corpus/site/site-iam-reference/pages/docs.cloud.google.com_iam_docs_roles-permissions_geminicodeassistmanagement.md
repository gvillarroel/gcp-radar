Gemini Code Assist Management roles
Gemini Code Assist Management offers the following service agent roles.
Service agent roles should only be granted to service agents .

Gemini Code Assist Management Service Agent
( roles/ geminicodeassistmanagement.serviceAgent )
Gives Gemini Code Assist Management Service Agent access to Cloud Platform resources.
Warning: Do not grant service agent roles to any principals except
service agents .
