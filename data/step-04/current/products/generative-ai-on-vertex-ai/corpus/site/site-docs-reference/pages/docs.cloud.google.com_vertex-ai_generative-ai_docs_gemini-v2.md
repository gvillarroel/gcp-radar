Gemma models
Gemma 4
An open model well-suited for tasks like text generation, coding, and reasoning, and supporting multimodal input (text and image for all variants, and additionally audio for the E2B and E4B variants).
Gemma 3n
An open model designed for efficient execution on low-resource devices, supporting multimodal input (text, image, video, and audio) and text output in over 140 languages.
Gemma 3
An open model featuring text and image input, support for over 140 languages, and a 128K context window.
Gemma 2
An open model supporting text generation, summarization, and extraction.
