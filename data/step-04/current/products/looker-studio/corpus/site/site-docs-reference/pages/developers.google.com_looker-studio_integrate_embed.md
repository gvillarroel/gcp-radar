Page Summary
outlined_flag
Share Looker Studio reports by embedding them into websites and applications using iframe, oEmbed, or Open Graph Tags.
Use the Embed Code option within the Looker Studio Embed Report feature to generate iframe code for embedding reports on platforms that support iframes.
Easily embed Looker Studio reports on platforms supporting oEmbed, such as Medium and Reddit, by simply pasting the report URL.
Share interactive snippets of Looker Studio reports on various social media platforms like Twitter, Facebook, and LinkedIn, by leveraging the Open Graph Protocol.
Share insights with the world by embedding a Looker Studio report in any site or
app that supports the HTML iframe tag, oEmbed, and Open Graph Tags.
Embed using iframe
You can embed reports into platforms that support iframe embeds. You can use the
Embed Code option from the Embed Report feature in Looker Studio.

support oEmbed such as Medium and Reddit. Visit embed.ly to see the
