The Cloud Interconnect API and gcloud commands are part of Compute Engine.
Cloud Interconnect provides the following API resource types and their
methods in the Compute Engine documentation:
interconnects
interconnectAttachments
interconnectLocations
crossSiteNetworks
wireGroups
For more information about the gcloud commands, see
gcloud compute interconnects
in the Google Cloud CLI documentation.
