What's next
You can get an aggregated view of support cases and Google Cloud events on the
Support page in Cloud Hub.
View open support cases, or open a new case.
Get a summary of current Google Cloud incidents and in-progress
maintenance
Learn about your support package and other support package options.
Required roles
To get the permissions that
you need to view quotas, system limits, and Compute Engine resource usage,
ask your administrator to grant you the
Cloud Hub Operator ( roles/cloudhub.operator )
IAM role on the project.
For more information about granting roles, see Manage access to projects, folders, and organizations .
You might also be able to get
the required permissions through custom
roles or other predefined
roles .
View or open support cases
In the Google Cloud console, go to the Support page,
Go to Support
From the project selector, select a project or organization.
The Support page displays support case information for the selected project
or organization.
Technical cases overview : Displays a summary of open technical cases:
My open cases : Cases that you created or are subscribed to.
Cases needing customer input : Cases that require information from you or
your team.
Total open cases : All open cases.
To view cases for any of the categories, click View cases . You can then view
details of a case from the Cases page.
The Technical cases table lists open technical cases, sorted by priority.
Click a case title to view case details.
The Google Cloud Billing Support : section lets you open a new billing
support case or view open cases.
To open a billing support case, click Get billing support .
To view open billing support cases, click View billing cases .
For more information about working with support cases, refer to the
Cloud Customer Care documentation.
Create and manage support cases .
Manage Cloud Billing support cases .
View incidents and maintenance
The Support page provides summaries of two types of Google Cloud events
that are relevant for the selected project or organization.
Incidents : A Google Cloud incident is a service outage
or degradation.
Maintenance : Maintenance activities for a Google Cloud service
supported by Unified Maintenance .
To view event information:
In the Google Cloud console, go to the Support page,
Go to Support
From the project selector, select a project or organization.
The Support page displays information for the selected project or organization.
You can view the total number of current incidents and in-progress maintenance
activities in the Google Cloud events section.
To view the incidents in Personalized Service Health, click View incidents .
To view maintenance details, click View maintenance . You can then explore
upcoming, in-progress, and planned maintenance activities on the
Maintenance page.
You can also view summaries of incidents in the Google Cloud incidents
section. To see the details of an incident in Service Health,
click the incident name.
For more information about viewing incidents, see the quickstart in
the Service Health documentation.
View support information
You can view your current support package, view other support package options,
and view the steps to get started with your current support package.
Basic Support is included for all Google Cloud customers, and provides
access to documentation , community support ,
Cloud Billing support , and
Active Assist recommendations .
To view support information:
In the Google Cloud console, go to the Support page,
Go to Support
From the project selector, select a project or organization.
The Support information section displays your current
support package .
To view other support package options click View Customer Care services .
To learn about getting started with your support package, click the
getting started link. For example, if you have the Premium package, the link
the link text is Get started with Premium support .
Setting up your support package or making changes to your support package
requires additional permissions .
