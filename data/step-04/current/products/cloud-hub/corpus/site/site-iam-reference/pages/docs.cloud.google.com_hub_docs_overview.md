What's next
Cloud Hub provides DevOps and SRE teams with a centralized view of
operations data and insights for your Google Cloud applications and resources.
Viewing this data together in one place helps you to take action on important
issues, patterns, and trends.
View active events, including Google Cloud incidents and maintenance
activities.
View health data, including Monitoring alerts and metrics
for health and performance.
View capacity data, including quota usage and Compute Engine resource
usage.
View failed App Hub application deployments and available
application updates.
View open support cases and Cloud Customer Care information.
Cloud Hub can display data for a selected Google Cloud project or
App Hub application .
View data by application
Many cloud applications evolve to include multiple infrastructure resources
from one or more Google Cloud projects, which can make it harder for both
developers and operators to manage and understand these resources. By organizing
your resources as App Hub applications, you can better
understand resource interactions and analyze, monitor, manage, and troubleshoot
in an application-centric way.
You can use App Hub to create applications from existing
Google Cloud workloads or use Application Design Center to design
and deploy new Google Cloud resources, which automatically provision App Hub applications.
To learn more about viewing data by project or by application, see
Application views and project views .
Find the information you need
Cloud Hub displays groups of related data on the following main
pages:
Home
Brings together top items from each of the categories of information in
Cloud Hub so that you can get a summary of the health and
performance of your Google Cloud resources on a single page.
Deployments
View failed application deployments from Application Design Center and the
identified cause of the failure.
View deployed applications with an available update.
Health & troubleshooting
View open alerts based on alerting policies that you set up in
Cloud Monitoring.
View active Google Cloud incidents for service outages or degradations.
View metrics about the health and performance of Google Cloud
resources such as utilization, latency, or errors.
Optimization
View the total cost and cost trend for a selected project or application.
View The top five resources or application workloads with the highest cost.
View The five most expensive resources or workloads with lowest utilization.
Quotas & reservations
View Google Cloud quotas and system limits with over 90% usage.
View historical and forecasted usage of Compute Engine resources.
View Compute Engine reservations.
Maintenance
View upcoming, in-progress, and completed maintenance activities and the
affected resources. For some types of maintenance activities, you can
reschedule the maintenance activity or apply an on-demand update.
View completed or cancelled maintenance activities.
Support
View open support cases, or open a new case.
View active Google Cloud incidents.
View in-progress maintenance.
Learn about your support package and other support package options.
