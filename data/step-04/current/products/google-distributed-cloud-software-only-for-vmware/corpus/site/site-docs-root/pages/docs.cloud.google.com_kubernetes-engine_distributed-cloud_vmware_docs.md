Read product documentation
Google Distributed Cloud (software only) for VMware extends Google Cloud's infrastructure and services into your data center. With
a software-only installation on VMware of Google Distributed Cloud, you can create and manage
GKE clusters on hardware in your VMware vSphere environment, while using
Google Cloud features. Google Distributed Cloud (software only) for VMware lets you deploy and operate containerized applications
on your clusters, at scale, using Google's infrastructure.
