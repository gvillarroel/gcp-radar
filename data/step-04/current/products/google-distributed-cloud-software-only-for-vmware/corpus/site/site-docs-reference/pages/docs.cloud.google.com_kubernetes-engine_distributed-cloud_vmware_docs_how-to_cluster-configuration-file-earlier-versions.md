Cluster configuration files for 1.16 and earlier
Stay organized with collections

You can find the cluster configuration file reference documentation for an
earlier version by adding the minor version number in the following URLs:
Admin cluster:
https:cloud.google.com/anthos/clusters/docs/on-prem/ VERSION /how-to/admin-cluster-configuration-file
User cluster:
https:cloud.google.com/anthos/clusters/docs/on-prem/ VERSION /how-to/user-cluster-configuration-file
Replace VERSION with a minor version from 1.0 to 1.16 and
copy the URL to the address bar in your browser.
