Gemini Code Assist Standard and Enterprise
Gemini Code Assist Standard and Enterprise use Google Cloud
for load-balancing, so they are able to operate globally. Because
Gemini Code Assist operates globally, you can't choose which
region to use. Gemini Code Assist can be served from the
following regions:
Americas
Iowa ( us-central1 )
Oregon ( us-west1 )
Las Vegas ( us-west4 )
N. Virginia ( us-east4 )
Europe
Belgium ( europe-west1 )
Finland ( europe-north1 )
Asia Pacific
Singapore ( asia-southeast1 )
Most Gemini in BigQuery processing occurs in the
jurisdictional boundaries of the location where the BigQuery
dataset is stored. For more information about Gemini in
BigQuery processing locations, see Where Gemini
in BigQuery processes your data .
