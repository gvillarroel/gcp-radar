# radar

This directory stores the final reports for the project.

Final reports in `radar/` must be generated from the validated source-of-truth content stored in `artifacts/`.

Current canonical layout:

- `radar/<product-slug>/card.md`
- `radar/<product-slug>/features-1.md`

`card.md` is the concise product report. `features-1.md` is the first curated feature page and each listed feature must include its IAM role mapping, with any inference clearly labeled.

All documentation stored here must be written in English.
