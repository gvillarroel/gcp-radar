# Place photo URIs

Product: Places SDK for Android
Feature slug: `place-photo-uris`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Adds the ability to retrieve photo URIs for a place in addition to photo bitmaps.
