# Queue-level HTTP target routing

Product: Cloud Tasks
Feature slug: `queue-level-http-target-routing`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Cloud Tasks lets queues define routing for HTTP target tasks so individual tasks do not need routing configuration.
