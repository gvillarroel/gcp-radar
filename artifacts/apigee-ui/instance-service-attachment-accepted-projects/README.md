# Instance service attachment accepted projects

Product: Apigee UI
Feature slug: `instance-service-attachment-accepted-projects`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The instance management UI lets users specify accepted Cloud projects that can privately connect to an instance's service attachment.
