# Legacy API Product format warning

Product: Apigee UI
Feature slug: `legacy-api-product-format-warning`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The UI displays a warning when an API Product is in legacy format and some shown fields may be legacy fields.
