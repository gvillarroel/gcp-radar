# Migration plan service disabling

Product: Migrate to Containers
Feature slug: `migration-plan-service-disabling`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Migration plans can automatically disable unneeded VM services and optionally disable additional services on the migrated container.
