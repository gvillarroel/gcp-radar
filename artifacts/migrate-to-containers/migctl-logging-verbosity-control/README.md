# Migctl logging verbosity control

Product: Migrate to Containers
Feature slug: `migctl-logging-verbosity-control`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The migctl logging set-verbosity command lets users control backend log output between info-only and debug levels.
