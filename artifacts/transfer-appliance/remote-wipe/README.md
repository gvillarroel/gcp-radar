# Remote Wipe

Product: Transfer Appliance
Feature slug: `remote-wipe`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Transfer Appliance includes an optional Remote Wipe step in the return process to erase data on the appliance before it is returned to Google.
