# ui.Button and ui.Label imageUrl option

Product: Earth Engine Code Editor
Feature slug: `ui-button-and-ui-label-imageurl-option`
Coverage: `MEDIUM`

## Technical Summary

Ui.Button and ui.Label now support an imageUrl option that displays an image instead of label text.
