# Cloud DNS forwarding

Product: Cloud DNS
Feature slug: `cloud-dns-forwarding`
Coverage: `MEDIUM`

## Technical Summary

Cloud DNS supports DNS forwarding as a managed feature; Cloud DNS forwarding allows DNS queries to be routed from Cloud DNS to other DNS resolvers.
