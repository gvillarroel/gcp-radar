# CDS document size limits

Product: Document AI
Feature slug: `cds-document-size-limits`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Custom Document Splitter supports up to 1,000-page documents for async or batch prediction and up to 200 pages for import, labeling, training, or evaluation.
