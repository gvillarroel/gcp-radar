# Form and table parsing

Product: Document AI
Feature slug: `form-and-table-parsing`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Form and table parsing lets the API extract forms or tables from PDF, TIFF, or GIF documents.
