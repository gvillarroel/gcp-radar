# Document-level prompting for custom document processors

Product: Document AI
Feature slug: `document-level-prompting-for-custom-document-processors`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

A feature that lets custom document processors use a document-level prompt to inject business context and improve extraction quality.

## Lifecycle

- Latest feature date: 2026-01-12
- Deprecation date: none recorded
- Status: feature_observed
