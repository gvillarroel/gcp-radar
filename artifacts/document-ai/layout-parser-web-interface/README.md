## Technical Summary

This preview web interface lets you inspect processed PDFs, parsed JSON, block layout, and image or table annotations, and adjust layout configuration from the console; A preview web interface for layout parser that displays processed PDFs, parsed JSON, block layouts, and image or table annotations.
