# OCR native PDF parsing

Product: Document AI
Feature slug: `ocr-native-pdf-parsing`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

OCR can extract embedded text from digital PDFs and fall back to optical OCR for non-digital regions.
