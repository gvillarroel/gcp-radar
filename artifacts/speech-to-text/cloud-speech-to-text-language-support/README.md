# Cloud Speech-to-Text language support

Product: Speech-to-Text
Feature slug: `cloud-speech-to-text-language-support`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Cloud Speech-to-Text added support for seven new languages: Burmese, Estonian, Uzbek, Punjabi, Albanian, Macedonian, and Mongolian.
