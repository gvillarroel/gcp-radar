# Facet controls

Product: Retail API
Feature slug: `facet-controls`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Facet controls let you control facet values and numerical facet intervals for search and browse operations without editing your catalog.
