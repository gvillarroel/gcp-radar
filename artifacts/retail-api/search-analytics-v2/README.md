# Search analytics v2

Product: Retail API
Feature slug: `search-analytics-v2`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Search analytics v2 provides Looker-based dashboards with detailed search and browse metrics, funnel reporting, and filtering options.
