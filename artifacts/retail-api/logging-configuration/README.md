# Logging configuration

Product: Retail API
Feature slug: `logging-configuration`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Logging configuration lets you control which Retail API service logs are written to Cloud Logging and at what severity.
