# Serving controls file import and export

Product: Retail API
Feature slug: `serving-controls-file-import-and-export`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

A capability that lets you import serving controls from files and export them to files for moving and editing controls in bulk.
