# Entities

Product: Retail API
Feature slug: `entities`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Entities let you subdivide a retail organization into separate segments for tailored recommendations, search results, and autocomplete.

## Lifecycle

- Latest feature date: 2023-06-26
- Deprecation date: none recorded
