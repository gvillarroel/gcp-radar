# Horizontal Pod Autoscaler decision logging

Product: Google Kubernetes Engine
Feature slug: `horizontal-pod-autoscaler-decision-logging`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

GKE can log atomic and final Horizontal Pod Autoscaler recommendations in Cloud Logging for visibility into autoscaling decisions.
