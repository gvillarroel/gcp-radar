Product: Google Kubernetes Engine

## Technical Summary

The HorizontalPodAutoscaler API v2beta2 defines Kubernetes pod autoscaling and is deprecated in favor of v2; HorizontalPodAutoscaler API v2beta2 is a Kubernetes beta API for workload autoscaling; deprecated on 2022-09-14.
