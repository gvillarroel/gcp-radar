# NODE_SA_MISSING_PERMISSIONS

Product: Google Kubernetes Engine
Feature slug: `node-sa-missing-permissions`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

This GKE Recommendations subtype identifies clusters whose node service accounts are missing IAM permissions needed for normal cluster operations.
