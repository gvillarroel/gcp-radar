# EndpointSlice API

Product: Google Kubernetes Engine
Feature slug: `endpointslice-api`
Coverage: `MEDIUM`

## Technical Summary

The discovery.k8s.io/v1beta1 EndpointSlice API is deprecated and will be removed in Kubernetes 1.25; EndpointSlice is available in the stable discovery.k8s.io/v1 API for scalable service discovery; deprecated on 2021-10-01.
