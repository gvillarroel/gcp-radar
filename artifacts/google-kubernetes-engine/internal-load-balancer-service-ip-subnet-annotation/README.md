# Internal Load Balancer Service IP subnet annotation

Product: Google Kubernetes Engine
Feature slug: `internal-load-balancer-service-ip-subnet-annotation`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Allows specifying a VPC subnet for internal Load Balancer Service IPs with a per-Service annotation.

## Lifecycle

- Latest feature date: 2020-05-08
- Deprecation date: none recorded
- Status: feature_observed
