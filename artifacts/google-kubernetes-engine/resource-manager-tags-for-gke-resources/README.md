# Resource Manager tags for GKE resources

Product: Google Kubernetes Engine
Feature slug: `resource-manager-tags-for-gke-resources`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The GKE API can apply Resource Manager tags to GKE resources and underlying Compute Engine VMs for selective firewall enforcement.
