# Node pool metadata updates

Product: Google Kubernetes Engine
Feature slug: `node-pool-metadata-updates`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

You can dynamically update network tags, node labels, and node taints on an existing GKE node pool.
