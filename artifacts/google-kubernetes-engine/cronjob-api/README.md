# CronJob API

Product: Google Kubernetes Engine
Feature slug: `cronjob-api`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The batch/v1beta1 CronJob API is deprecated and will be removed in Kubernetes 1.25; CronJob is available in the stable batch/v1 API for scheduled jobs; deprecated on 2021-10-01.

## Lifecycle

- Latest feature date: 2021-10-01
- Deprecation date: 2021-10-01
- Status: deprecation_noted
