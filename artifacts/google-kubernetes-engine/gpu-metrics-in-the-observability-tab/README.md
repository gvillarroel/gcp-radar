# GPU metrics in the Observability tab

Product: Google Kubernetes Engine
Feature slug: `gpu-metrics-in-the-observability-tab`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The cluster details and cluster list Observability tabs now show GPU metrics for clusters with GPU nodes.
