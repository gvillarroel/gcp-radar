# Multiple pod CIDRs

Product: Google Kubernetes Engine
Feature slug: `multiple-pod-cidrs`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Multiple pod CIDRs lets you assign a different Pod CIDR to a new node pool than the cluster creation CIDR.
