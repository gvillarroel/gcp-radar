# DaemonSet maxSurge

Product: Google Kubernetes Engine
Feature slug: `daemonset-maxsurge`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

DaemonSet maxSurge allows updated DaemonSet pods to run on nodes before old pods are removed.

## Lifecycle

- Latest feature date: 2021-10-01
- Deprecation date: none recorded
- Status: feature_observed
