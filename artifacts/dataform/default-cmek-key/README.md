# Default CMEK key

Product: Dataform
Feature slug: `default-cmek-key`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

A default CMEK key lets a project encrypt multiple Dataform repositories with the same customer-managed encryption key.
