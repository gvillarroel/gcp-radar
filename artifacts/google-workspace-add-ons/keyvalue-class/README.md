# KeyValue class

Product: Google Workspace add-ons
Feature slug: `keyvalue-class`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

A card service component for displaying a key-value pair in add-on cards; deprecated on 2021-03-09.
