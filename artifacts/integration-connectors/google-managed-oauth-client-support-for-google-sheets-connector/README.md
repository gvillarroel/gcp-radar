# Google-managed OAuth client support for Google Sheets connector

Product: Integration Connectors
Feature slug: `google-managed-oauth-client-support-for-google-sheets-connector`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Google Sheets connector can use a Google-managed OAuth client instead of a customer-created client.
