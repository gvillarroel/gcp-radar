# Google-managed OAuth client support for Gmail connector

Product: Integration Connectors
Feature slug: `google-managed-oauth-client-support-for-gmail-connector`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Gmail connector can use a Google-managed OAuth client instead of a customer-created client.
