# ODB Subnets

Product: Oracle Database@Google Cloud
Feature slug: `odb-subnets`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

ODB Subnets define subnets for Oracle Database@Google Cloud resources in an OCI child site that connect with a Google Cloud VPC network.
