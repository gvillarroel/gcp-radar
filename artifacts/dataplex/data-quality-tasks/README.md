# Data Quality tasks

Product: Dataplex
Feature slug: `data-quality-tasks`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Data Quality tasks run data quality validations on BigQuery tables, including tables outside a Dataplex lake and GCS data exposed as BigQuery external tables.
