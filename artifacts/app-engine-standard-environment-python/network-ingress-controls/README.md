Product: App Engine standard environment Python
Feature slug: `network-ingress-controls`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Network ingress controls can restrict an App Engine app to receive requests only through Cloud Load Balancing.
