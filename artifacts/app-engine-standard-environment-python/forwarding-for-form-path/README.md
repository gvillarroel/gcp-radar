# Forwarding for /form path

Product: App Engine standard environment Python
Feature slug: `forwarding-for-form-path`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

App Engine now allows the /form URL path and forwards requests on that path to applications.
