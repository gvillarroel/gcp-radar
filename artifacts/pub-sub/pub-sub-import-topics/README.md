Product: Pub/Sub
Feature slug: `pub-sub-import-topics`
Coverage: `MEDIUM`

## Technical Summary

Import topics let you ingest streaming data into Pub/Sub from Azure Event Hubs, Amazon Managed Streaming for Apache Kafka, and Confluent Cloud.
