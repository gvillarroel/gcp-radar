# HeaderName support for Authentication bearer token header customization

Product: Apigee hybrid
Feature slug: `headername-support-for-authentication-bearer-token-header-customization`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Apigee hybrid adds the HeaderName element under Authentication so ServiceCallout, ExternalCallout, and TargetEndpoint configurations can use a custom header for bearer tokens.

## Lifecycle

- Latest feature date: 2023-11-17
- Deprecation date: none recorded
- Status: feature_observed

## IAM

No defensible IAM mapping was found in the current evidence.
