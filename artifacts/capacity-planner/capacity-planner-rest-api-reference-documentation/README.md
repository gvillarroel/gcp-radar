## Technical Summary

Capacity Planner REST API reference is the official Google Cloud documentation for the Capacity Planner programmatic interface, exposing v1beta REST resources and methods for projects, organizations, and folders (including forecast query/export and usage/history operations). The reference includes schema pages such as ForecastType and QueryForecastsResponse that define forecast data model details, and endpoint-level pages document required authorization scopes and IAM permission requirements for those calls.
