# K8sPSPAutomountServiceAccountTokenPod constraint template

Product: Anthos Config Management
Feature slug: `k8spspautomountserviceaccounttokenpod-constraint-template`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

This constraint template governs automounting of service account tokens in pods.
