# Config Sync private Helm repository sync

Product: Anthos Config Management
Feature slug: `config-sync-private-helm-repository-sync`
Coverage: `MEDIUM`

## Technical Summary

Config Sync can sync from private Helm repositories, including OCI-based repositories, as a preview capability.
