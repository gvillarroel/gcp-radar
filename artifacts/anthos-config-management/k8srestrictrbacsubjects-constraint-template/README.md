# K8sRestrictRbacSubjects constraint template

Product: Anthos Config Management
Feature slug: `k8srestrictrbacsubjects-constraint-template`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

This constraint template restricts which RBAC subjects can be used in Kubernetes access control objects.
