# Policy Controller namespace exclusions

Product: Anthos Config Management
Feature slug: `policy-controller-namespace-exclusions`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Policy Controller namespace exclusions let specified namespaces bypass admission control enforcement.

## Lifecycle

- Latest feature date: 2020-04-23
- Deprecation date: none recorded
- Status: feature_observed
