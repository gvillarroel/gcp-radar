# Additional conversion directives for Oracle/SQL Server to PostgreSQL migrations

Product: Cloud Database Migration Service
Feature slug: `additional-conversion-directives-for-oracle-sql-server-to-postgresql-migrations`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Heterogeneous migrations now support RENAME, MOVE, CASE_HANDLING, and GENERATE_MISSING_PK directives to control Oracle and SQL Server object conversion to PostgreSQL.
