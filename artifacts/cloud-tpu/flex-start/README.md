# Flex-start

Product: Cloud TPU
Feature slug: `flex-start`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Flex-start is a flexible Cloud TPU consumption option that dynamically provisions TPUs for up to seven days without long-term reservations.
