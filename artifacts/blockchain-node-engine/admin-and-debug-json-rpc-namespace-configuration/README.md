# Admin and debug JSON-RPC namespace configuration

Product: Blockchain Node Engine
Feature slug: `admin-and-debug-json-rpc-namespace-configuration`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary
