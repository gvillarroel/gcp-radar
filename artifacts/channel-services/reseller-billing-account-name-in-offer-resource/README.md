# Reseller Billing Account name in Offer resource

Product: Channel Services
Feature slug: `reseller-billing-account-name-in-offer-resource`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Makes the Reseller Billing Account name field available in the Offer resource to map Google Cloud Platform offers to reseller billing account names from Cloud Console.

## Lifecycle

- Latest feature date: 2021-02-23
- Deprecation date: none recorded
- Status: feature_observed
