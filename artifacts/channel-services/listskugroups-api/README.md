# ListSkuGroups API

Product: Channel Services
Feature slug: `listskugroups-api`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Introduces the ListSkuGroups public API to list rebilling-supported SKU groups that can be configured in customer or channel partner repricing.
