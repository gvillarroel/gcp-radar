# Translation Hub post-editing workflow

Product: Translation Hub
Feature slug: `translation-hub-post-editing-workflow`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Translation Hub's post-editing workflow enables administrators to organize translators and post-editing groups, while portal users can request post-edits that translators review and edit.
