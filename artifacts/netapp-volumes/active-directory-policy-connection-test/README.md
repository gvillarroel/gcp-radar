# Active Directory policy connection test

Product: NetApp Volumes
Feature slug: `active-directory-policy-connection-test`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Lets you test whether an Active Directory policy is properly connected to the Active Directory service in the Google Cloud console.
