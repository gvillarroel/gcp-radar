# NFS all-squash

Product: NetApp Volumes
Feature slug: `nfs-all-squash`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

NFS all-squash maps all client user IDs to a single anonymous user ID to improve security.
