# Active Directory policies

Product: NetApp Volumes
Feature slug: `active-directory-policies`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

You can create more than one Active Directory policy in each region; Active Directory policies can manage the BUILTIN\\Administrators group.
