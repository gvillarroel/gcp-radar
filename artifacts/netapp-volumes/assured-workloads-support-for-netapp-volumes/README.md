# Assured Workloads support for NetApp Volumes

Product: NetApp Volumes
Feature slug: `assured-workloads-support-for-netapp-volumes`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Enables Google Cloud NetApp Volumes to be used with Assured Workloads in supported regions.
