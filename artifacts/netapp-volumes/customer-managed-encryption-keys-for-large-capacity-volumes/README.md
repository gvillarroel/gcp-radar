# Customer-managed encryption keys for large capacity volumes

Product: NetApp Volumes
Feature slug: `customer-managed-encryption-keys-for-large-capacity-volumes`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Allows large-capacity volumes to be encrypted with customer-managed encryption keys.

- Latest feature date: 2025-01-23
