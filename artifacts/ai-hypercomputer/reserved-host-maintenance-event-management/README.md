# Reserved-host maintenance event management

Product: AI Hypercomputer
Feature slug: `reserved-host-maintenance-event-management`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

You can now proactively manage upcoming host maintenance events on reserved capacity blocks, whether VMs are running or not, to reduce disruption and help maintain performance.
