# Cost Table Nested View

Product: Cloud Billing
Feature slug: `cost-table-nested-view`
Coverage: `MEDIUM`

## Technical Summary

Adds a nested, tree-structured table view to the Cloud Billing Cost Table report for hierarchical cost analysis.
