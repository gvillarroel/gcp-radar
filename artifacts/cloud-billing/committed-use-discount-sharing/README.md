# Committed use discount sharing

Product: Cloud Billing
Feature slug: `committed-use-discount-sharing`
Coverage: `MEDIUM`

## Technical Summary

Introduced generally available discount sharing so committed use discounts can be applied across multiple projects within a single Cloud Billing account; Enables applying purchased committed-use discounts across multiple projects within a single Cloud Billing account.
