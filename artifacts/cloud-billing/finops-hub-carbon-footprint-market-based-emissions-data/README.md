# FinOps hub carbon footprint market-based emissions data

Product: Cloud Billing
Feature slug: `finops-hub-carbon-footprint-market-based-emissions-data`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

The Carbon Footprint dashboard in FinOps hub now includes Scope 2 market-based emissions data in preview as an additional emissions metric option.
