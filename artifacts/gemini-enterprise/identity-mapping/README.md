# Identity mapping

Product: Gemini Enterprise
Feature slug: `identity-mapping`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Administrators can map external SaaS identities to their identity provider so Google can enforce access control correctly.
