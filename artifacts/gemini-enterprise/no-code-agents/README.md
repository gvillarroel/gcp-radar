# No-code agents

Product: Gemini Enterprise
Feature slug: `no-code-agents`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

No-code agents can be configured with specific assistant action tools to help accomplish their assigned tasks; No-code agents can be created with specific data sources to control what information they can access during conversations.
