# ServiceNow catalog entity knowledge base filter

Product: Gemini Enterprise
Feature slug: `servicenow-catalog-entity-knowledge-base-filter`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

ServiceNow connectors can filter knowledge base entities by catalog ID so only matching catalogSysId values are ingested.
