# Optimized data ingestion

Product: Gemini Enterprise
Feature slug: `optimized-data-ingestion`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Agentspace Enterprise optimizes data ingestion during syncs based on assistant answer quality and supports filters to choose what data is ingested.
