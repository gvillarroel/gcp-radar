# IDS Threat Exceptions

Product: Cloud IDS
Feature slug: `ids-threat-exceptions`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

IDS Threat Exceptions lets you disable specific noisy or unnecessary threat IDs when creating or updating a Cloud IDS endpoint.
