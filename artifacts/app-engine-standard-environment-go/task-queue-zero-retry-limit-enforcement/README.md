# Task Queue zero retry limit enforcement

Product: App Engine standard environment Go
Feature slug: `task-queue-zero-retry-limit-enforcement`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Failed tasks in queues with a retry_limit of zero are no longer retried.
