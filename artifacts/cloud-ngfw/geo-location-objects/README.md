# Geo-location objects

Product: Cloud NGFW
Feature slug: `geo-location-objects`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Geo-location objects let firewall policy rules filter external IPv4 and IPv6 traffic by geographic location or region.

## Lifecycle

- Latest feature date: 2023-06-05
- Deprecation date: none recorded
