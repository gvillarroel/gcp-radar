# FQDN objects

Product: Cloud NGFW
Feature slug: `fqdn-objects`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

FQDN objects let firewall policy rules filter incoming or outgoing traffic for specific domain names.
