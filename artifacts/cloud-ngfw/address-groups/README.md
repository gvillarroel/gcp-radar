# Address groups

Product: Cloud NGFW
Feature slug: `address-groups`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Address groups are reusable collections of IPv4 or IPv6 CIDR ranges that can be referenced across firewall policy rules.
