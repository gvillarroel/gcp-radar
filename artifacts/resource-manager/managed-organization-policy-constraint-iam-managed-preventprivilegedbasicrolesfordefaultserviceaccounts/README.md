# Managed organization policy constraint iam.managed.preventPrivilegedBasicRolesForDefaultServiceAccounts

Product: Resource Manager
Feature slug: `managed-organization-policy-constraint-iam-managed-preventprivilegedbasicrolesfordefaultserviceaccounts`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

This managed organization policy constraint prevents default service accounts from being granted the Editor or Owner role.
