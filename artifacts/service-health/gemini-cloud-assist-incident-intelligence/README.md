# Gemini Cloud Assist incident intelligence

Product: Service Health
Feature slug: `gemini-cloud-assist-incident-intelligence`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Service Health now allows users to ask Gemini Cloud Assist for active incidents, incident impact, and update information.
