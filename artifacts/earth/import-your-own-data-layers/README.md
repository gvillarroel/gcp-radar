# Import your own data layers

Product: Earth
Feature slug: `import-your-own-data-layers`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Users can import their own large-scale KML and GeoJSON datasets into Google Earth projects as data layers.
