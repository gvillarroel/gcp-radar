# Mobile data layer import

Product: Earth
Feature slug: `mobile-data-layer-import`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Users can import large vector datasets and add KML, KMZ, and GeoJSON files as data layers from a mobile device.

- Latest feature date: 2026-02-25
- Deprecation date: none recorded
