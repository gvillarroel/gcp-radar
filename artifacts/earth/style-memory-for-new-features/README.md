# Style memory for new features

Product: Earth
Feature slug: `style-memory-for-new-features`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Google Earth can automatically reuse the most recent style for newly created points, lines, and polygons of the same type.

## Lifecycle

- Latest feature date: 2025-11-20
- Deprecation date: none recorded
- Status: feature_observed
