# Feature style copy and paste

Product: Earth
Feature slug: `feature-style-copy-and-paste`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Users can copy a style from one point, line, or polygon and paste it onto another feature of the same type.
