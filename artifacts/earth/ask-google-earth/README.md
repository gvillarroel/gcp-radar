# Ask Google Earth

Product: Earth
Feature slug: `ask-google-earth`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Users can create and analyze geospatial datasets by asking natural-language questions about spatial relationships and project context.
