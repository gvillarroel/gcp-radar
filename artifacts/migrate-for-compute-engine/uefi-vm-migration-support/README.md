# UEFI VM migration support

Product: Migrate for Compute Engine
Feature slug: `uefi-vm-migration-support`
Coverage: `MEDIUM`

## Technical Summary

Migrate for Compute Engine can migrate UEFI-based virtual machines to Google Cloud UEFI-enabled hosts.
