# Server-side apply metadata auto-trigger

Product: Config Connector
Feature slug: `server-side-apply-metadata-auto-trigger`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Config Connector can automatically trigger server-side apply metadata on resources in supported Kubernetes clusters.
