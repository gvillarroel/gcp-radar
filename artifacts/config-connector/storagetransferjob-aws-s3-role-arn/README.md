# StorageTransferJob AWS S3 role ARN

Product: Config Connector
Feature slug: `storagetransferjob-aws-s3-role-arn`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The StorageTransferJob resource supports specifying an AWS S3 role ARN through spec.transferSpec.awsS3DataSource.roleArn.
