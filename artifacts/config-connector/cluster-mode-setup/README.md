# Cluster-mode setup

Product: Config Connector
Feature slug: `cluster-mode-setup`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Cluster-mode setup lets Config Connector use one Google Service Account across all namespaces in a cluster.

## Lifecycle

- Latest feature date: 2020-07-16
- Deprecation date: none recorded
