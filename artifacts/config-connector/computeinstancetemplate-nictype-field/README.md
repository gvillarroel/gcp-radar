# ComputeInstanceTemplate nicType field

Product: Config Connector
Feature slug: `computeinstancetemplate-nictype-field`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The nicType field on ComputeInstanceTemplate configures the network interface type for instance templates; ComputeInstanceTemplate supports the nicType field; deprecated on 2021-03-25.
