# Namespaced mode multi-service-account authentication

Product: Config Connector
Feature slug: `namespaced-mode-multi-service-account-authentication`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Namespaced mode lets Config Connector authenticate to multiple Google Service Accounts using different Kubernetes Service Accounts.

## Lifecycle

- Latest feature date: 2020-01-23
- Deprecation date: none recorded
- Status: feature_observed
