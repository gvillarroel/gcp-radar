# ComputeInstance spec.networkInterface[].networkIp field

Product: Config Connector

Coverage: `MEDIUM`

## Technical Summary

The ComputeInstance resource includes a spec.networkInterface[].networkIp field for setting a network interface IP address directly; deprecated on 2022-04-21.
