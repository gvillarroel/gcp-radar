# HL7v2

Product: Cloud Healthcare API
Feature slug: `hl7v2`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

User labels were added to DICOM, HL7v2, and FHIR stores to support resource filtering and billing charge views by label.
