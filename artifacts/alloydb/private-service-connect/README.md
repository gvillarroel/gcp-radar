# Private Service Connect

Product: AlloyDB
Feature slug: `private-service-connect`
Coverage: `MEDIUM`

## Technical Summary

Private Service Connect lets clients connect to an AlloyDB instance from multiple VPC networks across groups, projects, or organizations.
