# Flexible pattern matching for URL maps

Product: Cloud Load Balancing
Feature slug: `flexible-pattern-matching-for-url-maps`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Supported Application Load Balancers can use wildcard pattern matching in URL map path matchers for advanced traffic management; Global external HTTP(S) load balancers support wildcard pattern matching in path matchers for advanced traffic management.
