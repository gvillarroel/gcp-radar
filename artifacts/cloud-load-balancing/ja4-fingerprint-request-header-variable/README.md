# JA4 fingerprint request header variable

Product: Cloud Load Balancing
Feature slug: `ja4-fingerprint-request-header-variable`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Global external Application Load Balancers can add the JA4 fingerprint to custom request headers by using the tls_ja4_fingerprint variable.
