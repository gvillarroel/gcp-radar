# ESP and ICMP traffic support for Network Load Balancing

Product: Cloud Load Balancing
Feature slug: `esp-and-icmp-traffic-support-for-network-load-balancing`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Network Load Balancing supports load balancing ESP and ICMP traffic by using the L3_DEFAULT forwarding rule protocol.

## Lifecycle

- Latest feature date: 2021-06-09
- Deprecation date: none recorded
- Status: feature_observed
