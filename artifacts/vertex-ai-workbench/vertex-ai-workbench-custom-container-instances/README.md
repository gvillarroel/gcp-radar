# Vertex AI Workbench custom container instances

Product: Vertex AI Workbench
Feature slug: `vertex-ai-workbench-custom-container-instances`
Coverage: `MEDIUM`

## Technical Summary

Vertex AI Workbench now supports creating instances from custom containers, with support limited to custom containers derived from the Google-provided base container.
