# Custom container images for AI Platform Notebooks instances

Product: Vertex AI Workbench
Feature slug: `custom-container-images-for-ai-platform-notebooks-instances`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

AI Platform Notebooks can now be deployed using custom container images, including Deep Learning Containers derivatives.

## Lifecycle

- Latest feature date: 2019-09-09
- Deprecation date: none recorded
- Status: feature_observed
