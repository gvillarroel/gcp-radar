# Agent Assessments

Product: Contact Center AI Insights
Feature slug: `agent-assessments`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Agent assessments evaluate individual conversations and let human evaluators add notes and feedback for the agent.
