# Topic Modeling

Product: Contact Center AI Insights
Feature slug: `topic-modeling`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Topic modeling discovers topics or call drivers in conversations between contact center agents and end users.

- Latest feature date: 2022-11-15
- Deprecation date: none recorded
