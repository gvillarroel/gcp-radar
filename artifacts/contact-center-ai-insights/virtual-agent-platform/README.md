# Virtual Agent Platform

Product: Contact Center AI Insights
Feature slug: `virtual-agent-platform`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

The virtual agent platform provides aggregated quality management metrics for virtual agent conversations, including escalation rate, latency, and customer sentiment.
