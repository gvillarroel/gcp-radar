# Autolabeling Rules

Product: Contact Center AI Insights
Feature slug: `autolabeling-rules`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Autolabeling rules automatically apply key-value labels to conversations based on defined conditions.
