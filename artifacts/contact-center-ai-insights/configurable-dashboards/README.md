# Configurable Dashboards

Product: Contact Center AI Insights
Feature slug: `configurable-dashboards`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Configurable dashboards let users build custom dashboards for usage and feedback metrics with chart options and AI assistance.
