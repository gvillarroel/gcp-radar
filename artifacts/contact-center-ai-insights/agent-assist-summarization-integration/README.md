# Agent Assist Summarization Integration

Product: Contact Center AI Insights
Feature slug: `agent-assist-summarization-integration`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Agent Assist summarization integration lets Conversational Insights use existing LLM generators to create conversation summaries for export.
