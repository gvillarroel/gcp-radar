# Sentiment Analysis

Product: Contact Center AI Insights
Feature slug: `sentiment-analysis`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Sentiment analysis detects the mood of a conversation and assigns a positive, neutral, or negative score.
