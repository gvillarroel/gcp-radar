Product: Contact Center AI Insights
Feature slug: `conversational-insights-devkit`
Coverage: `MEDIUM`

## Technical Summary

The Conversational Insights devkit helps developers import conversations, transcribe audio, create recognizers, transform transcript formats, and manage global settings.
