# Analysis Rules for Follow-Up Analysis

Product: Contact Center AI Insights
Feature slug: `analysis-rules-for-follow-up-analysis`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Analysis rules for follow-up analysis let CX Insights analyze one group of conversations based on results from another group.

- Latest feature date: 2026-01-31
- Deprecation date: none recorded
