# Discovery client telemetry collection

Product: Migration Center
Feature slug: `discovery-client-telemetry-collection`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

The Discovery client can collect usage and other anonymized data to help improve the product.
