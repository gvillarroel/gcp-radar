# vCenter discovery guest OS credentials

Product: Migration Center
Feature slug: `vcenter-discovery-guest-os-credentials`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

You can add new guest OS credentials from the vCenter discovery page.
