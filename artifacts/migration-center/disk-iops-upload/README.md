# Disk IOPS upload

Product: Migration Center
Feature slug: `disk-iops-upload`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Migration Center can upload disk read and write IOPS data to improve pricing and sizing reports.
