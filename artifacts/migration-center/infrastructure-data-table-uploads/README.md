# Infrastructure data table uploads

Product: Migration Center
Feature slug: `infrastructure-data-table-uploads`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Migration Center lets users upload infrastructure data tables created from available templates, with file uploads up to 100 MB.
