# Apigee prepaid billing for developers

Product: Apigee Monetization
Feature slug: `apigee-prepaid-billing-for-developers`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Apigee introduced prepaid billing for developers, allowing them to pay in advance, store multiple currencies in a developer wallet, monitor balance in real time, and block API calls when funds are insufficient.

## Lifecycle

- Latest feature date: 2021-11-03
- Deprecation date: none recorded
