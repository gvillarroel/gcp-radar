# Monetization Transaction Success Criteria

Product: Apigee Monetization
Feature slug: `monetization-transaction-success-criteria`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Monetization supports configuring the transactionSuccess variable in the DataCapture policy to control whether a transaction is monetized.
