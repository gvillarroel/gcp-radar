# Security Insights dashboard

Product: Policy Intelligence
Feature slug: `security-insights-dashboard`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Security Insights dashboard lets IAM administrators review and manage identity risks across an organization, folder, or project in the Google Cloud console.
