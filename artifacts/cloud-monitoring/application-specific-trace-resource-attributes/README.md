Product: Cloud Monitoring
Feature slug: `application-specific-trace-resource-attributes`

## Technical Summary

Trace data can include application-specific resource attributes for supported Google Cloud resources and OpenTelemetry-instrumented applications using the Google Cloud Telemetry endpoint.
