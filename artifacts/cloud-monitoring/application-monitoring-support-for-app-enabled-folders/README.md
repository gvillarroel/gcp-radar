# Application Monitoring support for app-enabled folders

Product: Cloud Monitoring
Feature slug: `application-monitoring-support-for-app-enabled-folders`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Application Monitoring supports app-enabled folders with automatic synchronization of the management project's metrics scope to folder projects when quota is available.
