# Ops Agent installation from VM Instances dashboard

Product: Cloud Monitoring
Feature slug: `ops-agent-installation-from-vm-instances-dashboard`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Monitoring VM Instances dashboard can generate Cloud Shell commands to install the Ops Agent or legacy agents on selected Compute Engine VMs.
