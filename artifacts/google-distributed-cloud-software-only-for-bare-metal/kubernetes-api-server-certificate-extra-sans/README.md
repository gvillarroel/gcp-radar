# Kubernetes API server certificate extra SANs

Product: Google Distributed Cloud (software only) for bare metal
Feature slug: `kubernetes-api-server-certificate-extra-sans`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Lets you add extra subject alternative name entries to the Kubernetes API server certificate.
