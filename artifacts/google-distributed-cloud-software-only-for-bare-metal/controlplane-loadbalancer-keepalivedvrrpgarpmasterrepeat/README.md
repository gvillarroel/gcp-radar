# controlPlane.loadBalancer.keepalivedVRRPGARPMasterRepeat

Product: Google Distributed Cloud (software only) for bare metal
Feature slug: `controlplane-loadbalancer-keepalivedvrrpgarpmasterrepeat`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

This cluster configuration field sets how many gratuitous ARP messages Keepalived sends when a control plane node becomes master.
