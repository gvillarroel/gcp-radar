# Multiple BGPLoadBalancer resources

Product: Google Distributed Cloud (software only) for bare metal
Feature slug: `multiple-bgploadbalancer-resources`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Lets you define multiple BGPLoadBalancer resources to control how peers advertise load balancer nodes and services.
