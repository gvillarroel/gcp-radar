# POSIX groups

Product: Cloud Identity
Feature slug: `posix-groups`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

POSIX groups let Cloud Identity groups use POSIX attributes for Unix-style identity and access integration; deprecated on 2024-09-26.

## Lifecycle
