# IAM attributes in custom organization policies

Product: Identity and Access Management
Feature slug: `iam-attributes-in-custom-organization-policies`
Coverage: `MEDIUM`

## Technical Summary

IAM attributes can be used in custom organization policies to control how allow policies are modified.
