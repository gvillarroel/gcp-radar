# Google Groups management in Cloud Console

Product: Identity and Access Management
Feature slug: `google-groups-management-in-cloud-console`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

You can now manage Google Groups from the Cloud Console.

- Latest feature date: 2020-05-19
- Deprecation date: none recorded
- Status: feature_observed
