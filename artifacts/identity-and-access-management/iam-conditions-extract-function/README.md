# IAM Conditions extract() function

Product: Identity and Access Management
Feature slug: `iam-conditions-extract-function`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

IAM Conditions now supports the extract() function for referring to arbitrary parts of a resource name.
