# IAM Conditions resource attributes for Apigee X

Product: Identity and Access Management
Feature slug: `iam-conditions-resource-attributes-for-apigee-x`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Adds Apigee X resource attributes to IAM Conditions so you can grant access to a subset of Apigee X resources.
