# Privileged Access Manager access grant modification alerts

Product: Identity and Access Management
Feature slug: `privileged-access-manager-access-grant-modification-alerts`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Privileged Access Manager can alert on external modifications to access grants made outside of PAM.

## Lifecycle

- Latest feature date: 2024-09-16
- Deprecation date: none recorded
- Status: feature_observed
