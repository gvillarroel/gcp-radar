# Service account insights

Product: Identity and Access Management
Feature slug: `service-account-insights`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

IAM Recommender can now generate insights for service accounts that you can manage.

## Lifecycle

- Latest feature date: 2020-10-16
- Deprecation date: none recorded
- Status: feature_observed
