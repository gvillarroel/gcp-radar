# Privileged Access Manager VPC Service Controls integration

Product: Identity and Access Management
Feature slug: `privileged-access-manager-vpc-service-controls-integration`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Privileged Access Manager integrates with VPC Service Controls to enforce authorized network access or access context.
