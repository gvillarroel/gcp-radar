# Tags-based access control

Product: Identity and Access Management
Feature slug: `tags-based-access-control`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Tags can be attached to resources and used to manage access to those resources.

## Lifecycle

- Latest feature date: 2021-02-09
- Deprecation date: none recorded
- Status: feature_observed
