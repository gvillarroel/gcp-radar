# CustomInfoType custom dictionaries

Product: Sensitive Data Protection
Feature slug: `custominfotype-custom-dictionaries`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Allows user-provided custom dictionaries to be used for infoType matching in inspection, redaction, de-identification, and inspection operations.
