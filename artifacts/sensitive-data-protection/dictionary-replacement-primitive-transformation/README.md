# Dictionary replacement primitive transformation

Product: Sensitive Data Protection
Feature slug: `dictionary-replacement-primitive-transformation`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The dictionary replacement primitive transformation replaces detected sensitive values with random values from a supplied word list.
