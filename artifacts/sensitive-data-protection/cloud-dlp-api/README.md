# Cloud DLP API

Product: Sensitive Data Protection
Feature slug: `cloud-dlp-api`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Cloud DLP API provides REST-based sensitive data classification and management for text, images, Cloud Storage, and Cloud Datastore.

- Latest feature date: 2017-03-09
- Deprecation date: none recorded
