# COUNTRY_DEMOGRAPHIC infoType detector

Product: Sensitive Data Protection

Coverage: `MEDIUM`

## Technical Summary

The COUNTRY_DEMOGRAPHIC built-in infoType detector identifies references to countries used for place of birth, residency, or citizenship.
