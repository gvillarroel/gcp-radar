# Image auto-redaction

Product: Sensitive Data Protection
Feature slug: `image-auto-redaction`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Automatically redacts all text from images and supports custom fill colors for image redaction bounding boxes.

- Latest feature date: 2017-06-15
- Deprecation date: none recorded
