# Cloud CDN TLS v1.3 by default

Product: Cloud CDN
Feature slug: `cloud-cdn-tls-v1-3-by-default`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Cloud CDN is enabled for TLS v1.3 by default on applicable external load balancer integrations.
