# Cloud CDN Signed Cookies

Product: Cloud CDN
Feature slug: `cloud-cdn-signed-cookies`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Cloud CDN Signed Cookies are generally available and allow signing a URL prefix and issuing cookies for protected cached content.
