# Direct event triggers from Cloud Firestore with authentication context

Product: Eventarc
Feature slug: `direct-event-triggers-from-cloud-firestore-with-authentication-context`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Eventarc can create triggers for direct events from Cloud Firestore that include authentication context.

- Deprecation date: none recorded
