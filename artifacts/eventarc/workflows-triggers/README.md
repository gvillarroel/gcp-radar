# Workflows triggers

Product: Eventarc
Feature slug: `workflows-triggers`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Eventarc can create triggers for Workflows destinations from the Eventarc page in Cloud Console; Eventarc can trigger Workflows destinations.
