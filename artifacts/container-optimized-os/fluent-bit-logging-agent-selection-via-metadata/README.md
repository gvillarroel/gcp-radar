# Fluent Bit logging agent selection via metadata

Product: Container Optimized OS
Feature slug: `fluent-bit-logging-agent-selection-via-metadata`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Container-Optimized OS can use the Fluent Bit logging agent when the google-logging-use-fluentbit metadata key is enabled.
