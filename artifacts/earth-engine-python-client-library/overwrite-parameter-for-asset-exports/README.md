# Overwrite parameter for asset exports

Product: Earth Engine Python Client Library
Feature slug: `overwrite-parameter-for-asset-exports`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Adds an overwrite parameter to Export.image.toAsset() and Export.table.toAsset() so exports can overwrite existing destination assets.

- Latest feature date: 2025-11-30
