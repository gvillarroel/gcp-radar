# Collection.map() opt_dropNulls option

Product: Earth Engine Python Client Library
Feature slug: `collection-map-opt-dropnulls-option`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Adds an opt_dropNulls argument to Collection.map() to drop null results.
