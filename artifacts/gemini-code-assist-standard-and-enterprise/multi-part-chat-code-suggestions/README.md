# multi-part chat code suggestions

Product: Gemini Code Assist Standard and Enterprise
Feature slug: `multi-part-chat-code-suggestions`

## Technical Summary

Gemini Code Assist can generate multi-part code suggestions in IntelliJ chat and let you accept one change or all changes; VS Code Gemini Code Assist can generate multi-part chat code suggestions that can be accepted individually or all at once.
