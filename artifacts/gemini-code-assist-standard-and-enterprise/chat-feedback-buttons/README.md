# Chat feedback buttons

Product: Gemini Code Assist Standard and Enterprise
Feature slug: `chat-feedback-buttons`
Coverage: `MEDIUM`

## Technical Summary

Provides thumbs up and thumbs down feedback controls for chat responses; Adds thumbs up and thumbs down buttons in the IntelliJ Duet AI plug-in chat window for response quality feedback.
