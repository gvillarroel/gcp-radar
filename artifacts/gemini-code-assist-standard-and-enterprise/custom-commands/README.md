# Custom commands

Product: Gemini Code Assist Standard and Enterprise
Feature slug: `custom-commands`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Lets you create, save, and run preconfigured prompts for repetitive tasks in IntelliJ Gemini Code Assist; VS Code Gemini Code Assist supports custom commands in the inline chat menu and lightbulb menu.
