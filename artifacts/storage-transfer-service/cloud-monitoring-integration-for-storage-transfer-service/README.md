# Cloud Monitoring integration for Storage Transfer Service

Product: Storage Transfer Service
Feature slug: `cloud-monitoring-integration-for-storage-transfer-service`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Storage Transfer Service adds GA support for Cloud Monitoring, enabling metrics on object and data transfer counts, transfer speeds, errors, and error codes.
