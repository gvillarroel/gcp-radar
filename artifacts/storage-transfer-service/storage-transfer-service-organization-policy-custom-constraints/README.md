# Storage Transfer Service organization policy custom constraints

Product: Storage Transfer Service
Feature slug: `storage-transfer-service-organization-policy-custom-constraints`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Storage Transfer Service now supports Organization Policy custom constraints to control and restrict how transfers are configured and allowed within an organization.
