# Cloud Storage volume mount options

Product: Cloud Run
Feature slug: `cloud-storage-volume-mount-options`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Cloud Storage volume mounts let Cloud Run services and jobs specify mount options when attaching buckets as volumes.
