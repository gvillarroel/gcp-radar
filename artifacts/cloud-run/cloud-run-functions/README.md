# Cloud Run functions

Product: Cloud Run
Feature slug: `cloud-run-functions`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Cloud Run functions let you deploy and directly update functions in Cloud Run, including functions created with the Cloud Functions v2 API.
