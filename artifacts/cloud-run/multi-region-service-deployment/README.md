# Multi-region service deployment

Product: Cloud Run
Feature slug: `multi-region-service-deployment`
Coverage: `MEDIUM`

## Technical Summary

Multi-region service deployment lets you deploy and configure a Cloud Run multi-region service with a single gcloud command.
