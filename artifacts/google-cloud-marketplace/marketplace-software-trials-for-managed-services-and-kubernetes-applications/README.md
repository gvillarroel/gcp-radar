# Marketplace software trials for managed services and Kubernetes applications

Product: Google Cloud Marketplace
Feature slug: `marketplace-software-trials-for-managed-services-and-kubernetes-applications`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Vendors of managed services and Kubernetes applications can offer software trials without charging the software license during the trial.
