# Organization-owned logs

Product: Cloud Logging
Feature slug: `organization-owned-logs`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Logging API allows organizations as well as projects to own logs with organization-scoped log names.
