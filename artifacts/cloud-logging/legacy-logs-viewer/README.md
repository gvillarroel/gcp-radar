# Legacy Logs Viewer

Product: Cloud Logging
Feature slug: `legacy-logs-viewer`
Coverage: `MEDIUM`

## Technical Summary

Legacy Logs Viewer is the older log viewing interface that is being retired in favor of Logs Explorer; deprecated on 2022-03-01.
