# Spanner UUID data type support

Product: Spanner
Feature slug: `spanner-uuid-data-type-support`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Spanner now supports a UUID data type in both GoogleSQL and PostgreSQL dialect databases for storing 128-bit universal unique identifiers.
