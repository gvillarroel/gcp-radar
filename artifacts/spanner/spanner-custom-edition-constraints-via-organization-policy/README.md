# Spanner custom edition constraints via organization policy

Product: Spanner
Feature slug: `spanner-custom-edition-constraints-via-organization-policy`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Organizations can define custom edition constraints in organization policies to restrict which Spanner instance editions users can create.
