# text.url_decode function

Product: Workflows
Feature slug: `text-url-decode-function`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The text.url_decode function converts plus signs and percent-escaped characters to UTF-8 text.
