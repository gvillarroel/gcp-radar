# Conda-free container images

Product: Deep Learning Containers
Feature slug: `conda-free-container-images`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

New Deep Learning Containers images, except TensorFlow images, are published without Conda to reduce image size, improve performance, and simplify vulnerability management.
