# HA network architecture upgrade for multiple instances

Product: Cloud SQL for MySQL
Feature slug: `ha-network-architecture-upgrade-for-multiple-instances`
Coverage: `MEDIUM`

## Technical Summary

Cloud SQL lets you upgrade network architecture for HA-enabled instances in a region even when multiple instances share the same network and region.
