# Domain-wide add-on installation

Product: Apps Script
Feature slug: `domain-wide-add-on-installation`
Coverage: `MEDIUM`

## Technical Summary

Admins can install and authorize Docs, Sheets, and Forms add-ons for all users in a domain.
