# Ui.createAddonMenu()

Product: Apps Script
Feature slug: `ui-createaddonmenu`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Ui.createAddonMenu() lets scripts add a submenu to the Add-ons menu in Google Sheets or Docs.
