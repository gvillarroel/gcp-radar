# Script identity tokens

Product: Apps Script
Feature slug: `script-identity-tokens`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Apps Script Script service adds ScriptApp.getIdentityToken() to return an identity token for the effective user.
