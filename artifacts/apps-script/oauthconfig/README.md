# OAuthConfig

Product: Apps Script
Feature slug: `oauthconfig`
Coverage: `MEDIUM`

## Technical Summary

OAuthConfig was the URL Fetch service class for connecting to OAuth 1.0 APIs; deprecated on 2015-03-04.
