# DocsListDialog OAuth token support

Product: Apps Script
Feature slug: `docslistdialog-oauth-token-support`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

DocsListDialog can accept an OAuth 2.0 token for fetching user-specific dialog data.
