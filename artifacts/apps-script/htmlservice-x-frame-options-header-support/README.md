# HtmlService X-Frame-Options header support

Product: Apps Script
Feature slug: `htmlservice-x-frame-options-header-support`
Coverage: `MEDIUM`

## Technical Summary

HtmlService can set X-Frame-Options headers so Apps Script HTML and web apps can render in iframes.
