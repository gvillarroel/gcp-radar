# Spreadsheet copy paste types

Product: Apps Script
Feature slug: `spreadsheet-copy-paste-types`
Coverage: `MEDIUM`

## Technical Summary

Apps Script Spreadsheet service adds the CopyPasteType enum and a Range.copyTo() overload for paste type control.
