# Spreadsheet linked form URL access

Product: Apps Script
Feature slug: `spreadsheet-linked-form-url-access`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Apps Script Spreadsheet service adds Spreadsheet.getFormUrl() to return the URL of a form linked to a sheet or spreadsheet.
