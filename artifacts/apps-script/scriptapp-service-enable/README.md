# ScriptApp.Service.enable()

Product: Apps Script
Feature slug: `scriptapp-service-enable`
Coverage: `MEDIUM`

## Technical Summary

ScriptApp.Service.enable() enabled access to a service under the older Apps Script authorization model; deprecated on 2015-08-10.
