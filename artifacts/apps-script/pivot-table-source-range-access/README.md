# Pivot table source range access

Product: Apps Script
Feature slug: `pivot-table-source-range-access`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Apps Script Spreadsheet service adds PivotTable.getSourceDataRange() to access the source range of a pivot table.
