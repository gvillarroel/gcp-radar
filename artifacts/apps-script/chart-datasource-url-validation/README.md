# Chart datasource URL validation

Product: Apps Script
Feature slug: `chart-datasource-url-validation`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Charts now apply extra validation to datasource URLs, blocking custom URLs that rely on non-Google authentication.
