# Utilities.jsonParse() and Utilities.jsonStringify()

Product: Apps Script
Feature slug: `utilities-jsonparse-and-utilities-jsonstringify`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Utilities.jsonParse() and Utilities.jsonStringify() provided JSON parsing and serialization helpers before standard JavaScript JSON methods were preferred; deprecated on 2013-11-18.

## Lifecycle

- Latest feature date: 2013-11-18
- Deprecation date: 2013-11-18
- Status: deprecation_noted
