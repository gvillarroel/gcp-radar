# Looker connector private IP support

Product: Looker
Feature slug: `looker-connector-private-ip-support`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Looker connector can connect to private IP Looker (Google Cloud core) instances using the Looker instance ID.
