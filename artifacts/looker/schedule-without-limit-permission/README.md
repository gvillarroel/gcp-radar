# schedule_without_limit permission

Product: Looker
Feature slug: `schedule-without-limit-permission`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The schedule_without_limit permission lets admins restrict a user's ability to deliver all data results from a Look or Explore.
