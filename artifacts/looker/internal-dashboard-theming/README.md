# Internal Dashboard Theming

Product: Looker
Feature slug: `internal-dashboard-theming`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Internal Dashboard Theming is available as a preview feature in Looker (Google Cloud core); Users can apply predefined themes to Looker dashboards and manage them with the manage_internal_themes permission.
