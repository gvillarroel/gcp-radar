Product: Looker
Feature slug: `chart-config-editor`
Coverage: `MEDIUM`

## Technical Summary

The Chart Config Editor now supports conditional data formatters for comparing data values to other measure values; The Chart Config Editor now supports comparing data values to the mean value for a series.
