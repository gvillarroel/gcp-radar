# Disable Connection

Product: Looker
Feature slug: `disable-connection`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Disable Connection lets admins disable a database connection so Looker stops sending queries to it and returns an error to users.
