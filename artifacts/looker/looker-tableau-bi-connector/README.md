# Looker Tableau BI Connector

Product: Looker
Feature slug: `looker-tableau-bi-connector`
Coverage: `MEDIUM`

## Technical Summary

Makes the Looker Tableau BI Connector available on Tableau Exchange for Tableau Desktop and Tableau Server; Lets Tableau Cloud use a Looker Explore as a data source through the Looker Tableau BI Connector.
