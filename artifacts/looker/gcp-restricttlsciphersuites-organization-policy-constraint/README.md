# gcp.restrictTLSCipherSuites organization policy constraint

Product: Looker
Feature slug: `gcp-restricttlsciphersuites-organization-policy-constraint`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Lets admins apply a TLS cipher suite restriction policy to Looker (Google Cloud core) instances that use public IP networking.
