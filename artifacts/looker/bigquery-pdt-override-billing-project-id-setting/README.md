# BigQuery PDT Override Billing Project ID setting

Product: Looker
Feature slug: `bigquery-pdt-override-billing-project-id-setting`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Lets Looker admins specify the billing project used for PDT build and maintenance queries on BigQuery connections.
