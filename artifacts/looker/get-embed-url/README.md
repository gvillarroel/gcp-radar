# Get embed URL

Product: Looker
Feature slug: `get-embed-url`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

This feature automatically generates a private embed URL for a dashboard, Look, or Explore and can include parameters and an existing theme.
