# Self-service Explores

Product: Looker
Feature slug: `self-service-explores`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Self-service Explores lets users upload and analyze data in Explores, including from Google Sheets when OAuth uploads are enabled; Self-service Explores can now be updated with data from the latest version of the source file used to create them.
