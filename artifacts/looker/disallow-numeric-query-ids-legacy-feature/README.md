# Disallow Numeric Query IDs legacy feature

Product: Looker
Feature slug: `disallow-numeric-query-ids-legacy-feature`
Coverage: `MEDIUM`

## Technical Summary

This legacy feature lets users opt in to or out of query API changes that affect numeric query IDs.
