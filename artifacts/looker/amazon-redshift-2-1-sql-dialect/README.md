# Amazon Redshift 2.1+ SQL dialect

Product: Looker
Feature slug: `amazon-redshift-2-1-sql-dialect`
Coverage: `MEDIUM`

## Technical Summary

Adds support for creating connections with the Amazon Redshift 2.1+ SQL dialect using the Redshift JDBC driver.
