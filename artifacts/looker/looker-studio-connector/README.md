# Looker Studio connector

Product: Looker
Feature slug: `looker-studio-connector`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Looker Studio Connector is available for all Looker-hosted instances, including those hosted on AWS and Azure; The Looker Studio connector is generally available and lets users add Looker Explores as data sources in Looker Studio reports.
