# Studio in Looker report recovery after re-enable

Product: Looker
Feature slug: `studio-in-looker-report-recovery-after-re-enable`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Reports saved within the previous 30 days remain available after Studio in Looker is disabled and then re-enabled.
