# In-database merge queries

Product: Looker
Feature slug: `in-database-merge-queries`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Merge queries on the same BigQuery connection can now be joined in the database instead of in Looker memory.
