# instance license revoked notice

Product: Looker
Feature slug: `instance-license-revoked-notice`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Instance admins now receive a notice when the instance license is revoked and have 14 days to correct issues before shutdown.
