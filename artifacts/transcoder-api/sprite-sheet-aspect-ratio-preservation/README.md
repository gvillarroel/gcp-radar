# Sprite sheet aspect ratio preservation

Product: Transcoder API
Feature slug: `sprite-sheet-aspect-ratio-preservation`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Sprite sheet generation now preserves source aspect ratio by auto-calculating one dimension when only sprite width or height is provided.

## Lifecycle

- Latest feature date: 2021-02-26
- Deprecation date: none recorded
- Status: feature_observed
