# Source aspect ratio preservation

Product: Transcoder API
Feature slug: `source-aspect-ratio-preservation`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Transcoder API now preserves the original source video's aspect ratio during transcoding.
