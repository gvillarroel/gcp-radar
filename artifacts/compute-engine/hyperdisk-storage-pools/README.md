# Hyperdisk Storage Pools

Product: Compute Engine
Feature slug: `hyperdisk-storage-pools`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Hyperdisk Storage Pools let you pre-purchase and manage disk capacity, throughput, and IOPS in aggregate for Compute Engine workloads.
