# Reservation consumption view

Product: Compute Engine
Feature slug: `reservation-consumption-view`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Compute Engine can show which reservation a VM consumes and list the VMs consuming a reservation.
