# ANY_SINGLE_ZONE distribution shape for regional MIGs

Product: Compute Engine
Feature slug: `any-single-zone-distribution-shape-for-regional-migs`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The ANY_SINGLE_ZONE distribution shape lets a regional managed instance group automatically choose one zone with available resources within quota.

## Lifecycle

- Latest feature date: 2022-11-15
- Deprecation date: none recorded
