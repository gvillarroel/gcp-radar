# Reservation consumption visibility on VM instances

Product: Compute Engine
Feature slug: `reservation-consumption-visibility-on-vm-instances`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

A new consumedReservation field in VM instance details shows the full resource name of the reservation consumed by an instance.

- Latest feature date: 2025-11-10
- Deprecation date: none recorded
