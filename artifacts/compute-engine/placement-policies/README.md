# Placement policies

Product: Compute Engine
Feature slug: `placement-policies`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Placement policies let you control relative VM placement on underlying host infrastructure for latency or isolation goals.
