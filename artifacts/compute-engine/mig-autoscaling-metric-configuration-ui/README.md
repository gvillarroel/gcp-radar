# MIG autoscaling metric configuration UI

Product: Compute Engine
Feature slug: `mig-autoscaling-metric-configuration-ui`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The managed instance group autoscaling interface lets you explore Cloud Monitoring metrics and filters, visualize values, and review the aggregated autoscaling signal.
