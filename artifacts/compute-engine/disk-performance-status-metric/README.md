# Disk performance status metric

Product: Compute Engine
Feature slug: `disk-performance-status-metric`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The disk performance status metric monitors the health of Hyperdisk and Persistent Disk volumes and indicates adverse Compute Engine events affecting disks.
