# Calendar mode future reservations for TPU-attached VMs

Product: Compute Engine
Feature slug: `calendar-mode-future-reservations-for-tpu-attached-vms`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Future reservation requests in calendar mode can reserve capacity for VMs with attached TPUs.
