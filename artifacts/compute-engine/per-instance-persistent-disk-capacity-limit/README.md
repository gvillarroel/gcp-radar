# Per-instance persistent disk capacity limit

Product: Compute Engine
Feature slug: `per-instance-persistent-disk-capacity-limit`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

A Compute Engine instance can attach up to 257 TB of persistent disk storage.
