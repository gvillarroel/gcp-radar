# OS configuration management

Feature slug: `os-configuration-management`

## Technical Summary

OS configuration management deploys and automates software configuration on VM instances and includes assignment editing and reporting capabilities; OS configuration management deploys and automates software configurations on VM instances with policy rollout controls and compliance reporting.
