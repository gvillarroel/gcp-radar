# N2 VM regional availability

Product: Compute Engine
Feature slug: `n2-vm-regional-availability`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

N2 machine types are available in additional Osaka and Seoul zones; N2 virtual machines are available in additional Mumbai and Jakarta zones.
