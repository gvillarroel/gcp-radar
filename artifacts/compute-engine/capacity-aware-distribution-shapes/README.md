# Capacity-aware distribution shapes

Product: Compute Engine
Feature slug: `capacity-aware-distribution-shapes`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Regional managed instance groups can distribute instances across zones using capacity-aware distribution shapes that can also prioritize reservations.

- Latest feature date: 2021-06-08
- Deprecation date: none recorded
