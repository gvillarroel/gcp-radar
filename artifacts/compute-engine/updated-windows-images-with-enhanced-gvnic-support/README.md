# Updated Windows images with enhanced gVNIC support

Product: Compute Engine
Feature slug: `updated-windows-images-with-enhanced-gvnic-support`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Updated Windows OS images include a new gVNIC driver version that enables up to 200 Gbps networking and Jumbo frames on supported instances.
