# Live migration within sole-tenant node groups

Product: Compute Engine
Feature slug: `live-migration-within-sole-tenant-node-groups`
Coverage: `MEDIUM`

## Technical Summary

Live migration within sole-tenant node groups lets VMs move within the node group during host maintenance events.
