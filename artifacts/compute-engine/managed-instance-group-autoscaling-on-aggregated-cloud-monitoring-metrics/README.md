# Managed instance group autoscaling on aggregated Cloud Monitoring metrics

Product: Compute Engine
Feature slug: `managed-instance-group-autoscaling-on-aggregated-cloud-monitoring-metrics`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Regional and zonal managed instance groups can autoscale based on filtered aggregated Cloud Monitoring metrics for the group.

## Lifecycle

- Latest feature date: 2021-06-29
- Deprecation date: none recorded
- Status: feature_observed
