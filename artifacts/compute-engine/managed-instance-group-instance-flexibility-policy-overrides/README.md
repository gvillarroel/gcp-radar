# Managed instance group instance flexibility policy overrides

Product: Compute Engine
Feature slug: `managed-instance-group-instance-flexibility-policy-overrides`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Managed instance groups can use instance flexibility policies to override the minimum CPU platform and disk definition in the instance template.

- Latest feature date: 2026-03-23
- Deprecation date: none recorded
