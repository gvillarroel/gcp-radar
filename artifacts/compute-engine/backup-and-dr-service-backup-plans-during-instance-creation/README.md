# Backup and DR Service backup plans during instance creation

Product: Compute Engine
Feature slug: `backup-and-dr-service-backup-plans-during-instance-creation`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Backup and DR Service backup plans can be applied when creating instances to centralize backup management and use immutable backup vaults.
