# Managed instance group suspended and stopped VM pools

Product: Compute Engine
Feature slug: `managed-instance-group-suspended-and-stopped-vm-pools`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Managed instance groups can maintain pools of suspended and stopped VMs to reduce costs and speed up scale-out operations.
