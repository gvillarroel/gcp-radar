Product: Compute Engine
Feature slug: `future-reservation-requests-in-calendar-mode`
Coverage: `MEDIUM`

## Technical Summary

Future reservation requests in calendar mode let you reserve GPU, TPU, or H4D resources for VMs up to 90 days in advance.
