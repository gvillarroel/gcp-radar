# Performance Monitoring Unit for C4 VMs

Product: Compute Engine
Feature slug: `performance-monitoring-unit-for-c4-vms`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

C4 virtual machines can use the performance monitoring unit to observe low-level CPU events and metrics for performance analysis.
