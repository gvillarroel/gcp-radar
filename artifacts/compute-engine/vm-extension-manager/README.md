# VM Extension Manager

Product: Compute Engine
Feature slug: `vm-extension-manager`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

VM Extension Manager lets you install, govern, and monitor guest agent extensions across Compute Engine VMs using extension policies.
