# Autoscaling for regional managed instance groups with ANY and ANY_SINGLE_ZONE

Product: Compute Engine
Feature slug: `autoscaling-for-regional-managed-instance-groups-with-any-and-any-single-zone`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Regional managed instance groups can autoscale when their target distribution shape is set to ANY or ANY_SINGLE_ZONE.

## Lifecycle

- Latest feature date: 2025-11-18
- Deprecation date: none recorded
- Status: feature_observed
