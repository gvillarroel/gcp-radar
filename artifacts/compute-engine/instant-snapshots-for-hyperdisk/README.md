# Instant snapshots for Hyperdisk

Product: Compute Engine
Feature slug: `instant-snapshots-for-hyperdisk`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Instant snapshots can create in-place backups for Hyperdisk Balanced, Hyperdisk Balanced High Availability, and Hyperdisk Extreme disks.
