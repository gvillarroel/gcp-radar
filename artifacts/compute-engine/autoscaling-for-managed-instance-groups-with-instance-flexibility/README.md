# Autoscaling for managed instance groups with instance flexibility

Product: Compute Engine
Feature slug: `autoscaling-for-managed-instance-groups-with-instance-flexibility`
Coverage: `MEDIUM`

## Technical Summary

Managed instance groups that use instance flexibility can now autoscale based on workload demand.
