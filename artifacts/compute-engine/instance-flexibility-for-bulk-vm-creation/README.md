# Instance flexibility for bulk VM creation

Product: Compute Engine
Feature slug: `instance-flexibility-for-bulk-vm-creation`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Instance flexibility lets bulk regional VM creation select from multiple acceptable machine types based on available capacity and quota.
