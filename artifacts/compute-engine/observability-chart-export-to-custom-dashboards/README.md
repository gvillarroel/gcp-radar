# Observability chart export to custom dashboards

Product: Compute Engine
Feature slug: `observability-chart-export-to-custom-dashboards`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Charts from the VM instance Observability tab can be copied into custom Cloud Monitoring dashboards.

## Lifecycle

- Latest feature date: 2021-11-08
- Deprecation date: none recorded
- Status: feature_observed
