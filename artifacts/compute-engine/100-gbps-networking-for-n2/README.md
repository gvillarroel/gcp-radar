# 100 Gbps networking for N2

Product: Compute Engine
Feature slug: `100-gbps-networking-for-n2`
Coverage: `MEDIUM`

## Technical Summary

N2, N2D, and C2 virtual machines can be configured with up to 100 Gbps of network bandwidth.
