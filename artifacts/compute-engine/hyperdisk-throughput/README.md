# Hyperdisk Throughput

Product: Compute Engine
Feature slug: `hyperdisk-throughput`
Coverage: `MEDIUM`

## Technical Summary

Hyperdisk Throughput is throughput-oriented block storage with dynamically configurable capacity and throughput for VM workloads.
