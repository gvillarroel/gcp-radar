# Spot VMs

Product: Compute Engine
Feature slug: `spot-vms`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Spot VMs provide discounted interruptible virtual machines for fault-tolerant workloads without the 24-hour runtime limit of preemptible VMs.
