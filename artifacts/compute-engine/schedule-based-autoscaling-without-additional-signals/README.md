# Schedule-based autoscaling without additional signals

Product: Compute Engine
Feature slug: `schedule-based-autoscaling-without-additional-signals`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Managed instance groups support schedule-based autoscaling without requiring another autoscaling signal.
