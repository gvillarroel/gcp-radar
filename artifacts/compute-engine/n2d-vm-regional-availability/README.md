# N2D VM regional availability

Product: Compute Engine
Feature slug: `n2d-vm-regional-availability`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

General-purpose N2D virtual machines are available in the us-west4-b zone; N2D machine types are available in the us-west4-a zone.
