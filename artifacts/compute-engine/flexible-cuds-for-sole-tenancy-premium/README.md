# Flexible CUDs for sole-tenancy premium

Product: Compute Engine
Feature slug: `flexible-cuds-for-sole-tenancy-premium`
Coverage: `MEDIUM`

## Technical Summary

Compute flexible committed use discounts are available for the sole-tenancy premium on eligible sole-tenant node types.
