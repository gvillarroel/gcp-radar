# Regionally scoped snapshots

Product: Compute Engine
Feature slug: `regionally-scoped-snapshots`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Regionally scoped snapshots keep snapshot data and required metadata co-located within a selected region and support additional location controls.
