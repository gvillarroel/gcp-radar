# Local SSDs on sole-tenant nodes

Product: Compute Engine
Feature slug: `local-ssds-on-sole-tenant-nodes`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Local SSDs on sole-tenant nodes allow VM instances on sole-tenant nodes to use local SSD storage.
