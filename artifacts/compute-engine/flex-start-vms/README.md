# Flex-start VMs

Product: Compute Engine
Feature slug: `flex-start-vms`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Flex-start VMs are short-duration VM instances that use flexible-start capacity pools and can be deployed standalone or added to managed instance groups with discounts on supported resources.
