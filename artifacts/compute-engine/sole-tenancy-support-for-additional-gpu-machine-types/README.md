# Sole-tenancy support for additional GPU machine types

Product: Compute Engine
Feature slug: `sole-tenancy-support-for-additional-gpu-machine-types`
Coverage: `MEDIUM`

## Technical Summary

Sole-tenancy now supports A2 Ultra, A2 Mega, A2 High, A3 Mega, and A3 High GPU machine types through dedicated node types.
