# Asynchronous Replication for Hyperdisk

Product: Compute Engine
Feature slug: `asynchronous-replication-for-hyperdisk`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Asynchronous Replication provides cross-region disaster recovery for Hyperdisk Balanced, Hyperdisk Balanced High Availability, and Hyperdisk Extreme disks.
