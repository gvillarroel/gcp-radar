# Stateful IP addresses for managed instance groups

Product: Compute Engine
Feature slug: `stateful-ip-addresses-for-managed-instance-groups`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Managed instance groups can preserve stateful IP addresses across autohealing, updates, and recreations.
