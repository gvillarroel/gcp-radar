# Managed instance group resize retry control

Product: Compute Engine
Feature slug: `managed-instance-group-resize-retry-control`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Managed instance groups can disable VM creation retries during resizing operations.
