# Compact placement policies for standalone Flex-start VMs

Product: Compute Engine
Feature slug: `compact-placement-policies-for-standalone-flex-start-vms`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Standalone Flex-start VMs can use compact placement policies to colocate instances and reduce network hops for latency-sensitive workloads.
