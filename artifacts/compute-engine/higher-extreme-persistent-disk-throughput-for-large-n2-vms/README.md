# Higher Extreme Persistent Disk throughput for large N2 VMs

Product: Compute Engine
Feature slug: `higher-extreme-persistent-disk-throughput-for-large-n2-vms`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

N2 VMs with 64 or more vCPUs support up to 4 GB/s read and 3 GB/s write throughput per instance with Extreme Persistent Disk.
