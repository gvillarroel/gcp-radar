# Intel MPI 2021 support in HPC VM Images

Product: Compute Engine
Feature slug: `intel-mpi-2021-support-in-hpc-vm-images`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

HPC VM Images support Intel MPI 2021 along with tools for installing the Intel MPI library and the net and psm3 libfabric providers.
