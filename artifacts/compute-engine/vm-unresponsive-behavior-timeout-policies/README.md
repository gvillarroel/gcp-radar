# VM unresponsive behavior timeout policies

Product: Compute Engine
Feature slug: `vm-unresponsive-behavior-timeout-policies`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

VM availability policies can define how long Compute Engine waits before terminating or restarting an unresponsive VM.
