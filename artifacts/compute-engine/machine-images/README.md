# Machine images

Product: Compute Engine
Feature slug: `machine-images`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Machine images capture the configuration, metadata, permissions, and data needed to create VM instances; Machine images store the configuration, metadata, permissions, and data needed to create a VM instance in one resource.
