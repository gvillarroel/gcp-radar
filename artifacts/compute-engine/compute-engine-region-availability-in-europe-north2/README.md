# Compute Engine region availability in europe-north2

Product: Compute Engine
Feature slug: `compute-engine-region-availability-in-europe-north2`

## Technical Summary

Compute Engine is available in the Stockholm region with N4, C3D highmem, C4 highmem, and E2 machine types across all three zones.
