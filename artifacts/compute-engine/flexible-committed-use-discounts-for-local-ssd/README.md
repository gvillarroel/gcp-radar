# Flexible committed use discounts for Local SSD

Product: Compute Engine
Feature slug: `flexible-committed-use-discounts-for-local-ssd`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Flexible committed use discounts let eligible Local SSD usage receive commitments that are not restricted to a single project, region, or machine series.

- Deprecation date: none recorded
