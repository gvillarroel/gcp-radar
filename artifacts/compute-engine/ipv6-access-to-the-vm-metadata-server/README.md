# IPv6 access to the VM metadata server

Product: Compute Engine
Feature slug: `ipv6-access-to-the-vm-metadata-server`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Single-stack IPv6 VM instances can access the Compute Engine metadata server over IPv6 connectivity.
