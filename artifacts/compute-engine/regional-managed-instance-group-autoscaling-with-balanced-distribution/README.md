# Regional managed instance group autoscaling with BALANCED distribution

Product: Compute Engine
Feature slug: `regional-managed-instance-group-autoscaling-with-balanced-distribution`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Regional managed instance groups can autoscale with a BALANCED target distribution shape that considers per-zone capacity availability.
