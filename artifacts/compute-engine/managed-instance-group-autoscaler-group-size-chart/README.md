# Managed instance group autoscaler group size chart

Product: Compute Engine
Feature slug: `managed-instance-group-autoscaler-group-size-chart`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Autoscaled managed instance groups can display configured group size and autoscaler-recommended size on a monitoring chart.
