# Zonal metadata

Product: Compute Engine
Feature slug: `zonal-metadata`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Zonal metadata lets you define custom metadata at a zonal scope within a project to isolate metadata changes and improve reliability.
