# Google Meet smart notes file retrieval

Product: Google Meet
Feature slug: `google-meet-smart-notes-file-retrieval`
Coverage: `MEDIUM`

## Technical Summary

Developers can use the smartNotes resource to get and list smart notes files in a conference record.
