# Google Meet Add-ons SDK

Product: Google Meet
Feature slug: `google-meet-add-ons-sdk`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Google Meet Add-ons SDK lets developers embed apps into Google Meet so users can discover, share, and collaborate without leaving Meet.
