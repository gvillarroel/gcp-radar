# customer-managed CA

Product: Memorystore for Valkey
Feature slug: `customer-managed-ca`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

A CA mode that uses a customer-hosted CA pool in Certificate Authority Service so client applications can connect without additional CA certificate downloads.
