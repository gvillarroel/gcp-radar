# RouteChangedListener trigger events

Product: Navigation SDK for Android
Feature slug: `routechangedlistener-trigger-events`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

RouteChangedListener now fires after route generation, after an alternative route is selected before navigation starts, and after a route is cleared.
