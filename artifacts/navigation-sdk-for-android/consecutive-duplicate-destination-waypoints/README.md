# Consecutive duplicate destination waypoints

Product: Navigation SDK for Android
Feature slug: `consecutive-duplicate-destination-waypoints`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The SDK allowed the navigator to be given the same destination waypoint more than once in a row; deprecated on 2024-09-13.

## Lifecycle

- Latest feature date: 2024-09-13
- Deprecation date: 2024-09-13
- Status: deprecation_noted
