# Enhanced location context for Waypoint API

Product: Navigation SDK for Android
Feature slug: `enhanced-location-context-for-waypoint-api`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Allows providing enhanced location context to the Waypoint API using a Place ID and coordinates or a navigationPointToken.
