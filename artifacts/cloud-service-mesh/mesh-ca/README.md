# Mesh CA

Product: Cloud Service Mesh
Feature slug: `mesh-ca`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Mesh CA is available to any GKE customer without requiring the purchase of Anthos; Mesh CA is a Google-managed certificate authority that issues mTLS certificates for workloads in Anthos Service Mesh.
