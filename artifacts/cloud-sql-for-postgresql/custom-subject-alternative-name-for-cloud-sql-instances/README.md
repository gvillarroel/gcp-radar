# Custom subject alternative name for Cloud SQL instances

Product: Cloud SQL for PostgreSQL
Feature slug: `custom-subject-alternative-name-for-cloud-sql-instances`
Coverage: `MEDIUM`

## Technical Summary

Custom subject alternative names let Cloud SQL instances use custom DNS names for connections when configured with customer-managed CAS CA.
