# pg_wait_sampling.profile_queries flag

Product: Cloud SQL for PostgreSQL
Feature slug: `pg-wait-sampling-profile-queries-flag`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The pg_wait_sampling.profile_queries flag controls whether wait profiles are collected per query or across all queries.
