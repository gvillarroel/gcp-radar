# Immediate instance name reuse

Product: Cloud SQL for PostgreSQL
Feature slug: `immediate-instance-name-reuse`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Cloud SQL allows an instance name to be reused immediately after the instance is deleted.
