# hash_mem_multiplier flag

Product: Cloud SQL for PostgreSQL
Feature slug: `hash-mem-multiplier-flag`
Coverage: `MEDIUM`

## Technical Summary

The hash_mem_multiplier flag controls the maximum memory that hash-based operations can use.
