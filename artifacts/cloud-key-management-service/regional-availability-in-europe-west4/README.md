# Regional availability in europe-west4

Product: Cloud Key Management Service
Feature slug: `regional-availability-in-europe-west4`
Coverage: `MEDIUM`

## Technical Summary

Cloud KMS resources can be created in the europe-west4 region, including creating key rings through the API and gcloud.
