# G.711 A-law audio encoding

Product: Dialogflow
Feature slug: `g-711-a-law-audio-encoding`
Coverage: `MEDIUM`

## Technical Summary

Dialogflow CX and ES support G.711 A-law encoding for input and output audio in addition to Mu-law.
