# Transparency and Control Center

Product: Recommender
Feature slug: `transparency-and-control-center`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Transparency and Control Center lets administrators download processed data to view insights and recommendations.
