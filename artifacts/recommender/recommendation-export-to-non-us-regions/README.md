# Recommendation export to non-US regions

Product: Recommender
Feature slug: `recommendation-export-to-non-us-regions`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Allows recommendations to be exported to non-US regions.
