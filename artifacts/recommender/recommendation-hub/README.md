# Recommendation Hub

Product: Recommender
Feature slug: `recommendation-hub`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

A centralized page for viewing recommendations with organization and folder views, custom sorting, and filtering; Recommendation Hub lets you view, prioritize, and apply recommendations in the Google Cloud Console.
