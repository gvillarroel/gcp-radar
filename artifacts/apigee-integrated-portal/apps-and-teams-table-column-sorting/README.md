# Apps and Teams table column sorting

Product: Apigee Integrated Portal
Feature slug: `apps-and-teams-table-column-sorting`
Coverage: `MEDIUM`

## Technical Summary

Adds support for sorting the Apps and Teams tables by Name and Created columns using clickable column headers.
