# Publishing data export

Product: Apigee Integrated Portal
Feature slug: `publishing-data-export`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Adds the ability to export portal publishing data for developers, apps, and API products from the Cloud console as CSV or JSON files.
