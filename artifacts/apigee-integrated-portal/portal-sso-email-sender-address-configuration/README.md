# Portal SSO email sender address configuration

Product: Apigee Integrated Portal
Feature slug: `portal-sso-email-sender-address-configuration`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Updates Portal SSO email sender behavior to use the custom SMTP sender address when configured or fall back to no-reply@google.com.

## Lifecycle

- Latest feature date: 2022-05-04
- Deprecation date: none recorded
- Status: feature_observed
