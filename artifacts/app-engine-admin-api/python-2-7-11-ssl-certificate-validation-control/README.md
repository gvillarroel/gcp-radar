# Python 2.7.11 SSL certificate validation control

Product: App Engine Admin API
Feature slug: `python-2-7-11-ssl-certificate-validation-control`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

App Engine Python 2.7.11 SSL module certificate validation behavior is now controllable via the PYTHONHTTPSVERIFY environment variable.

- Latest feature date: 2017-05-15
- Deprecation date: none recorded
