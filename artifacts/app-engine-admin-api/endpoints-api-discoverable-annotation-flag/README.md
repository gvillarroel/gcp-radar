# Endpoints API discoverable annotation flag

Product: App Engine Admin API
Feature slug: `endpoints-api-discoverable-annotation-flag`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Developers can set a discoverable boolean on the @Api annotation to disable API discovery behavior.

## Lifecycle

- Latest feature date: 2015-11-30
- Deprecation date: none recorded
- Status: feature_observed
