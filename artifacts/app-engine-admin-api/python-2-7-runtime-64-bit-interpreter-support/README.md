# Python 2.7 runtime 64-bit interpreter support

Product: App Engine Admin API
Feature slug: `python-2-7-runtime-64-bit-interpreter-support`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

All Python 2.7 App Engine applications now run on a 64-bit Python interpreter.
