# Python SSL 2.7 deprecation

Product: App Engine Admin API
Feature slug: `python-ssl-2-7-deprecation`

## Technical Summary

Google announced deprecation of Python SSL library version 2.7 for App Engine and advised migration to SSL version 2.7.11; deprecated on 2017-11-15.
