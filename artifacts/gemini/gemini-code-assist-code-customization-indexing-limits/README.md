# Gemini Code Assist code customization indexing limits

Product: Gemini
Feature slug: `gemini-code-assist-code-customization-indexing-limits`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Code customization can index up to 20,000 repositories with up to 500 repositories per repository group.
