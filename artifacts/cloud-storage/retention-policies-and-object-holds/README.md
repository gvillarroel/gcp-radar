# Retention policies and object holds

Product: Cloud Storage
Feature slug: `retention-policies-and-object-holds`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Retention policies and object holds help prevent object deletion or overwrite until defined retention or hold conditions are met.
