# Cloud EKM encryption for Cloud Storage

Product: Cloud Storage
Feature slug: `cloud-ekm-encryption-for-cloud-storage`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Cloud Storage can use Cloud EKM keys as customer-managed encryption keys for data encryption.

## Lifecycle

- Latest feature date: 2021-10-13
- Deprecation date: none recorded
- Status: feature_observed
