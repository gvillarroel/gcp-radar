# Object contexts

Product: Cloud Storage
Feature slug: `object-contexts`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Object contexts let you attach contextual information to Cloud Storage objects to improve data management and discovery.
