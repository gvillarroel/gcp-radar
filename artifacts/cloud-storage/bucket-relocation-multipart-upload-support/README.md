# Bucket relocation multipart upload support

Product: Cloud Storage
Feature slug: `bucket-relocation-multipart-upload-support`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Bucket relocation with write downtime supports completed multipart uploads that finish before final synchronization.

## Lifecycle

- Latest feature date: 2026-01-21
- Deprecation date: none recorded
- Status: feature_observed
