# Anywhere Cache

Product: Cloud Storage
Feature slug: `anywhere-cache`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Anywhere Cache provides SSD-backed caches in the same zones as workloads to speed data access and reduce transfer fees.
