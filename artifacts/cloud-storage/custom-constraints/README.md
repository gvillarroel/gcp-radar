# Custom constraints

Product: Cloud Storage
Feature slug: `custom-constraints`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Custom constraints let organizations enforce policy rules on Cloud Storage resources such as requiring Object Versioning on buckets.
