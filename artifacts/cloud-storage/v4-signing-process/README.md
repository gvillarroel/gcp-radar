# V4 signing process

Product: Cloud Storage
Feature slug: `v4-signing-process`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The V4 signing process is an improved method for creating signed requests with RSA or HMAC signatures, including signed URLs.

## Lifecycle

- Latest feature date: 2019-04-05
- Deprecation date: none recorded
