# Object Lifecycle Management noncurrent time conditions

Product: Cloud Storage
Feature slug: `object-lifecycle-management-noncurrent-time-conditions`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Noncurrent time conditions let lifecycle rules act based on when an object became noncurrent.
