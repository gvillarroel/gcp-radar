# Coldline Storage

Product: Cloud Storage
Feature slug: `coldline-storage`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Coldline Storage is an archival storage class for low-cost, immediately accessible data used for backup, archival, and disaster recovery.
