# Object Lifecycle Management custom time conditions

Product: Cloud Storage
Feature slug: `object-lifecycle-management-custom-time-conditions`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Custom time conditions let lifecycle rules act based on a custom time set on objects.
