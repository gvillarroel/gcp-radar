# Custom security profiles in Apigee UI

Product: Apigee Advanced API Security
Feature slug: `custom-security-profiles-in-apigee-ui`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Customers can create and edit custom security profiles in the Apigee UI to define which security categories contribute to risk scoring.
