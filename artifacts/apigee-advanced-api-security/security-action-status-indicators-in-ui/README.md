# Security action status indicators in UI

Product: Apigee Advanced API Security
Feature slug: `security-action-status-indicators-in-ui`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The security actions UI now shows status icons and an expired marker for enabled, disabled, paused, and expired security actions.
