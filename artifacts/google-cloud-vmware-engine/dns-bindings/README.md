# DNS bindings

Product: Google Cloud VMware Engine
Feature slug: `dns-bindings`
Coverage: `MEDIUM`

## Technical Summary

DNS bindings provide bidirectional Cloud DNS integration so Cloud DNS administrators can bind VMware Engine networks like other VPCs.
