# NSX-T syslog forwarding to Cloud Logging

Product: Google Cloud VMware Engine
Feature slug: `nsx-t-syslog-forwarding-to-cloud-logging`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

NSX-T syslog messages of a chosen severity can be forwarded to Cloud Logging for alerting and dashboards.
