# User IP address source selection in Connectivity Tests

Product: Network Intelligence Center
Feature slug: `user-ip-address-source-selection-in-connectivity-tests`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Connectivity Tests lets you use your user IP address as the source IP address for a connectivity test in the Google Cloud console.
