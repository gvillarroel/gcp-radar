# Environment groups

Product: Google SecOps SOAR
Feature slug: `environment-groups`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Users can group environments into logical categories for user assignment, IdP mapping, playbooks, and case filters.
