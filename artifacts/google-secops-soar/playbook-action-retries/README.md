# Playbook action retries

Product: Google SecOps SOAR
Feature slug: `playbook-action-retries`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Playbooks can automatically retry individual actions that fail due to temporary issues such as network outages, API rate limits, or service unavailability.
