# Chat space smart chips

Product: Chat API
Feature slug: `chat-space-smart-chips`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The chatSpaceLinkData field in RichLinkMetadata lets messages include smart chips that point to Chat spaces.
