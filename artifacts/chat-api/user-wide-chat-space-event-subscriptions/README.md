# User-wide Chat space event subscriptions

Product: Chat API
Feature slug: `user-wide-chat-space-event-subscriptions`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Chat apps can subscribe to events across all Chat spaces where a user is a member by targeting all spaces for that user.
