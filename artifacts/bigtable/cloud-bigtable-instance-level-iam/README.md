# Cloud Bigtable instance-level IAM

Product: Bigtable
Feature slug: `cloud-bigtable-instance-level-iam`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

Cloud Bigtable introduced general availability of instance-level IAM.

- Deprecation date: none recorded
