# Cloud Bigtable regional availability

Product: Bigtable
Feature slug: `cloud-bigtable-regional-availability`

## Technical Summary

Cloud Bigtable is now available in the me-west1 (Tel Aviv) region; Cloud Bigtable is now available in the us-south1 (Dallas) and europe-southwest1 (Madrid) regions.
