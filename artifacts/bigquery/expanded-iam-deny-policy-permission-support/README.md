# Expanded IAM deny policy permission support

Product: BigQuery
Feature slug: `expanded-iam-deny-policy-permission-support`
Coverage: `MEDIUM`
IAM mapping: `explicit`

## Technical Summary

IAM deny policies support additional BigQuery permissions, including bigquery.tables.getData for denying table read access; Deny policies support a broader set of permissions.
