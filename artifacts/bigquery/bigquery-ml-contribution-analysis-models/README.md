# BigQuery ML contribution analysis models

Product: BigQuery
Feature slug: `bigquery-ml-contribution-analysis-models`
Coverage: `MEDIUM`

## Technical Summary

BigQuery ML can create contribution analysis models with CREATE MODEL and use ML.GET_INSIGHTS to explain changes in key metrics across multidimensional data.
