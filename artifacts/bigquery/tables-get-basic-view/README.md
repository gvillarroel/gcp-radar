# tables.get BASIC view

Product: BigQuery
Feature slug: `tables-get-basic-view`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The tables.get API method can return a BASIC view that omits some storage statistics to reduce latency.
