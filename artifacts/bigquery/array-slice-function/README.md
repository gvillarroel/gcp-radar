# ARRAY_SLICE function

Product: BigQuery
Feature slug: `array-slice-function`
Coverage: `MEDIUM`

## Technical Summary

The ARRAY_SLICE GoogleSQL function returns a slice of an array; The ARRAY_SLICE GoogleSQL function returns an array containing consecutive elements from an input array.
