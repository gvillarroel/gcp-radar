# NULL marker options for CSV loads

Product: BigQuery
Feature slug: `null-marker-options-for-csv-loads`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

CREATE EXTERNAL TABLE and LOAD DATA support null_markers to define which CSV strings represent NULL values.
