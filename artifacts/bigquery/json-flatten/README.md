# JSON_FLATTEN

Product: BigQuery
Feature slug: `json-flatten`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

JSON_FLATTEN extracts all non-array values from a JSON value, including values under consecutively nested arrays.
