# Table functions

Product: BigQuery
Feature slug: `table-functions`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Table functions let BigQuery queries return tables from parameterized function definitions; Table functions are user-defined functions that return tables in BigQuery.
