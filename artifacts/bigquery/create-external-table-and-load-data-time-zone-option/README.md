# CREATE EXTERNAL TABLE and LOAD DATA time_zone option

Product: BigQuery
Feature slug: `create-external-table-and-load-data-time-zone-option`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The time_zone option specifies a time zone to use when loading data with CREATE EXTERNAL TABLE or LOAD DATA.
