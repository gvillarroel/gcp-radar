# AI.GENERATE_TABLE

Product: BigQuery
Feature slug: `ai-generate-table`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

AI.GENERATE_TABLE produces structured table output from unstructured inputs including text, images, audio, and video; BigQuery ML now supports AI.GENERATE_TABLE with output_schema to generate structured Gemini output that can be converted into tables.
