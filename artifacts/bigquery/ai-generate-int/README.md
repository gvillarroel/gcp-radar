# AI.GENERATE_INT

Product: BigQuery
Feature slug: `ai-generate-int`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

AI.GENERATE_INT generates integer scalar values for filtering, scoring, and counting workflows; BigQuery ML now supports the AI.GENERATE_INT function for Gemini-based text analysis with integer output.
