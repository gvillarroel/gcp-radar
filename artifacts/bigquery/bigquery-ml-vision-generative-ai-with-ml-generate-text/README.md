# BigQuery ML vision generative AI with ML.GENERATE_TEXT

Product: BigQuery
Feature slug: `bigquery-ml-vision-generative-ai-with-ml-generate-text`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

BigQuery ML can use ML.GENERATE_TEXT with gemini-pro-vision remote models to perform image and video understanding tasks on visual content in object tables.
