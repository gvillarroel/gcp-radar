# REVERSE and ARRAY_REVERSE functions

Product: BigQuery

Coverage: `MEDIUM`

## Technical Summary

BigQuery Standard SQL provides the REVERSE and ARRAY_REVERSE functions for reversing STRING, BYTES, and ARRAY values.
