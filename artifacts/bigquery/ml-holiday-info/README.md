# ML.HOLIDAY_INFO

Product: BigQuery
Feature slug: `ml-holiday-info`
Coverage: `MEDIUM`

## Technical Summary

ML.HOLIDAY_INFO returns the list of holidays modeled by an ARIMA_PLUS or ARIMA_PLUS_XREG time series forecasting model.
