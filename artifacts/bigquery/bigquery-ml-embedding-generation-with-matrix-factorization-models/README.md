# BigQuery ML embedding generation with matrix factorization models

Product: BigQuery
Feature slug: `bigquery-ml-embedding-generation-with-matrix-factorization-models`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

BigQuery ML can use ML.GENERATE_EMBEDDING with matrix factorization models to create embeddings for user or item data.
