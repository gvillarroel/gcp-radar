# AI.SIMILARITY

Product: BigQuery
Feature slug: `ai-similarity`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The AI.SIMILARITY function computes semantic similarity for text pairs, image pairs, and text-to-image pairs; AI.SIMILARITY computes semantic similarity between pairs of text, pairs of images, or text and image inputs.
