# ST_CONVEXHULL function

Product: BigQuery
Feature slug: `st-convexhull-function`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

BigQuery GIS supports the ST_CONVEXHULL function to return the smallest convex geography covering the input.
