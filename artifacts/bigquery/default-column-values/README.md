# Default column values

Product: BigQuery
Feature slug: `default-column-values`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Default column values let users define default values on columns in BigQuery tables; BigQuery tables can define default values for columns.
