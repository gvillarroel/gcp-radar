# Explicit schema for external tables

Product: BigQuery
Feature slug: `explicit-schema-for-external-tables`
Coverage: `MEDIUM`

## Technical Summary

BigQuery external tables over Parquet, ORC, and Avro can be created with an explicitly specified schema instead of relying on auto-detection.
