# Table tags for IAM policies

Product: BigQuery
Feature slug: `table-tags-for-iam-policies`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

BigQuery lets you use tags on tables to conditionally allow or deny access with IAM policies.
