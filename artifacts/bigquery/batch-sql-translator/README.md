# Batch SQL translator

Product: BigQuery
Feature slug: `batch-sql-translator`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The batch SQL translator converts supported SQL dialects such as Apache Impala SQL into GoogleSQL in batch workflows; BigQuery Migration Service includes a Batch SQL Translator for translating SQL in batch workflows.
