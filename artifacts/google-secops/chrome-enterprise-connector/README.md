# Chrome Enterprise Connector

Product: Google SecOps
Feature slug: `chrome-enterprise-connector`
Coverage: `MEDIUM`

## Technical Summary

The Chrome Enterprise Connector configures recommended export settings and sends Chrome Enterprise Premium data through Google Cloud to Google Security Operations.
