# Playbook Simulator

Product: Google SecOps
Feature slug: `playbook-simulator`
Coverage: `MEDIUM`

## Technical Summary

Playbook Simulator can visualize and debug playbooks that contain loops, with updated step ordering and auto-scrolling to recent activity.
