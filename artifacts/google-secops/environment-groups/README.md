# Environment groups

Product: Google SecOps
Feature slug: `environment-groups`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Environment groups let administrators organize environments into logical categories for user access, IdP mapping, playbooks, and case filtering.
