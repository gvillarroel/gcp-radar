# Image export shardSize and fileDimensions arguments

Product: Earth Engine JavaScript Client Library
Feature slug: `image-export-shardsize-and-filedimensions-arguments`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Adds shardSize and fileDimensions arguments to Export.image.toDrive() and Export.image.toCloudStorage() for multi-file image exports.
