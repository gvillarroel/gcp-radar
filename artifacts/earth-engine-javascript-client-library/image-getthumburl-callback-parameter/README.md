# Image.getThumbUrl() callback parameter

Product: Earth Engine JavaScript Client Library
Feature slug: `image-getthumburl-callback-parameter`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Adds an optional callback parameter to Image.getThumbUrl() for retrieving thumbnail URLs.
