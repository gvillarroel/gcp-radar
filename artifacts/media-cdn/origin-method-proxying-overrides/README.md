# Origin method proxying overrides

Product: Media CDN
Feature slug: `origin-method-proxying-overrides`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Media CDN can proxy supported HTTP methods other than GET, HEAD, and OPTIONS to an origin on specific route rules.
