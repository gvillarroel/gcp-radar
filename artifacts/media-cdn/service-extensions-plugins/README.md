# Service Extensions plugins

Product: Media CDN
Feature slug: `service-extensions-plugins`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Media CDN can run Service Extensions plugins in the request-response path for lightweight customization.
