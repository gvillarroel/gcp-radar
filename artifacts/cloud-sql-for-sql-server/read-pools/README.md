# Read pools

Product: Cloud SQL for SQL Server
Feature slug: `read-pools`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Read pools provide a single load-balanced read endpoint in front of up to seven read pool nodes for scaling read workloads.
