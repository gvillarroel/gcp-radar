# gp3 Amazon EBS volume type support

Product: Anthos clusters on AWS (previous generation)
Feature slug: `gp3-amazon-ebs-volume-type-support`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Anthos clusters on AWS supports gp3 EBS volume types and configuration of gp3 volumes for management service, AWSCluster, and AWSNodePools.

## Lifecycle

- Latest feature date: 2021-03-31
- Deprecation date: none recorded
- Status: feature_observed
