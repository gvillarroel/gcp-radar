# URLFetch oversized payload exception

Product: App Engine standard environment Java
Feature slug: `urlfetch-oversized-payload-exception`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Java URLFetch API uses RequestPayloadTooLargeException for requests whose payloads exceed the supported size.
