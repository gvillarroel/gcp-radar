# Task queue zero retry_limit behavior

Product: App Engine standard environment Java
Feature slug: `task-queue-zero-retry-limit-behavior`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Failed tasks in queues configured with a retry_limit of zero are no longer retried.
