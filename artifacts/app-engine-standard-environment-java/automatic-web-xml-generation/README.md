# Automatic web.xml generation

Product: App Engine standard environment Java
Feature slug: `automatic-web-xml-generation`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

App Engine can avoid generating a web.xml file when a Java 7 app already includes a servlet 3.1 web.xml.
