# URLFetch default deadline property

Product: App Engine standard environment Java
Feature slug: `urlfetch-default-deadline-property`
Coverage: `MEDIUM`

## Technical Summary

The Java URLFetch API supports an appengine-web.xml property to set a default fetch timeout in seconds.
