# Document Ranking API

Product: Vertex AI Search
Feature slug: `document-ranking-api`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Document Ranking API reranks a provided list of documents based on relevance to a query and is designed as a stateless API that does not require documents to be indexed beforehand; Introduces a stateless Document Ranking API that reranks provided documents by relevance to a query without requiring prior indexing.
