# Media Search query mode configuration and auto-selection

Product: Vertex AI Search
Feature slug: `media-search-query-mode-configuration-and-auto-selection`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Media Search now supports full-query and search-as-you-type result modes, with an auto mode that dynamically selects the best mode and is enabled by default.
