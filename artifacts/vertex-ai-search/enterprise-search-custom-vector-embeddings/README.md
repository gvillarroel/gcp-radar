# Enterprise Search custom vector embeddings

Product: Vertex AI Search
Feature slug: `enterprise-search-custom-vector-embeddings`
Coverage: `MEDIUM`

## Technical Summary

Enterprise Search supports using customer-provided vector embeddings in preview by allowing users to upload custom embeddings and apply them during search.
