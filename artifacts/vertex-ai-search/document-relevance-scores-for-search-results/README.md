# Document relevance scores for search results

Product: Vertex AI Search
Feature slug: `document-relevance-scores-for-search-results`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Returns a relevance score for each search result in a query, enabling downstream ranking or filtering of results for structured and unstructured data stores.
