# Boost search results

Product: Vertex AI Search
Feature slug: `boost-search-results`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Adds result-boosting capabilities for Vertex AI Search that improve ranking for media applications and generic search apps using unstructured and website data; Allows Vertex AI Search to boost relevance rankings using custom numerical attributes and freshness signals.
