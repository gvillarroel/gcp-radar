# Vertex AI Search adjacent chunk retrieval

Product: Vertex AI Search
Feature slug: `vertex-ai-search-adjacent-chunk-retrieval`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Enables search responses to include chunks that appear immediately before and after the most relevant chunk in a source document.
