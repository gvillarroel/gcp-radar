## Technical Summary

Vertex AI Codey APIs became generally available for building code generation, completion, and multi-turn code chat solutions; The Vertex AI Codey APIs entered Preview, allowing code generation, code completion, and code chat APIs to be used from any Google Cloud project without allowlisting in us-central1 via Generative AI Studio or REST.
