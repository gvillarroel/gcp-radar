# Virtual agent top-level queue transfers

Product: Google Cloud Contact Center as a Service
Feature slug: `virtual-agent-top-level-queue-transfers`
Coverage: `MEDIUM`

## Technical Summary

A virtual agent can now transfer consumers to a top-level queue and navigate active subqueue and leaf queue options.
