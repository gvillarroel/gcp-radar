# Chat transfer limits

Product: Google Cloud Contact Center as a Service
Feature slug: `chat-transfer-limits`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Chat transfer limit settings can include virtual agents, human agents, or both, and can reset the transfer count when a chat is dismissed; Chat sessions can be limited to a configured number of transfers, with options to disable transfer or allow one final transfer to a queue.
