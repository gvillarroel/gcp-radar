# Wait-time virtual agents for calls

Product: Google Cloud Contact Center as a Service
Feature slug: `wait-time-virtual-agents-for-calls`
Coverage: `MEDIUM`

## Technical Summary

A virtual agent can handle escalated incoming calls by providing real-time queue updates and transferring the call when an agent becomes available.
