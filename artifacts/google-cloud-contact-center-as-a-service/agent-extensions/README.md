# Agent extensions

Product: Google Cloud Contact Center as a Service
Feature slug: `agent-extensions`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Administrators can assign extension numbers to agents and provide an extension directory for end-users to call them directly; Agents can be assigned extensions for agent-to-agent calling.
