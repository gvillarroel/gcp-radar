# Agent Chat Adapter automatic translations

Product: Google Cloud Contact Center as a Service
Feature slug: `agent-chat-adapter-automatic-translations`
Coverage: `MEDIUM`

## Technical Summary

The Agent Chat Adapter can automatically translate messages between the end user's language and the queue's default language.
