# Skip Cascade Group Timer

Product: Google Cloud Contact Center as a Service
Feature slug: `skip-cascade-group-timer`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

This setting bypasses cascade timers and routes a call or chat to the next available agent.
