# Call Adapter transfer workflow

Product: Google Cloud Contact Center as a Service
Feature slug: `call-adapter-transfer-workflow`
Coverage: `MEDIUM`

## Technical Summary

The Call Adapter combines Transfer and Add Party into one streamlined transfer flow and supports use of the Outside Line tab during transfers.
