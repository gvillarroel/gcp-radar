# Batch translation

Product: Cloud Translation
Feature slug: `batch-translation`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Cloud Translation API v3beta1 supports asynchronous batch translation of .txt, .tsv, and .html files stored in Cloud Storage.
