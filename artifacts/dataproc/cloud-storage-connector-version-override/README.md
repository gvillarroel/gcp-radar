# Cloud Storage connector version override

Product: Dataproc
Feature slug: `cloud-storage-connector-version-override`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Dataproc lets users update the installed Cloud Storage connector version by setting a metadata key.
