# Stackdriver logging toggle

Product: Dataproc
Feature slug: `stackdriver-logging-toggle`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Stackdriver logging toggle lets users disable Stackdriver logging on Dataproc clusters through a cluster property.
