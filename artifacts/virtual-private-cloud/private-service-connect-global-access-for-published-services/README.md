# Private Service Connect global access for published services

Product: Virtual Private Cloud
Feature slug: `private-service-connect-global-access-for-published-services`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Global access for Private Service Connect endpoints allows clients in any region to send traffic to published services through those endpoints.

## Lifecycle

- Latest feature date: 2023-05-17
- Deprecation date: none recorded
