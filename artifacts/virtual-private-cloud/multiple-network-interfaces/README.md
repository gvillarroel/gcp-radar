# Multiple Network Interfaces

Product: Virtual Private Cloud
Feature slug: `multiple-network-interfaces`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Multiple Network Interfaces allows a VM instance to attach more than one virtual network interface, each connected to a different VPC network; Multiple Network Interfaces enables a VM instance to use more than one virtual network interface, with each interface attached to a different VPC network.
