# VPC network 1500 MTU support

Product: Virtual Private Cloud
Feature slug: `vpc-network-1500-mtu-support`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

VPC networks now support a maximum transmission unit (MTU) of 1500 bytes.
