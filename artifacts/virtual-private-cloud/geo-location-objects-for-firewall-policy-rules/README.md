# Geo-location objects for firewall policy rules

Product: Virtual Private Cloud
Feature slug: `geo-location-objects-for-firewall-policy-rules`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Firewall policy rules in VPC can use geo-location objects to filter external IPv4 and IPv6 traffic by region.
