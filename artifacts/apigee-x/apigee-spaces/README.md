# Apigee Spaces

Product: Apigee X
Feature slug: `apigee-spaces`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Apigee Spaces provides identity-based isolation, team-level grouping, and granular IAM control for API resources within an Apigee organization.
