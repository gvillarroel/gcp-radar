# API product-scoped quotas

Product: Apigee X
Feature slug: `api-product-scoped-quotas`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

API product-scoped quotas let you enforce request limits across all API proxies within an API product.
