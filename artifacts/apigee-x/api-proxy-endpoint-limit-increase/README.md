# API proxy endpoint limit increase

Product: Apigee X
Feature slug: `api-proxy-endpoint-limit-increase`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Apigee increases the maximum number of endpoints allowed per API proxy from five to ten.
