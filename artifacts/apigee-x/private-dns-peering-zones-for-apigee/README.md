# Private DNS peering zones for Apigee

Product: Apigee X
Feature slug: `private-dns-peering-zones-for-apigee`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

Apigee organizations without VPC peering can now resolve private domains by peering DNS zones with Apigee.
