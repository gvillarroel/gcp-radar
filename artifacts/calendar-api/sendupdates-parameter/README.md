# sendUpdates parameter

Product: Calendar API
Feature slug: `sendupdates-parameter`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Calendar API provides a sendUpdates parameter for controlling whether event change notifications go to all guests, only non-Google Calendar guests, or no guests.
