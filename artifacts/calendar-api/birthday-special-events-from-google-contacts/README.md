# Birthday special events from Google Contacts

Product: Calendar API
Feature slug: `birthday-special-events-from-google-contacts`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

The Calendar API can access birthdays and other special events automatically created from Google Contacts, including birthday-specific metadata in birthdayProperties.
