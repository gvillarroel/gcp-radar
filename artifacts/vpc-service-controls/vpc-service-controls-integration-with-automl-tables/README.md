# VPC Service Controls integration with AutoML Tables

Product: VPC Service Controls
Feature slug: `vpc-service-controls-integration-with-automl-tables`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

This integration lets VPC Service Controls protect access to AutoML Tables within a service perimeter.
