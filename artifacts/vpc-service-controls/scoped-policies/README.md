# Scoped policies

Product: VPC Service Controls
Feature slug: `scoped-policies`
Coverage: `MEDIUM`
IAM mapping: `unknown`

## Technical Summary

This feature lets administrators create VPC Service Controls access policies scoped to specific folders or projects.
